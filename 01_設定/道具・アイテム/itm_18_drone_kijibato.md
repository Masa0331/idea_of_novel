# ドローンキジバト（キジバト型ドローン）

## 概要

平優真が鍛冶屋望に「果樹園の害鳥（スズメ・ムクドリ等）駆除および忌避ミスト散布用」という名目で依頼し、製作させたキジバト（ハト科）型の特注小型ドローン。
優真の**真の目的は、この機体の制御システムをリバースエンジニアリング（分解・解析）し、本命である「ドローントンビ」の自動滑空・姿勢制御（ソアリング制御）システムとして転用すること**である。自身の計画にトビを利用することを望に悟られないよう、あえて全く異なる鳥で、かつ飛行制御の核となる部分が共通する仕様で依頼した。

作中において、アカメが目撃し恐怖した「煙を吐く獲物（ハト）の姿をしたバケモノ」の正体である。

---

## 1. 望への依頼名目（優真の巧妙な建前）

腕の良い技術屋である望に対し、優真は以下の「技術的・合理的な理由」を提示してこの機体を作らせた。

1.  **ターゲットの油断誘発とステルス性**
    「果樹園で深刻な被害を出すスズメやムクドリは警戒心が強い。猛禽類の姿をしたドローンではすぐに逃げられてしまい、忌避ミストを浴びせられない。だが、彼らにとって身近で無害な『キジバト』の姿であれば油断して接近を許す。キジバトのウロコ模様の羽もカモフラージュに最適だ」
2.  **故障率の劇的な低減と『帆翔飛行（ソアリング）』の必要性**
    「本物の鳥のように『たくさん羽ばたく（フラッピング）機構』は、関節やギアなどの可動部に多大な機械的ストレスがかかり、故障率が極めて高くなる。また、常に羽ばたき続けるのはバッテリー消費が激しく、実用的な滞空時間を稼げない。
    そのため、基本は上昇気流や風を捉えて滑空する『帆翔飛行（ソアリング）』をメインの飛行モードにし、羽ばたきは高度維持や微調整などの必要最小限に抑える高度な省電力制御プログラムを開発してほしい」
3.  **重量と翼開長のバランス**
    「ミスト散布機構やカメラ, バッテリーを積むと重くなる。しかし、滑空（ソアリング）をメインにするのであれば、翼面積を広げて翼開長をキジバト実寸（約55〜60cm）に設計することで、総重量約180g前後という制約のなかでも、十分な揚力を得て安定した滑空滞空が可能になる」

望はこれらの「可動部を減らし、滑空姿勢制御に特化して耐久性と省電力を極める」という技術的アプローチに知的好奇心をそそられ、高度な「ソアリング姿勢制御（ゆらぎ）プログラム」を本機に組み込むことになった。

## 2. 基本スペック

**ベース機体**: 滑空型固定翼/可変翼ハイブリッド方式（グライダー型クアッドコプター技術の応用）

### サイズ

| 部位 | 数値 | 備考 |
| ---- | ---- | ---- |
| 翼開長（全幅） | **約 55〜60 cm** | キジバトの実際のサイズにほぼ合致。滑空性能を重視した広い翼幅 |
| 全長（頭部〜尾羽末端） | **約 33 cm** | 実際のキジバトと同等。胴体部に液体タンクやポンプを格納するため、本物よりわずかに肉厚 |

### 重量

| 構成要素 | 重量 |
| -------- | ---- |
| 機体フレーム＋外装 | 約 35 g |
| モーター（推進用・姿勢制御サーボ含む） | 約 45 g |
| フライトコントローラー（気圧・風力センサー含む） | 約 15 g |
| バッテリー（2S 高放電LiPo） | 約 35 g |
| 液体タンク ＋ マイクロポンプ機構 | 約 20 g |
| ペイロード（水・農薬・忌避剤など） | **最大 30 g (30ml)** |
| FPVマイクロカメラ ＋ 映像送信機（VTX） | 約 15 g |
| RCレシーバー（アンテナ含む） | 約 2 g |
| 配線・コネクタ・ネジ類等 | 約 13 g |
| **総離陸重量（監視モード・液体なし）** | **約 180〜190 g** |
| **総離陸重量（農薬散布モード・液体満載・カメラ込み）** | **約 210〜220 g** |

> [!NOTE]
> 実際のキジバトの体重は約200〜300g程度。本機体はほぼ実物と同等の重量バランスを実現しており、外見のシルエットやサイズ感と相まって, 遠目には本物のキジバトと全く区別がつかない。

### 飛行性能

| 項目 | 数値 | 備考 |
| ---- | ---- | ---- |
| 最大飛行時間 | **約 25〜35 分** | 滑空（ソアリング）モードを多用することで、従来のマルチコプター方式（10分程度）に比べ飛躍的に滞空時間が向上。ミスト噴射により液体が空になればさらに滑空しやすくなる |
| 最高速度 | **約 50 km/h** | 滑空速度および推進用モーターによる最高飛翔速度 |
| 操縦・通信距離（RCリンク） | **最大 1 km / 実用 200〜500 m** | 見通し確保時 / 市街地・障害物あり |
| 映像伝送距離（アナログFPV） | **最大 500 m / 実用 100〜300 m** | 見通し確保時 / 市街地 |
| 飛行中騒音（機体直下 1 m） | **滑空時：約 30 dB 以下（ほぼ無音）**<br>モーター駆動時：**約 60〜65 dB** | 滑空時は無音。モーター駆動時でも静かな乗用車内（60 dB）程度 |

> [!NOTE]
> **無音滑空のステルス性能について**
> 本機体は「羽ばたきを最小限に抑えて滑空する」仕様であるため、ターゲットや周囲の野鳥に接近する際、推進用モーターを停止した完全滑空（ソアリング）状態に入る。この状態では風切り音以外の羽音が一切発生せず, 騒音値は 30 dB 以下（深夜の郊外やささやき声と同等）となり、野生の鳥たちにも直前まで気づかれない極めて高いステルス性を発揮する。

## 3. 特殊装備：液体噴射機構（ミスト散布機能）

本機体の最大の特徴であり、望が優真のオーダーを受けて苦心して組み込んだ機能。

* **マイクロポンプとノズル**: 機体の腹部（または尾羽の下部）に超小型の噴射ノズルを搭載。
* **ミスト噴射（煙の正体）**: 害鳥の顔に向けてピンポイントで液体を当てるため、高圧で微細なミスト状にして噴射する設定が可能。**無音で滑空しながらミストを噴射する様が、遠目には「煙を吐いている」ように見える。**
* **ペイロードの内容**: 表向きは「カラスを驚かせるための水」や「忌避用のハッカ油」。しかし、優真は実際に**薄めた農薬**を充填して使用している。これはドローントンビの作戦行動中に接近してくる大型猛禽類（女王・オオタカや周辺のトンビなど）の**モビング（群れによる追い払い）対策**として準備されたものであり、過去にも有効な忌避効果が確認されていた。優真は表面の「哺乳類には無害」という記述だけを確認し、生き物への危害はないと判断して使用を決めたが、裏面の警告文にある「鳥類には有害」という記述を見落としていた。

> [!WARNING]
> **鳥たちへの致命的な脅威（優真の見落とし）**
> 鳥類の呼吸器（気嚢システム）は哺乳類よりも極めて敏感であり、空気中の化学物質や毒素を効率よく（致命的に）吸収してしまう。ミストを浴びたマロン・アブラーゲ・アカメが致命的な状態に陥る直接の原因となる。

## 4. 監視・偵察装備（カメラシステム）

本機体は液体噴射機構に加え、FPVカメラと映像送信機（VTX）を搭載した**監視・偵察モード**での運用が可能。

### FPVカメラ

* **搭載位置**: 頭部（正面）または腹部（斜め前方）に内蔵
* **仕様**: 超軽量マイクロFPVカメラ。リアルタイム映像を操縦者へ無線送信

### 操縦者の想定位置と通信距離

| 条件 | RCリンク距離 | FPV映像距離 | 備考 |
| ---- | ------------ | ----------- | ---- |
| 見通し良好（屋外・障害物なし） | 最大 1 km | 最大 500 m | 公園・河川敷など開けた場所から操縦する場合 |
| 市街地・障害物あり | 実用 200〜500 m | 実用 100〜300 m | 建物が密集した住宅地・商業地での運用 |

### 監視モードと農薬散布モードの使い使い分け

| 運用モード | 液体タンク | カメラ・VTX | 総重量（目安） |
| ---------- | ---------- | ----------- | -------------- |
| **監視モード** | 空（液体なし） | 搭載 | 約 180〜190 g |
| **農薬散布モード** | 満載（30 ml） | 搭載 | 約 210〜220 g |

優真はハヤブサ探偵事務所周辺を監視する際、液体タンクを空にした監視モードで運用。事務所から **100〜500 m 圏内の路上駐車した車内、または見通しの確保できる建物の陰・高台**から操縦し, FPVゴーグルで事務所周辺の映像をリアルタイム確認する。

## 5. 機体構造と外装

* **ベースとなる望の機能美**: 望から納品された時点では「精巧な機械としての鳥」であり、軽量な樹脂素材にキジバトのカラーリング（首元の側頸斑や羽のウロコ模様）が施された状態だった。
* **優真による狂気的な装飾（獲物のキメラ）**: 優真は納品後、本物の鳥を完全に欺くため、事前に集めておいた**「本物のキジバトの落ち羽」**を機体に貼り付けている。キジバトのウロコ模様の羽は特徴的であるため、本物の羽を流用することで生々しい質感と外見を獲得している。
* **飛行アルゴリズム（ソアリング制御）**: 望が開発した「ゆらぎプログラム」のキジバト専用バージョン。内蔵された気圧・風力センサーから気流の強さを感知し、自律的に姿勢を制御しながら滑空姿勢（ソアリング）を維持する。羽ばたきは離陸時や失速回避のための最小限に抑えられている。

## 6. 物語上の機能と優真の「真の嘘」

* **カモフラージュとアリバイ**: 優真にとって、このキジバト型ドローン自体はどうでもいい「ダミー」である。望にドローン製作の技術（特にソアリング制御）を注ぎ込ませつつ、自身の本命がトビであることを完全に隠蔽するための巧妙な隠れ蓑として機能する。
* **技術の窃盗**: 優真はこの機体を受け取った後、基板から「ソアリング姿勢制御（ゆらぎ）プログラム」などの設定データ（ダンプデータ）を吸い出し、自身が用意した大型の「ドローントンビ」へ流用した。トビは上昇気流を利用したソアリング（滑空）を最も得意とする鳥であるため、この滑空制御プログラムは劇的な相乗効果をもたらした。
* **予想外の凶器**: 本来はダミーとして作られたはずの機体だが、優れた滑空ステルス性能とミスト散布機能を持つため、ドローントンビを追跡してきたマロン・アブラーゲ・アカメの迎撃に実戦投入されることになる。
* **アカメの恐怖（獲物の姿をした異形）**: アカメはツミ（タカ科）であるため、キジバトは彼らにとって身近な「獲物」である。しかし、この機体は獲物であるキジバトの姿をしているにもかかわらず、全く羽ばたかずに不気味な無音で滑空し続け、自分たちから逃げるどころか、毒性の煙（農薬ミスト）を吐き出して襲いかかってくる。野生の直感からすれば「生き物としての魂や恐怖心が一切なく、獲物の羽を纏って滑空する不気味なバケモノ」であり、理解不能なキメラ的恐怖と絶望感を与える。
* **事務所の監視（キーキーの伏線）**: 優真はハヤブサ探偵事務所の周辺に飛ばして監視を行っていた。キジバトは市街地や住宅街に極めてありふれた鳥であるため、周囲に溶け込んで監視を行うことができた。これが、キーキーが目撃した「ハトっぽい鳥」という伏線と完全に一致する。
