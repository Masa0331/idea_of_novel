# 【一覧リスト】現代の探偵道具と小道具アイデア

このファイルは、現代日本で活動する探偵（ハヤブサ探偵事務所など）が所持・使用する可能性のある探偵道具（ガジェット・スパイ道具含む）の網羅的なリストと、それらを小説の描写やプロットで生かすためのアイデア集です。
すべてを一つのファイルにまとめており、作中での描写やイベントの発想補助として使用します。

---

## 1. 基本となる探偵道具（三種の神器）

- **スマートフォン（デュアルSIM機）**
  - **機能**: 高性能カメラ、ボイスレコーダー、GPS、各SNSアプリ、情報検索、連絡手段。通信会社を変えてエリアの冗長化を図る。業務用と私用の分離、ダミー連絡先管理を行う。
- **デジタルカメラ（一眼レフ・ミラーレス・コンデジ）**
  - **機能**: 高感度・手ブレ補正・無音シャッター搭載。特に望遠レンズは対象に気づかれずに撮影するために不可欠。
- **ICレコーダー / ボイスレコーダー**
  - **機能**: 指向性マイク、タイムスタンプ機能つき。暗所操作しやすい物理ボタン。非常に小型で、胸ポケットやカバンに忍ばせて使う。
  - **描写例**: 「鞄の中、ジッパーの先に触れると、指先だけでICレコーダーの凹凸をなぞれる。暗闇でも“REC”に迷わないよう、シールの角をあえて欠いてある。」

## 2. 視覚・撮影系（特殊カメラ）

- **超小型ボディカム（クリップ式） / ペン型フルHDカメラ**
  - **機能**: レンズ孔が小さく、シャツポケットからギリギリ覗く程度。防水・手ぶれ補正付きのものもある。
  - **描写例**: 「胸ポケットの万年筆を軽く捻ると、LEDが暗く点滅した。依頼人の震えた声と同時に、証拠がメモリに刻まれていく。」
- **暗視対応小型カメラ / 暗視スコープ（ナイトビジョン）**
  - **機能**: デジタル暗視や赤外線イルミネーター併用。夜間の張り込みに使用。
  - **描写例**: 「暗視スコープを覗くと、世界が緑色に染まった。闇に潜むはずの対象の息遣いまで聞こえてきそうな、不気味な静寂がそこにあった。」
- **サーマルカメラ（スマホ接続型）**
  - **機能**: 熱を可視化。夜間監視や人の熱源確認に使用。夜の公園で、見えない足跡の「熱の抜け」を追うなどの展開に。

## 3. 音声・通信傍受系（グレーゾーン含む）

- **指向性パラボラマイク（折りたたみ式）**
  - **機能**: 30m先の会話を拾える。音源の追跡に使用。
- **無線盗聴器 / ワイヤレスマイク**
  - **機能**: 電波を使って相手の会話を遠隔で拾う。車の下に貼り付けるマグネット式など（使用には違法リスクが伴う）。
  - **鳥ネタ**: 2023年に東京で発見された「虫型盗聴器」。軍事レベルのスパイ技術からの転用。
- **電波探知器（バグディテクター / TSCM）**
  - **機能**: 盗聴器やカメラの不審な電波（Bluetooth、Wi-Fi6など）を検出する。
  - **描写例**: 「RFディテクターの針がかすかに震える。ノイズの海に、誰かの呼吸のような微かな波。電波もまた、都市の言語だ。」

## 4. 追跡・位置情報・監視系

- **GPS発信機（マグネット式LTE-GPS / トラッカー）**
  - **機能**: 車のフレームやバンパーに磁石で貼り付け、リアルタイムで位置を追跡（無断取り付けは違法の可能性が高い）。
  - **描写例**: 「ターゲットの車のバンパー下に屈み込み、泥の跳ね返りを装ってマグネット式のGPSを貼り付けた。わずか3秒の早業だった。」
- **AirTag / Tile などのスマートトラッカー**
  - **機能**: 原則は自分の持ち物に使用。逆に犯人に仕込まれる逆転現象の描写などに。
- **マイクロドローン（200g未満クラス）**
  - **機能**: 航空法の制約を避けつつ空撮が可能。事件現場の全景確認や機動的な追跡に使用。
  - **鳥類模倣（バイオミミクリー）アイデア**: ハヤブサなどの猛禽類の狩りの飛行ルート計算などをドローンのアルゴリズムに取り入れる。

## 5. 現場観察・証拠保全・法務対応

- **証拠保全ツール**
  - UV/ブルーライト懐中電灯（痕跡・偽造検査）、ポータブル指紋採取キット（粉とブラシ、透明テープ）、目印用チョークやメジャー。
  - **描写例**: 「証拠袋の口を閉じると、カサリ、と小さな音が部屋の空気に沈む。封印シールの赤は、正義というより、手続きの色をしていた。」
- **偽造身分証・名刺バリエーション**
  - **機能**: 「廃業した架空広告代理店」など複数準備し、潜入時に使い分ける。

## 6. 変装・セルフケア・防御装備

- **変装・カバーグッズ**
  - **機能**: フレーム違いの眼鏡、キャップ、シンプルなウィッグ、折りたたみトートバッグ（小道具の視覚的リセット）。
  - **描写例**: 「変装は演技じゃない。歩幅、スマホの持ち手、エレベーターで鏡を見ない癖。顔を変えるより、生活のノイズを変えるほうが難しい。」
- **セルフディフェンス・エマージェンシー**
  - **機能**: 防犯ブザー、LEDストロボ付き催涙スプレー、簡易防刃ビジネスバッグ、救急セットなど。

## 7. デジタル・サイバー系調査（OSINT）

- **モバイルOSINTセット**
  - **機能**: ノートPC＋VPN＋仮想環境。SNSや公開データベースから相関図を生成。
- **データ復旧 / フォレンジックUSB**
  - **機能**: 焼損したHDDや削除されたデータからの復元・パスワードリカバリ。
- **記憶支援ツール（AI音声要約アプリ）**
  - **機能**: スマホに録音した会話をAIが自動要約し、キーワードを抽出。

## 【小説創作向け：プロットや描写のアイデア】

- **テクノロジーの逆転（見られている側へ）**
  - 盗聴器発見の依頼で訪れた部屋で、逆に探偵の持つ機材（スマホなど）がスキャンされる。街中の監視カメラやトラッカーにより「追っているはずが追われていた」というサスペンス展開。
- **テクノロジーの限界とアナログの力**
  - 最新ガジェットがバッテリー切れや電波障害で使えなくなる（「GPSの空白の時間」）。最後に役立つのは、手書きの地図や、顔を覚えるという昭和のアナログ的手法。
- **証拠の劣化と記憶の誤差**
  - ドローンやカメラが高画質で捉えた「真実（画角の中の出来事）」が、当事者の体験や感情と食い違う。映像には映っていない「匂い」や「音の空気感」が事件の鍵を握る。
- **グレーゾーンの葛藤**
  - 証拠を得るために、非合法な潜入や無断のGPS設置という一線を越えなければならない状況。正義の大義名分と違法性の間で揺れ動く探偵のルポルタージュ的心理描写。
- **小道具への記憶の仮託**
  - 壊滅した三脚の脚の中に過去の依頼資料が隠されていたり、指紋キットが自身の過去の冤罪の象徴であったりするなど、「道具に記憶が宿る」演出。
- **鳥の習性の利用（アナログハック）**
  - カラスの個体識別能力を利用し、特定の人物（犯人）が来た時だけカラスが鳴くように訓練する。あるいは鳥の「声紋」を録音から解析して飼い主を特定する。
