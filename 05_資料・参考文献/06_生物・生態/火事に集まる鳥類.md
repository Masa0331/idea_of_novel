# 火事・野焼きに集まる鳥類に関する生態と習性

ドローントンビ放火事件で利用された「トビが火に集まる」という習性の詳細と、火災現場（野焼きなど）に集まるその他の鳥たちの行動パターン。

## 1. なぜトビ（トンビ）は火（野焼き・山火事）に集まるのか？

*   **狩りの効率最大化（絶好の狩り場）**: トビにとって、火事の現場は労せずして獲物にありつけるボーナスステージである。火や煙に驚き、隠れ場所から燻り出されて逃げ惑う昆虫（バッタ、コオロギ）、爬虫類、両生類、小型哺乳類（ネズミなど）を上空から容易に発見し、捕食することができるため。
*   **オーストラリアの特異例との違い**: オーストラリアの猛禽類（茶色ハヤブサ等）には、「自ら燃える枝を咥えて運び、意図的に火を放って獲物をあぶり出す」という能動的な放火行動が確認されているが、**日本のトビに「火を運ぶ」習性は確認されていない**。あくまで「他人が起こした火事」を利用するだけである。（※優真のドローントンビはこのオーストラリアの鳥の習性を模倣しているため、日本の鳥としては「異常行動」となる）
*   **「情報センター」としての機能**: 火災現場上空で多数のトビが旋回しているのは、単に集まっているだけでなく、一羽が獲物を見つけると他の個体にもその動きが伝わり、獲物の位置情報を効率的に共有するための「情報交換の場」となっている。
*   **カモフラージュの有用性**: 目撃者である田辺の「トンビが野焼きの近くを飛んでいた」という証言は、農村部の日常風景として何ら不自然ではないため、警察の初動を「単なる事故・鳥獣による失火」に誤認させる完璧な偽装として機能する。

## 2. 野焼き現場に集まるその他の鳥たち

火事による影響（熱、煙、鎮火後の焼け跡）に応じて、各段階で様々な鳥が異なる目的で飛来する。

| 鳥の種類                                   | 集まる目的・狙い                       | 飛来のタイミング     | 主な行動エリア                                             |
| :----------------------------------------- | :------------------------------------- | :------------------- | :--------------------------------------------------------- |
| **トビ（トンビ）**                         | 逃げ惑う獲物・上昇気流の利用           | 初期〜中盤           | **上空**、火元の風上                                       |
| **カラス類**                               | おこぼれ狙い（焼死した虫や獣の死骸）   | 初期〜鎮火後         | はじめは遠巻きに観察 → **鎮火後の焼け跡（地上）**          |
| **モズ**                                   | 驚いて飛び出した昆虫やトカゲの捕食     | 中盤                 | 少し離れた**見晴らしの良い枝や杭の上**（そこから急襲）     |
| **セキレイ類**                             | 焼けて見えやすくなった地面の虫やミミズ | 鎮火直後             | **燃え跡のど真ん中（地上）**。地面が熱くても平気で歩き回る |
| **ムクドリ**                               | 焼け跡に炙り出された虫、ミミズ         | 鎮火後（安全確認後） | **燃え跡全体（地上）**。大きな群れで降り立ち「清掃」する   |
| **小型猛禽類（チョウゲンボウ、ノスリ等）** | 林や草むらから逃げ出すネズミなど小動物 | 中盤                 | **上空（ホバリング・旋回）**。地上には降りない             |

## 3. 小説での情景描写のコツ

*   「野焼きの煙が龍のように天に昇る。その周りを、黒い紙吹雪のように無数のトビが旋回していた。火事の報せを聞きつけて集まった弔問客か、あるいは火事場泥棒か。甲高い鳴き声だけが、やけに暢気に響いていた」というように、専門家の解説ではなく一連の景色・日常の情景として溶け込ませる。
*   火が燻っている間は上空にトビやチョウゲンボウが舞い、鎮火して水をまかれた直後にセキレイが地面を走り回る、というコントラストを描くことで、現場のリアリティが深まる。
