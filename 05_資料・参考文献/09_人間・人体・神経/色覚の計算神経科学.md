# 視神経・色覚の計算神経科学：色が「脳の発明」である仕組み

> **出典**：カリフォルニア大学バークレー校（小谷篤信氏・Ren Ng氏）による計算論的フレームワーク研究（ICLR論文）

---

## 1. 脳に届く視神経信号（ONS）の正体

私たちが目を開けば「当たり前のように」鮮やかな色の世界が広がっていると感じるが、脳に届く**視神経信号（ONS：Optic Nerve Signals）**は、私たちが知覚している映像とは似ても似つかない。

「色彩は、私たちの脳と宇宙が出会う場所である。」 — ポール・クレー

これが示すように、色彩は外の世界にそのまま存在するのではなく、脳が作り上げた「推論の結果」である。ONSの持つ「3つの不都合な真実」は以下の通りだ。

### ONSの主要特性

| 特性       | 現実の風景               | 視神経信号（ONS）                              |
| ---------- | ------------------------ | ---------------------------------------------- |
| 空間構造   | 正確な幾何学的配置       | 中心窩への集中による魚眼状の歪み               |
| 色の表現   | 連続的な色彩の広がり     | 錐体のランダム配置による点状のスペクトルノイズ |
| 情報の形態 | 物体の質感や滑らかな陰影 | 側抑制によるエッジ（境界線）の強調             |

- **空間的歪み（中心窩誘導性の歪み）**：網膜の細胞密度の偏りにより、信号は魚眼レンズで覗いたように極端に歪んでいる。中心部は高密度でサンプリングされ、周辺部は粗い。
- **ノイズのようなスペクトルサンプリング**：錐体細胞（光センサー）がモザイク状に配置されているため、信号はパッチワーク状のデジタルノイズのように見える。
- **勾配ドメインへの変換（側抑制）**：水平細胞による**ラテラル抑制（側抑制）**により、信号の大部分はエッジと時間的変化のみを伝える勾配情報に変換される。色の「面」の情報は送出段階でほぼ欠落している。

このバラバラで不完全な信号から豊かな視知覚を再構成する秘密は、脳の「推論」にある。

## 2. ニューラル・バケット：脳が自分の眼を逆算する仕組み

脳は学習を始める際、視神経から送られてくる1つひとつの「線（軸索）」が、どの網膜細胞から来ているのかを知らない。そこで、脳は計算上の変数として空の器（バケット）を用意し、学習を通じてこのパラメータを埋めていく。

主に以下の3つのバケットが、世界の再構築を支える：

1. **位置のバケット (P)**：各細胞が網膜のどの座標にあるのか。これが埋まることで空間の「歪み」を補正できる。
2. **種類のバケット (C)**：その細胞がどの光（L・M・S錐体など）に反応するのか。この「スペクトル・アイデンティティ」が色の復元に不可欠。
3. **つながりのバケット (W)**：周囲の細胞とどう影響し合っているのか。「中心・周辺（Center-surround）構造」を推測し、エッジ強調などの側抑制を逆算するために使われる。

学習が進むにつれてこの器の中に正しい情報が蓄積され、脳は「どの信号が、どの場所の、何色のものか」を正確に把握できるようになる。

## 3. 自己教師あり学習：予測と答え合わせのサイクル

脳は「自己教師あり学習（Self-supervised learning）」と呼ばれる手法で、外の世界の正解（教師データ）を必要とせずにルールを見つけ出す。このサイクルはバケット（P, C, W）を計算資源として活用する3つのステップで構成される。

### 予測サイクル

1. **デコード（Φ：ファイ）**：届いた信号を、脳内のバケット情報を参照して「内部イメージ」に翻訳する。Pで歪みを直し、Cで信号を色ベクトルに変換して「たぶんこんな景色だろう」と予測を立てる。
2. **変換（Ω：オメガ）**：脳は眼球がどれくらい動いたかを知っているため、その動きに合わせてイメージを平行移動（シフト）させる。「目が右に動いたから、景色は左に動くはずだ」とシミュレーションする。
3. **再エンコード（Ψ：プサイ）**：シフトしたイメージを、再びWやPなどの網膜ルールに通して視神経信号の形式に変換し直す。「次の瞬間に目から届くはずの暗号を、自分でもう一度作ってみる」作業。

数式で表すと：`Ô_{t+dt} = Ψ(Ω(Φ(O_t)))`

**「自分で作った予測信号」と「実際に目から届いた次の信号」のズレ（誤差）**を計算し、そのズレを最小化するようにバケットの中身を更新し続ける。これが脳の学習の原動力だ。

### 固視微動（Fixational Eye Motion）の役割

一点を見つめている時も、実は目が細かく震えるように動いている（**固視微動・フィクセーション・ドリフト**）。この動きこそが学習の鍵だ。

窓ガラス越しに景色を見ていると想像してほしい。ガラスに「汚れ（網膜の特性）」がついている場合、頭を動かせば「動くもの（外の景色）」と「動かないもの（ガラスの汚れ）」がはっきりと分離される。

眼球運動によって景色を網膜上で滑らせることで、脳は「常に一定の場所で反応するノイズ（網膜不変特性）」と「動きに合わせて変化する信号（外の景色）」を切り分けることができる。これが**ディスエンタングルメント（解きほぐし：Disentanglement）**である。

## 4. 色覚次元の段階的な創発

脳内での色覚の獲得は、統計的に安定した情報から順に、段階的に行われる。

| 学習ステップ               | 獲得する次元              | 内容                                                  |
| -------------------------- | ------------------------- | ----------------------------------------------------- |
| 0（初期）                  | 0次元                     | 何も学習していない状態                                |
| 700ステップ                | 1次元（モノクロ）         | 「明るいか暗いか」の統計的安定性を解読                |
| 1,200ステップ              | 2次元（二色型）           | センサーの違いを認識。青-黄、青-オレンジなど          |
| 100,000〜1,000,000ステップ | 3次元（三色型フルカラー） | L・M・S錐体情報を完全に解き明かした洗練された3D色空間 |

重要なのは、脳は最初から「色は赤・緑・青の3次元（RGB）である」と知っているわけではなく、視神経から送られてくる信号の**変動パターンだけを頼りに「自分の眼には何種類の錐体細胞があるのか」を自ら推論する**という点だ。

2次元の段階で再現された色覚（青-黄、青-オレンジ、ティール・ピンクなどの配色）は、実際の色覚多様性（色盲）で見られる色彩世界と正確に一致している。

## 5. 色覚次元の評価ツール：CMF-SIMとNeural Scope

獲得された色覚の「質」と「次元」を客観的・科学的に検証するための手法が2つある。

### CMF-SIM（Color Matching Function Test Simulator）

マクスウェルの等色実験を計算論的に再現する定量的測定ツール。特定の波長を再現するのに必要な最小の「原色（Primaries）」数を特定し、色彩次元（1D〜4D）を数学的に厳密に証明する。

- 脳を「ブラックボックスな観測者」として扱い、特定の色を再現するために必要な最小限の原色数を特定する
- 原色数を増やした際、AUCがほぼゼロに収束する最小の原色数が、その色覚の真の次元数

### NS（Neural-Scope）

高次元の内部表現（**R^N ベクトル空間**）をRGB空間へ線形投影して可視化する独立したツール。学習ループとは独立した「観測者のためのレンズ」であり、学習が進むにつれて内部知覚がどう変化しているかを直感的に捉えられる。

この「ブラックボックス・アプローチ」は、特定の色彩体系（RGB等）を前提とせずに視覚を分析することを可能にし、人間だけでなく他種（テトラクロマット等）の視覚体験や異常な色覚を持つ観察者の主観を客観的な科学として扱うパラダイムシフトをもたらした。

## 6. 4色型色覚（テトラクロマシー）：1億色の世界

### 脳の次元数は固定されていない

実験結果は驚くべき柔軟性を示している。受容器（コーン）の種類が1種類から4種類まで変化するのに応じ、脳は事前知識なしに、それぞれ1D（モノクロ）から4D（テトラクロマティック）の色空間を自然に獲得する。

| 錐体細胞の種類 | 創り出される色世界 | 識別可能色数（概算）    |
| -------------- | ------------------ | ----------------------- |
| 1種類          | 1次元（モノクロ）  | —                       |
| 2種類          | 2次元（二色型）    | 〜10,000色              |
| 3種類          | 3次元（三色型）    | 〜100万色（通常の人間） |
| 4種類          | 4次元（四色型）    | 〜1億色                 |

1つの錐体細胞は光の波長や明暗のわずかな違いを**約100段階**識別できる。一般的な人はこの3種類のセンサーの信号を脳で組み合わせるため `100 × 100 × 100 ≈ 100万色`、4色型色覚の人は `100万 × 100 ≈ 1億色` を識別できる。

### 4色型色覚の世界の見え方

実際の4色型色覚を持つアーティスト、コンチェッタ・アンティコ氏の体験から：

- **影の中の色彩のモザイク**：普通の人が見て「数種類の灰色」しか感じない影の中に、「何百種類もの灰色」と、スミレ色（バイオレット）・ターコイズブルー・モーブ（薄紫色）などがはっきりと見える。
- **宝石のディスプレイ**：鈍い灰色の小石の道も「オレンジ、黄、緑、青、ピンク」の色が飛び込んでくる「宝石のディスプレイ」のように輝いて見える。
- **木の葉の縁の色**：葉の縁にオレンジや赤、紫がひしめき合っているのを知覚する。
- **健康状態・感情の視覚化**：人が体調を崩しかけている時は肌に「緑や灰色」が現れるのを見たり、栄養状態が良い時は肌に「オレンジやピンクの輝き」を感じ取ったりできる。
- **低照度に強い**：影の中や夕暮れ時のような「薄暗い光の条件（低照度）」において、一般的な人よりもはるかに豊かな色彩を経験する。

### 色相球（Hue Sphere）：次元が変わると色の連続性が変わる

**3色型色覚（3D）の色相環（輪）**：最も鮮やかな色のつながりは1次元の線であり、両端が繋がった「色相環（輪）」。1次元の線上の点は前後の**2つしか隣接点を持たない**ため、オレンジの隣には「赤」と「黄色」しか存在できない。

**4色型色覚（4D）の色相球（球面）**：次元が1つ増えるため、色相のつながりは「1次元の輪」から**2次元の「球面（S²）」へと拡張**される。球面上の任意の点は360度の全方向に隣接点を持つため、4色型の世界ではオレンジの周囲を赤と黄色だけでなく**「緑」や「ピンク」などの色がリング状に取り囲む**ことになる。

3色型の人間には「ただの灰色」に見える2つの色が、4色型の脳内では青と黄色のように全く異なる「補色」として明確に分離して処理される現象がある（「keef」「litz」と名付けられた未知の対比色）。

## 7. 機能的テトラクロマットの稀少性

遺伝的に4つ目の錐体を持つ可能性がある女性は**12%から最大約50%**と推定されているが、実際に1億色を見分けられる「機能的なテトラクロマット」は**女性全体のわずか1〜2%**と非常に稀だ。

### 機能しない理由（3つの壁）

1. **錐体細胞の「感度のズレ」が小さすぎる**：変異した4つ目の錐体と既存の錐体のピーク波長がわずか4〜5nmしか離れていない場合、視覚システムの「ノイズ」に埋もれてしまい、脳が独立した新しい色として認識できない。機能が実証された「cDa29」という被験者の場合は**12ナノメートル**も離れていた。
2. **環境と「脳のトレーニング」の不足**：現代の環境（印刷物やディスプレイ、照明など）は圧倒的多数派の「3色型色覚」向けに作られているため、4色型にしか見えない特殊な色が環境中に不足している。刺激がないため能力が眠ったままになっている人が多い。
3. **厳しいテストをクリアできる人がほとんどいない**：視覚研究者のガブリエレ・ジョーダンらが行った厳密なテストで、機能的な4色型を実証した被験者はわずか1人（cDa29）だった。

「2つのX染色体における特定の突然変異」「既存の錐体から十分に離れた感度ピーク（12nm程度）」「環境要因と脳の発達」といういくつもの偶然と条件が重なる必要があり、それが極めて稀な存在にしている。

### 4色型の遺伝的背景

- 第4の錐体を生み出す遺伝子はX染色体上に存在するため、**X染色体を2つ持つ女性にのみ**発現する可能性がある
- 赤と緑の錐体を作る遺伝子はX染色体の上にあり、男性はX染色体を1つしか持たないため錐体が4種類になることはない
- 女性であれば、片方のX染色体に通常の赤と緑の遺伝子を、もう片方に突然変異した遺伝子を持つことで4つ目の錐体を同時に持てる

## 8. 新色「olo（オロ）」の発見

### Ozシステムとは

カリフォルニア大学バークレー校の研究チームが開発した**「Oz（オズ）」レーザーシステム**。人間の目にある特定の視細胞（錐体細胞）だけをピンポイントで狙い撃ちにして刺激する最先端の光学イメージング・システム。

自然界では、M錐体（緑）を活性化する光の85%はL錐体（赤）も同時に活性化させてしまうため、「M錐体だけが単独で刺激される」ことは物理的にあり得ない。OzシステムはこのM錐体だけを単独でピンポイントに刺激することに成功した。

### 「olo」の特性

脳は「自然界では絶対に発生しない純粋なM錐体のみの信号」を歴史上初めて受け取り、その結果として知覚された色が**「olo（オロ）」**だ。

- **「極めて彩度の高い青緑色（ティール）」または「深いピーコックグリーン（クジャクの羽のような青緑）」**
- **「すべての緑の中で最も緑らしい緑（the greenest of all greens）」**
- 自然界の最も鮮やかな色（緑色のレーザーポインターの光など）でさえ、比較すると「青白く見えてしまう」ほどの**「比類のない彩度」**
- 自然界や従来のディスプレイでは決して再現できない、**人為的に白光を混ぜてかろうじて「近似」できる程度**の完全に日常的な視覚体験の外側にある色

レーザーの狙いをわずかにずらして無作為な錐体細胞に光が当たるようにすると、新色「olo」は消え去り、被験者にはただの「普通の緑色のレーザー光」に見えるようになる。

この技術は、人間の脳には現在の眼の限界（3種類の錐体）によって制限されているだけで、**本来はもっと多くの色の次元を処理できる可塑性**を秘めていることを示した。

## 9. 遺伝子治療による色覚拡張

### リスザルでの成功例（2D→3D）

2009年のMancusoらによる研究で、先天的に2色型色覚（色盲）である**成体のオスのリスザル**に対し、遺伝子治療を用いて3つ目の錐体（Lオプシン）を網膜に導入した実験が行われた。

その結果、**成体であっても脳の視覚回路が新しい光受容体からの信号に適応し、新たに3次元（3色型）の色彩感覚を獲得することに成功**した。これは哺乳類の脳には成長後であっても新しい色の次元を処理できる「可塑性（柔軟性）」があることを証明した。

### ヒトの4色型色覚への拡張（シミュレーション）

UCバークレー校チームは人間の網膜と大脳皮質を模した計算フレームワークで、「遺伝子治療による色覚ブースト」をシミュレーションした。

- 通常の3色型モデルに4つ目の錐体（Q錐体）を追加
- 大脳皮質の学習モデルは自己教師あり学習によって新しい視神経の信号を解読し、**最終的に4次元（4D）のフルカラービジョンへと適応（再収束）した**

ただし4色型色覚への拡張が脳内で正しく発達するためには、**視覚環境に含まれる色の多様性**が強く影響する。自然界の風景だけでは4つ目の錐体を独自に刺激するような色のコントラストが不足している場合があり、4次元の色覚を完全に目覚めさせるには人工的な刺激や、4色型用の高いコントラストを持つ特殊な視覚環境（トレーニング）に脳をさらす必要がある。

### 色覚拡張プロセスの3段階

1. **治療直前**：既存の限定的な色空間（2Dなど）で世界を見ている
2. **追加直後のノイズ状態**：新しい受容体からの信号は、当初、脳にとって「意味不明な未知のノイズ」として映る
3. **再学習後の新視覚**：脳がSSLループを回し「ニューラル・バケツ」を更新し続けることで、数千から数万ステップを経て新しい色の次元が立ち上がる

## 10. 4色型色覚の社会的応用と潜在的デメリット

### 応用可能性

- **医療・健康状態の可視化**：黄疸・発熱・チアノーゼなど、通常の症状が現れる前に視覚的に早期発見が可能
- **セキュリティと迷彩の看破**：通常の3色型色覚を騙す「メタメリズム（等色）迷彩」を容易に見破れる
- **偽造防止技術**：4色型の人にしか見えない特殊なインクを使った強力な偽造防止技術
- **データビジュアライゼーション**：識別できる「色」が増えることは、そのまま「情報を伝えるチャンネル」が増えることを意味する
- **美容・デザイン**：照明の温度や周囲の色の反射まで正確に把握し、肌のトーンの「構成要素」を完璧に見極められる

### CVPYインク：4次元の色空間を物理的に表現する試み

通常のCMYKインクの限界を打ち破り、4色型色覚が持つ4次元の色空間を物理的な印刷物で再現するために開発されたインクセット。

- **C**yan（シアン）・**V**iolet（バイオレット）・**P**ink（ピンク）・**Y**ellow（イエロー）
- 光学的な分光反射率のポイントが493nm・551nm・603nmという特定の波長になるように数学的に設計
- プロトタイプ実現に使用された近似インク：EpsonのCyan、PlatinumのViolet、DiamineのPeach Haze、Noodler's InkのOperation Overlord Orange

4色型の人にしか見えない「イシハラ式テスト」新バージョンや、特殊偽造防止技術に応用可能。

### デメリット：1億色の代償

- **視覚的な疲労（情報過多）**：コンチェッタ・アンティコ氏はスーパーマーケットを「あらゆる角度から色が押し寄せてくる」と表現し、安らぐ色は「白」
- **大多数（3色型）との色彩感覚のズレ**：他人が「同じ色」に見える服の組み合わせが、4色型にとっては全く違う色に見え「ひどく衝突」して見える
- **能力を持て余すジレンマ**：現代の社会はすべて「3色型色覚」向けに作られており、能力を完全に発揮できる4色型向けの環境が存在しない

## 11. 生物学的な色覚の進化史（2D→3D→4D）

- **2色型（2D）への退化**：ジュラ紀の初期、哺乳類の祖先は恐竜を避けた夜行性生活で錐体細胞の多くを失い、S・M/L2つの錐体しか持たない2色型色覚となった
- **3色型（3D）の獲得**：旧世界ザルなどの霊長類へ進化する過程で、X染色体上にあったLWS遺伝子に「重複と突然変異」が起きた。これにより緑（M）に敏感な錐体と赤（L）に敏感な錐体が分かれ、青・緑・赤を見分ける3色型色覚を獲得した
- **4色型（4D）の誕生**：現代の人間において、X染色体を2本持つ女性の一部にさらなる突然変異が生じている。一方の染色体に通常のM・L遺伝子を、もう一方に変異したハイブリッド遺伝子（L'やM'など）を持つ場合、網膜に4種類の錐体細胞が発現することがある

## 12. 工学的応用：自己校正カメラ設計

（センシング工学への展開。本フレームワークを実装することで：）

- **製造誤差の許容**：物理的な画素配置の不規則性や分光感度の個体差を製造段階で完全に補正する必要がなくなる。運用開始後の「自己教師あり学習」がNeural Bucketsを通じてこれらの不変量を事後的に獲得し、従来なら廃棄されていた低精度センサーを「完璧なデバイス」へとソフトウェアでアップグレードできる
- **自己修復型センシング**：物理的な損傷や経時劣化が生じた場合でも、システムはリアルタイムで自己学習を継続し誤差を補正する
- **ヘテロジニアス・センサー・フュージョン**：既存システムに新しい受容器（例：近赤外線センサー）を「後付け」しても、ファームウェアの書き換えなしにその機能を統合し知覚次元を拡張できる

## 13. 用語集

| 用語                                        | 説明                                                                                                                                    |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 視神経信号（ONS）                           | 網膜神経節細胞から脳へ送られる電気信号の流れ。色彩情報は直接含まれず、空間歪み・スペクトルノイズ・勾配情報が絡み合った状態にある        |
| 固視微動（Fixational Eye Motion）           | 注視中も発生する不随意な微細眼球運動。静止したシーンを「時間的に変動する信号」へと変換するトリガーで、自己教師あり学習を可能にする      |
| ニューラルバケット（Neural Buckets）        | 各錐体細胞の推定プロパティ（位置P・スペクトルidentity C・側方抑制重みW）を格納する学習パラメータ群                                      |
| 網膜不変量（Retinal Invariants）            | 個体固有の固定された生物学的パラメータ（錐体の空間配置・スペクトル特性・側方抑制の結合重みなど）                                        |
| 側方抑制（Lateral Inhibition）              | 水平細胞によるコントラスト強調。ONSを絶対的輝度なしのエッジ情報の集積へと変換する                                                       |
| ディスエンタングルメント（Disentanglement） | 混ざり合った信号から「網膜不変特性（ノイズ）」と「外の景色の情報」を分離すること                                                        |
| テトラクロマシー（Tetrachromacy）           | 4種類の錐体細胞を持つ4次元の色覚。人間では一部の女性に遺伝的に発現する可能性がある                                                      |
| CMF-SIM                                     | マクスウェルの等色実験を計算論的に再現した定量ツール。色覚次元数を厳密に測定する                                                        |
| Neural Scope（NS）                          | 高次元内部表現をRGB空間へ線形投影して可視化する独立ツール                                                                               |
| メタメリズム（Metamerism）                  | 異なる分光特性を持つ色が、特定の色覚タイプの目には同じ色に見える現象                                                                    |
| olo（オロ）                                 | Ozシステムを用いてM錐体のみを単独刺激することで初めて知覚された新色。極めて彩度の高い青緑色（ティール・ピーコックグリーン）と形容される |
| CVPY                                        | 4色型色覚の4次元色空間を物理的に表現するためのインクセット（Cyan・Violet・Pink・Yellow）                                                |
| Keef・Litz                                  | 4次元の色理論モデルで計算された、3色型には同じグレーに見えるが4色型には補色として見える色のペア                                         |
| 空間的色補間（デモザイキング）              | 網膜上の各点には1種類の錐体しか存在しないため、周辺情報から全波長情報を推定するプロセス。脳のNeural Bucketsが担う                       |
