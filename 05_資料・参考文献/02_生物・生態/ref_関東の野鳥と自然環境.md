# 関東の野鳥と自然環境・地形の影響リスト

関東地方の自然環境、特に気象や地形が野鳥に与える影響と、それに対する各種の得手・不得手をまとめたリスト。

## 1. 気象要素

*   **突風・強風 / ゲリラ豪雨**
    *   **得意**: アマツバメ（強風を利用して飛翔）、カラス類（状況判断力が高く素早く避難）
    *   **苦手**: 小型のカラ類（シジュウカラなど・吹き飛ばされる）、ツバメ（巣が風雨で壊れやすい）、メジロ
*   **長雨・梅雨 / 猛暑（真夏日・熱帯夜）**
    *   **得意**: サギ類（雨でも水辺で採餌可能）、ドバト（都市部の熱アイランドに強い適応）、ムクドリ
    *   **苦手**: 猛禽類全般（雨で羽が濡れると飛翔能力低下、ネズミも隠れる）、高山性の鳥類（暑さに弱い）、小鳥全般（体温調節が困難）
*   **乾燥・水不足 / 冬の北風（空っ風など）**
    *   **得意**: ヒバリ（乾燥した河川敷や農耕地を好む）、猛禽類（北風の湧昇流を利用）
    *   **苦手**: カワセミ（水場が枯れると致命的）、ムクドリ（地面が硬くなりミミズが獲れない）、小鳥全般（寒風による急激な体温低下に弱い）
*   **深い雪・積雪 / 濃霧**
    *   **得意**: ツグミ（雪原でも餌を探せる）、キビタキ等の森林性小鳥（霧の森に適応）
    *   **苦手**: 地上採餌の鳥（キジ、ハクセキレイ等・餌が埋まる）、猛禽類（視界不良による狩り失敗）
*   **雷・落雷**
    *   **得意**: （特になし。全般的に恐れる）
    *   **苦手**: 高木で営巣するカラス類（落雷被害を受けやすい）

## 2. 地形・環境要素

*   **広大な平野（関東平野特有） / 河川敷のヨシ原・草原**
    *   **得意**: ヒバリ（開けた環境を好む）、チョウゲンボウ（ホバリングでの狩りに最適）、オオヨシキリ、セッカ
    *   **苦手**: 森林性の小鳥全般（身を隠す場所がない）、猛禽類（止まり木がない）
*   **都市部のビル群・コンクリートジャングル / 郊外の住宅街**
    *   **得意**: ハヤブサ（高層ビルを断崖絶壁に見立てる）、カラス類（ゴミ場適応、巣材確保）、ムクドリ（電線や看板をねぐらに利用）、ツバメ、スズメ（人工物利用）
    *   **苦手**: ワシ・タカの大型種（オオタカを除く・飛行空間が狭い）、森林・水辺を必要とする野鳥全般
*   **公園・緑地（人工的な自然） / 森林・山地**
    *   **得意**: オナガ、ヒヨドリ、メジロ（ツバキ等の植栽を利用）、アカゲラ、キビタキ、ヤマガラ（垂直・水平移動に長ける）
    *   **苦手**: 警戒心の強い大型鳥類、開けた場所を好む水鳥や猛禽類（木々が飛翔の妨げになる）
*   **海岸線・干潟 / 湖沼・ため池**
    *   **得意**: シギ・チドリ類（泥から餌を捕獲）、ユリカモメ、カモ類、カイツブリ、カワセミ
    *   **苦手**: 森林性・草原性の鳥全般
*   **急な傾斜地・崖**
    *   **得意**: イワツバメ、カワセミ（土手や崖に巣穴を作る）
    *   **苦手**: 平坦地で生活するチドリやキジ類

## 3. その他の環境要因

*   **農耕地（田畑）**
    *   **得意**: ケリ、スズメ、サギ類（田んぼのどじょう等）
    *   **苦手**: 森林特化の鳥類
*   **人工の照明・夜間の明るさ**
    *   **得意**: ゴイサギ、夜行性のフクロウ類（明るさに集まる虫やネズミを狙う）
    *   **苦手**: 渡り鳥（光害で方向感覚を失う、高層ビルに激突）
*   **人や車の行き交う道・騒音**
    *   **得意**: ハクセキレイ（コンビニの駐車場などでも平気）、ハシブトガラス
    *   **苦手**: コゲラ、声の小さな小鳥（さえずりが掻き消されてペア形成が困難化）

## （おまけ）特定の状況下での得意・不得意

*   **急な逃走・回避行動**：得意＝ツバメ等の敏捷な小鳥。不得意＝大型猛禽類、サギ類。
*   **長距離の移動・渡り**：得意＝シギ・チドリ類、ガン・カモ類。不得意＝キジ等（長距離飛行不可）。
*   **人工物への適応（営巣など）**：得意＝ツバメ、スズメ。不得意＝古木を必要とするフクロウ、アカゲラ。
*   **飢餓への耐性（絶食能力）**：得意＝大型猛禽類（消化が遅い）。不得意＝小鳥全般（代謝が早く、数日の絶食で致命的）。
*   **外敵への集団防衛**：得意＝カラス、ムクドリ。不得意＝単独行動の猛禽類。
*   **狭い空間での飛行・ホバリング**：得意＝ハチドリ、メジロ、チョウゲンボウ。不得意＝翼の長い海鳥やアホウドリ。
*   **毒虫・毛虫の捕食**：得意＝カッコウ、ホトトギス（毒毛虫の捕食能力）。不得意＝一般的な小鳥類。
*   **凍結した水面・湖**：得意＝ハクチョウ（氷上でも耐える）。不得意＝カワセミ（水に飛び込めないため致命的）。
*   **台風接近時の気圧降下**：得意＝カモメ等（いち早く内陸や安全な水域へ避難）。不得意＝小型で飛翔力の弱い鳥（巻き込まれて遭難）。
*   **硬い木の実や種子の採食**：得意＝シメ、イカル。不得意＝昆虫食特化の鳥類。
*   **空中での急降下狩猟**：得意＝ハヤブサ、トビ。不得意＝森林内で待ち伏せ狩りをするハイタカやフクロウ。
