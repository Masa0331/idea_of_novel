# 『やばすご！鳥伝説 鳥たちのビックリ生活』関連資料

## 1. 概要
本書は、鳥たちの驚くべき生態、特に「食生活」「恋愛・結婚・子育て」「超能力」、そして「鳥の面白さ」に焦点を当てた書籍のレビューと関連資料です。野鳥観察を通して鳥たちの行動の「なぜ？」を深掘りし、鳥たちの「信じられない一面」を解説しています。

## 2. 驚くべき食生活
* **カワウ**: 水に潜って魚を捕食する水鳥。水面を叩いたり水中に潜ったりして魚を追い込みます。時には1000羽を超える大群で「水のカラス」と呼ばれる集団を形成し、網打ち漁のような陣形を組んで協力して効率的に魚を捕獲します。
* **クロガモ**: 大好物はウバガイ（アサリやハマグリなど）などの二枚貝。これを殻ごと大量に丸呑みし、非常に丈夫な消化器官で、胃の中で貝殻を砕いて消化する能力を持ちます。消化の際には目を潰す（潰れた二枚貝の目を排出する）という独特の行動をします。
* **ヒレンジャク**: ヤドリギの実（種子）を好んで食べます。その排泄物である「長いうんち」は粘着性が強く、これが木に付着し新たな場所でヤドリギの種子が発芽するのを助け、鳥と植物との間に見事な共生関係を築いています。
* **イスカ**: マツボックリの種子を取り出すために、「クチバシが交差した特別な形」に進化しており、他の鳥では食べられないような奥にある種子を食べることができます。
* **ハヤブサ**: 定説ではタカやフクロウに近い猛禽類で「肉食の狩りの名人」（急降下時速300km超）とされてきましたが、最新のDNA調査により、インコ類（オウム目）と進化的に近い仲間である可能性が判明しました。クチバシの形や体形がインコに似ている点も指摘されています。
* **ヤマガラ**: 自分で選んだ植物の種子（ドングリなど）を土に埋めて隠す「貯食行動」を行います。隠した場所を忘れることで新しい木が生える手助けをしており、カケスやシジュウカラなども同様の行動をとります。
* **メジロ**: 細く長いクチバシと長い舌を使ってサクラなどの花蜜を吸います。その際、顔や胸の羽毛に花粉をつけて他の花へと運び、受粉を助ける（花粉媒介）重要な役割を担います。
* **オオワシ**: 日本最大の猛禽類の一つ。生きた獲物だけでなく、氷上に打ち上げられた魚やアザラシなどの死体（死骸）も主な餌とします。力強いクチバシと足の爪が特徴的です。
* **ワシカモメ**: 食べたい貝が硬くて口を閉じている場合、上空から貝を落として衝撃で殻を割り、中身を取り出して食べます。人間が落とした魚やゴミを利用することもあります。
* **オオジュリン**: 冬には植物や昆虫だけでなく、アシの皮をクチバシで剥くようにして、カイガラムシのフン（カイガラムシの出す甘い液体）を大好物として食べる珍しい食性を持つホオジロ科の小鳥です。
* **ダイゼン**: 干潟に生息する「ゴカイ」と呼ばれるミミズを好んで主食とするシギ。「大膳」という名前は、その肉が美味しいことから高貴な人々の食膳に供されたことに由来すると言われています。
* **ハマシギ**: 20世紀になって食料が判明したシギ。小型の二枚貝や、干潟の表面のバイオフィルム（微生物の集合体）を食べていることが明らかになりました。
* **ワカケホンセイインコ**: 都市環境に巧みに適応し、東京23区を中心に生息数を増やしている外来種です。桜の花や果実を餌として都市生活を送ります。
* **アカゲラ**: 木の幹に穴を開け、長い舌で中の虫を捕らえて食べるキツツキです。硬いクチバシと強靭な頭蓋骨が特徴です。
* **ヘラサギ**: スプーン（ヘラ）のような形をしたクチバシを持ち、水中の小魚やエビを左右に振りながら捕獲します。環境の変化により生息数が減少しています。
* **ダイサギ**: 白い体色で大きなサギ。捕まえたカエルなどの大きな獲物を咥え、何度も水につけて飲んだり食べたりし、最終的に丸呑みにする行動が見られます。
* **カツオドリ**: ダイビングして魚を捕らえる海鳥。獲物を見つけると「キーッ！」と大きな謎の鳴き声（仲間を呼ぶように見える）を出して急降下・ダイビング捕食を行います。
* **ハチクマ**: 猛禽類でありながら、スズメバチの巣を破壊し、幼虫やハチ（ハチミツ）を食べるタカです。ハチに刺されても平気な耐性・特性を持ちます。
* **チゴハヤブサ**: 「空中サーカスの軽業師」とも言える小型のハヤブサ。空中での高い運動能力・素早い方向転換で、飛んでいるトンボなどの大型昆虫を空中で捕らえます。
* **ペリット**: 多くの鳥は、食べ物の骨や毛、羽毛、種子など胃で消化できない未消化物を「ペリット」として吐き出す塊を作ります。これにより体を軽くし、飛ぶエネルギーを節約します。

## 3. 恋愛・結婚・子育ての驚くべき戦略
* **エナガ**: 体重8gほどの非常に小さな体で10個もの卵を産み、必死に多数のヒナを育てます。巣はクモの糸や羽毛で器用に作ります。時には親鳥以外の多くの大人が子育てを手伝う共同繁殖を行うこともあります。
* **キジ**: 毎日必死で自分のテリトリー（縄張り）を守り、メスを獲得するために他のオスと「命がけで追い出しあう」激しい競争を毎日繰り返します。
* **コゲラ**: オスの頭部にあるわずかな「赤い羽毛」が、求愛時にメスに見せる特有のチャームポイントとなっているキツツキです。
* **ヤマドリ**: 天敵（外敵）がヒナに近づくと、親鳥が自らケガをして飛べないふり（地面にうずくまり翼を垂らすなど）をして注意を引きつけ、その間にヒナを安全な場所へ逃がす感動的な親鳥の行動「擬傷（ぎしょう）」をとります。タゲリなどにも見られます。
* **カイツブリ**: 生まれたてのヒナは、すぐに親鳥の背中に乗って水面を移動し、親は水中にもぐって餌をとって与えるという愛らしい姿を見せる水鳥です。
* **オオハクチョウ**: パートナーと一生を共にする一夫一妻制の鳥。一度ペアになるとどちらかが死ぬまで相手を変えず、毎日何度も求愛ダンスを繰り返して絆を深めます。
* **コアジサシ**: オスがメスに「求愛給餌」として魚を贈り（運び）続け、メスが納得するまで求愛し、その後交尾と子育てが始まります。
* **カワラバト**: 都市のコンクリートの建物や人間の食べ残しを利用し、年に複数回繁殖するハト。オスもメスも親鳥の嗉嚢（そのう）から分泌される栄養豊富な「コジョウミルク」（ピジョンミルク）を出してヒナを育てる特殊能力を持ちます。
* **カルガモ**: 都会の公園の池など人間が作った環境を利用して子育てをするカモ。10〜14個の卵を産み、ヒナはすぐに自分で泳いで餌を探し自立が早いです。
* **ウグイス**: 「ホーホケキョ」と鳴くことで知られますが、冬には鳴かず「チャッ」「チャップ」「チッチー」などの地鳴きを出して越冬します。
* **タンチョウ**: ペアの絆を深めるために、毎日何度も求愛ダンスを繰り返します。
* **タマシギ**: 鳥の世界では珍しい「一妻多夫制」をとります。メス（派手で鳴き声で縄張りをアピールする）は複数のオスと交尾して複数の巣に卵を産み、すぐに次のオスを探します。そのため、オスが巣を作り、卵を抱き、ヒナの世話をすべて献身的に行います。
* **モズ**: 秋にはオスとメスが縄張りをめぐり激しく争いますが、やがてペアになり子育てを始めるという複雑な関係性を持ちます。
* **オオミズナギドリ**: 繁殖期（伊豆七島など）には、ヒナに与える魚を求めて100km（時に1000km）離れた遥か遠い海域まで長距離飛行して餌を探しに行く海鳥です。
* **トキ**: 繁殖期が近づくと、オスのトキはクチバシで体を洗い、泥を塗って首から上の皮膚や羽毛を黒っぽく汚す「繁殖色」に変化します。この黒く汚れた羽根の方がメスにモテる（経験・健康のサイン）という独自の美意識を持ちます。
* **オシドリ**: オスは美しい華やかな羽毛を持ちますが、繁殖期にメスが巣穴で卵を産んで単独でヒナを育て、オスは子育てには全く参加しません。
* **サシバ**: 求愛ダンスでお互いの信頼をゲットし、オスがメスにエサ（獲物）をプレゼントして求愛と子育てに真剣に取り組むタカです。
* **アオサギ・コサギ・ダイサギ**: 繁殖期になると「婚姻色」として体色や羽色が鮮やかに一時的に変化し、パートナー募集のサインとします。

## 4. 鳥たちの惊くべき超能力
* **アマツバメ**: 生涯のほとんどを空中で過ごし、繁殖期以外は地上に降りません。足が弱く歩くのは苦手で、「マイクロ睡眠」と呼ばれる短い眠りを繰り返し、空を飛びながら眠る能力を持ちます。
* **フクロウ**: 夜行性の猛禽類。優れた夜間視力と、獲物の位置を正確に把握する聴力（顔の羽毛がパラボラアンテナの役割をする）を持ちます。羽根の構造は新幹線の形状（騒音低減）に応用されています。
* **トラツグミ**: 「人間には聞こえないほどの金属音のような超音波」（5000～15000Hz）を発し、暗闇の中で獲物を探すのに役立てていると考えられています。
* **タンチョウ**: マイナス20℃の厳冬期の川の中に足を入れ、足が凍結するのを防ぎながら一晩中立ったまま眠ります。体温低下を抑え敵から身を守ります。
* **コミミズク**: 草むらに深く隠れた小さなネズミなどを上空（ホバリング）から見つけ出す驚異的な視力と聴力を持つフクロウ。暗所でもわずかな光を捉え、首が270度も回転します。
* **カケス**: 日本の野鳥界の「モノマネグランプリナンバー1」と称されるカラス科の鳥。他の鳥や動物の鳴き声だけでなく、救急車のサイレンなど人間が聞いた音まで巧みに真似る能力を持ちます。
* **オオバン**: 以前は臆病で警戒心が強かったものの、近年（過去5年ほど）は性格や生活様式が環境適応によって大幅に変化（イメチェン）し、都市部の公園等で大胆に生活するようになった水鳥です。
* **オオワシ**: 毎年同じ場所に数千kmの渡りを行い、29年以上生き続ける個体（「山爺」や「おばあちゃん」などと呼ばれる）もいます。
* **アホウドリ**: 長い翼を広げ、風の力を巧みに利用して「ほとんど羽ばたかずに長距離の海面を滑空」する優れた飛行技術（ダイナミックソアリング）を持ちます。航空技術者からも注目されています。
* **オオソリハシシギ**: 渡りの途中でニュージーランドからアラスカまでなど、約7000km〜1万km近く（地球の1/4）を5〜9日間かけて無着陸で休みなく飛び続ける驚異の持久力を持つ渡り鳥です。
* **ヒバリ**: 暴風雨の中など危険な荒波を乗り越える際、海を渡る途中で船に避難して乗り込むような行動（賢さ）が観察される渡り鳥です。
* **チョウゲンボウ**: ハヤブサ科の鳥で、人間には見えない「紫外線」を感知する能力を持つ小型のタカ。上空でホバリングしながら、地面（草むら）に隠れたネズミの尿の跡から出る紫外線を追跡し、獲物を発見・捕獲します。

## 5. 鳥はやっぱりおもしろい・多様な特徴
* **クロサギ**: 同じ種類でありながら、白い個体（タイプ）と黒い個体が存在する不思議なサギです。
* **カラス類**: ハシブトガラス（10分以上と長い水浴びを好む）、ハシボソガラス、ミヤマガラス、ワタリガラス、コクルガラスなど多様な種類が存在します。
* **メボソムシクイ**: 以前は1種類と考えられていましたが、DNA調査により鳴き声の違いから3種類に分類されたウグイス科の鳥です（見た目では区別できない）。
* **オガサワラカワラヒワ**: 小笠原諸島に生息。DNA調査により2020年に絶滅危惧種の新種と判明しました。
* **ダイサギ**: いくつかの亜種があり、他のサギと姿や大きさが似ているため名前の区別が難しい・混乱しやすいです。
* **ヘラシギ**: 特徴的なヘラ状のクチバシを持ちますが、生息環境の減少で世界中で約300羽しかおらず絶滅が危惧されています。
* **ヨシゴイ**: 危険を感じると周りの植物（アシなど）に擬態し、体を細く伸ばして「身を隠す名人」となります。
* **名前の由来と鳴き声**: サンコウチョウ（鳴き声が「月・日・星（ホイホイホイ）」と聞こえるのが由来）、カッコウ、ウソ、コマドリ、ジュウイチなど、鳴き声が名前の由来になった例が多くあります。
* **青い鳥**: オオルリ、コルリ、カワセミ、イソヒヨドリなど。幸せの象徴とされ探すのを楽しみにする人も多いです。

## 6. バードウォッチングと今後の示唆
* **バードウォッチングの意義**: 鳥の生態や行動を観察して楽しむ趣味。名前を知るだけでなく、「何をしている？」「なぜそうする？」と疑問を持つことで、鳥の「やばすご！」な生活への理解（超能力や繁殖戦略の奥深さ）が深まります。
* **始める時期**: 新緑や初夏は鳥が繁殖期で警戒心が強く見つけにくいため、葉が落ちて鳥が見つけやすい「秋から冬」が特におすすめです。
* **鳴き声で識別**: 「ホーホケキョ（ウグイス）」「ケキキ（キビタキ）」など、鳴き声の質やリズム、フレーズで鳥を関連付けて覚えるのがコツです。
* **環境への意識**: 鳥との交流を深めることは、生物多様性への理解を深め、保護活動への意識を高めることに繋がります。
