# 日本のペット業界の問題：キトンミル・悪質ブリーダー・流通の実態

> **関連ファイル**: `chr_12_mascot_charlene.md`（シャーリーン、マスコット猫のキャラクター背景）

---

## 1. キトンミルとは

**キトンミル（Kitten mill）**: 「子猫の工場」を直訳した言葉で、**営利のみを目的として猫を劣悪な環境で大量に繁殖させる施設**。動物福祉を顧みず、猫を金儲けの道具として扱う悪質な繁殖業者のシステム。犬の場合は「パピーミル（Puppy mill）」と呼ぶ。

---

## 2. キトンミルの実態と特徴

### 2.1 劣悪な飼育環境

- 狭く不衛生なケージに閉じ込められ、糞尿まみれの状態で飼育
- 爪や毛が伸び放題で手入れが行き届かない
- 換気がほとんど行われず、悪臭が漂い、ゴキブリ・ネズミが大量繁殖しているケースも
- **長野県松本市の実例**: 麻酔なしで犬を帝王切開（「獣医師に診せると金がかかるから」という理由）

### 2.2 「生産マシン」としての扱い

- 母猫は子猫を産む「道具」として扱われ、健康状態を無視した無理な交配を繰り返す
- 人工的な照明操作で冬でも年に何度も発情を誘発・出産させる（本来は年1〜2回が理想）
- 母猫が哺乳を続けると次の発情が来ないため、子猫を最低限の日数で引き離す
- 繁殖能力が落ちたら「使い物にならない」として放置・廃棄

### 2.3 不適切なケア

- 粗悪なフードや腐った餌、苔が生えた水が与えられることも
- 病気・怪我の動物が適切な処置なく放置。死体が放置されることも

## 3. 猫への悪影響

### 身体的影響

| 症状                   | 詳細                                                                                                                               |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **遺伝性疾患**         | 近親交配により先天異常のリスク増大。スコティッシュ・フォールドは先天性骨軟骨異形成症（折れ耳が奇形由来で全身の関節に骨瘤ができる） |
| **感染症**             | 早期離乳（生後8〜12週が理想）による免疫力低下。猫カリシウイルス・FeLV・FIV等                                                       |
| **栄養不足・発育不全** | 重度の歯周病・疥癬・床ずれ等が見られるケースも                                                                                     |

### 精神的影響

- 狭いケージでの飼育・早期離乳 → 社会性の低下・人間不信・攻撃性・分離不安
- 虐待を受けた動物は警戒心が強く、場合によっては殺処分対象になることも

## 4. ペット流通経路の実態

### 主な流通ルート

```
悪質ブリーダー（キトンミル）
       ↓ オークション（段ボール箱に詰められて競り落とされる）
ペットショップ（消費者が出身元を知れない）
       ↓ 売れ残り
値引き → 他業者へ売却 → 悪質引き取り業者（生き地獄） → 動物実験施設 → 殺処分
```

**ペットオークション**: 子猫が段ボール箱に詰められ商品のように競り落とされる。健康確認が不十分なまま取引される。

**大手ペットショップの実例**: Coo&RIKUの系列グループでは、自前の大規模繁殖場を全国展開し、月5万頭規模の犬猫を「生産」していたと元社員が証言。

### 消費者が出身元を知れない構造

- 複雑な流通経路のため、消費者は「どんな環境で育ったか」「悪質ブリーダー出身か」を把握できない
- ペットショップのブリーダー名表示は義務化されているが、環境調査をする消費者は少ない

## 5. 日本の法規制と現状の課題

### 動物愛護管理法の主な規制（2020年改正「数値規制」）

| 規制項目           | 内容                                                   |
| ------------------ | ------------------------------------------------------ |
| **ケージの広さ**   | 自然な姿勢で全動作が可能な十分な広さ                   |
| **飼育頭数上限**   | 繁殖猫25頭・販売猫30頭（従業員1名あたり）              |
| **繁殖回数・年齢** | 雌猫は6歳以下で繁殖（条件付きで7歳以下まで）           |
| **健康管理**       | 年1回定期健康診断の義務化                              |
| **8週齢規制**      | 生後56日未満の販売禁止（ただし生年月日の偽装事例あり） |
| **マイクロチップ** | 販売業者への装着・登録義務                             |

### 罰則（2019年改正）

- 動物殺傷: 5年以下の懲役または500万円以下の罰金
- 遺棄・虐待: 1年以下の懲役または100万円以下の罰金

### 現状の課題

- **取り締まりが追いつかない**: 行政の人手不足
- **事前偽装**: 立ち入り調査前に環境を取り繕える
- **レッドカード（行政処分）がほぼ出ない**: 数値規制のレッドカードが実際に出た事例は極めて稀
- **罰則の軽さ**: 史上最悪とされる事例（約1,000頭を劣悪環境で飼育、452頭を衰弱させた事件）でさえ、懲役1年・執行猶予3年の判決

## 6. 多頭飼育崩壊との関連

キトンミルは多頭飼育崩壊の主な原因の一つ。

**多頭飼育崩壊のタイプ**:
| タイプ                 | 内容                                                 |
| ---------------------- | ---------------------------------------------------- |
| 動物救助・保護者タイプ | 救助の使命感から過剰に保護し、管理不能に             |
| 過剰な世話タイプ       | 社会的孤立と動物への過剰な愛情から制御不能に         |
| ブリーダータイプ       | 営利目的が優先され売買・繁殖ペースが合わなくなり崩壊 |
| 搾取者タイプ           | 自己中心的に動物を集め、ケアを怠る                   |

## 7. 欧米との比較

欧米では**ペットショップでの生体販売を禁止または抑制**する動きが進んでいる。日本は法整備・意識の面で遅れていると指摘されている。

## 8. 私たちができること

1. **保護猫の譲渡を検討する**: 保護団体・自治体の譲渡会を活用
2. **避妊・去勢手術を徹底する**: 不要な繁殖防止と殺処分減少
3. **信頼できるブリーダーを選ぶ**: 飼育環境見学・親猫の確認・購入の急かしに注意
4. **消費行動を見直す**: 「可愛いから」の衝動買いが悪質業者を存続させる（「買い物は投票」）
5. **寄付・ボランティアへの参加**: 保護団体の運営支援

## 9. 小説創作への応用

### シャーリーンへの設定応用

- シャーリーンがキトンミル出身である、または悪質なペット流通を経験している背景設定の根拠として
- シャーリーンの人間不信・特定の行動パターン（攻撃性・過度な警戒心）の説明に使用

### 社会派テーマへの活用

- 「ペット業界の闇」を取り上げた事件の舞台設定
- 探偵事務所への依頼事件として「行方不明となった多頭飼育崩壊の母猫を探す」など
- 流丘市の保護猫活動・TNR活動（地域猫の避妊・去勢・リリース）と絡めた事件

### 描写例・表現例

> 「その猫は、人間の手を見ると体を低くした。きっと、人の手が『餌をくれるもの』ではなく『押し込める狭い箱』を連想させるのだろう。シャーリーンに初めて会ったとき、ひかりはそう直感した」

> 「オークション会場では、子猫たちが段ボール箱の中で鳴いていた。商品名には品種と月齢だけが書かれていた。その小さな命に『物』という名がついていた」
