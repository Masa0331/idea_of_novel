# 善場と火事 ── 設定資料

> 本資料は、善場 翔騎の事業に火災が起きた際の対応・捜査・危険性に関する設定を整理・統合したものである。
> 放火の手法（ドローントンビ・ニクロム線案）については `../../02_plot/` 配下の資料も参照。

---

## 1. 前提：火災の状況

### 1-1. 出火と位置関係
- **火元**: B棟（事務所・小屋）内部から出火（優真によるドローントンビ放火）。
- **A棟（猫舎・飼育舎）**: 無事。ブリーダー業の登録施設。
- **火葬車の位置**: B棟の西側出入り口の近く。善場がA棟から子ネコの死骸を積み込み終えたタイミングで隼と亜紀人が到着し、B棟反対側のプロパンガスボンベが火を噴いた。

### 1-2. 直前の周辺状況（トンビ放火事件の環境要因）
- **野焼きの煙**: 善場の小屋の半径500m以内で2〜3箇所の野焼きが行われており、現場周辺には常に煙の匂いが漂っている。この煙が北風によって南（B棟のある方向）へ流れていることが、後にA棟が延焼を免れる（助かる）伏線となる。
- **鳥たちの存在**:
  - **トビ**: 野焼きの煙に驚いて飛び出すネズミや昆虫を狙い、上空を2〜3羽のトビが旋回している。この自然な光景が、優真の繰る「ドローントンビ」が紛れ込むための最高のカモフラージュとなる。
  - **カラス**: トビと同様に獲物を狙っているが、より警戒心が強いため、煙の上空は飛ばず少し離れた場所から遠巻きに眺めている。

## 2. 公権力の対応（二段構え）

火災発生後、善場が対峙する公権力は**2つの波**で到来する。

### 第一段階：警察・消防（当日）

- **目的**: 放火犯と火災原因の捜査。
- **善場に対する態度**: 当初は「被害者」として扱う。動物管理の専門家ではないため、飼育舎がクリーンであれば疑わない。
- **善場がごまかせる条件**: 飼育舎が表向きクリーン（＝仮面が完璧）であること。

### 第二段階：保健所（動物愛護センター）（翌日以降）

- **目的**: 登録事業者が動物愛護管理法を遵守しているかの行政調査。「放火犯の捜査」ではない。
- **担当者**: 動物Gメンと呼ばれる専門職員。動物管理のプロ。
- **調査内容**:

#### A) 動物の安否と飼養環境の現物確認

- 火災を免れた飼育舎で、残された猫の健康状態を**全頭チェック**。
- 匂い（アンモニア臭）・毛艶・ケージの清掃状況を瞬時に見抜く。
- 善場がアングラ事業の動物を飼育舎に混ぜていた場合、「異質な個体」の存在に必ず気づく。

#### B) 飼養管理台帳と現物の突合（最重要）

- 「飼養管理台帳」＝ 動物の戸籍。いつ・どこから仕入れ、いつ・誰に販売（or 死亡）したかを全頭分記録。法律で5年間の保存が義務。
- 台帳の個体と、目の前のケージの個体の数をその場で**突合**する。

**善場が破綻するシナリオ**:

| パターン                 | 状況                                                               | 結果                                             |
| ------------------------ | ------------------------------------------------------------------ | ------------------------------------------------ |
| **台帳がない（燃えた）** | 「事務所と一緒に燃えた」と主張                                     | 即座に法令違反確定。「燃えた」は言い訳にならない |
| **数が合わない**         | クリーンな台帳だけ提出。しかし引き取り屋の動物を飼育舎に隠していた | 「台帳にない謎の猫」の存在で違法引き取りが発覚   |
| **偽造台帳を提出**       | クリーンな台帳のバックアップを提出                                 | 台帳と現物の突合で不一致が発覚                   |

## 3. 善場が入院中の場合

入院中でも保健所の調査は**即座に開始**される。

- **理由**: 調査対象は善場個人ではなく「登録事業者」。
- **調査の矛先**: 登録責任者である**彼女**に向かう。
- **管理体制の追及**: 「善場が入院中、誰が責任を持って動物の世話をするのか？」を厳しく追及。明確な管理計画がなければ「飼養継続困難」と判断され、**動物の一時保護（行政による押収）**に踏み切る可能性あり。

**物語的効果**: 善場という「司令塔」が不在の中、彼女が保健所のプロからの「台帳を出せ」「現物を見せろ」という二重の追及に一人で直面する。善場を守るために嘘をつくのか、パニックで自白するのか。

## 4. 善場の隠蔽行動

善場は「善良な被害者」を演じつつ、裏で最重要の証拠を処理する。

### 4-1. 火災発生直後の行動（最優先行動：案Cを採用）

善場が最も優先するのは、動物の命よりも「カネと帳簿」の確保である。火災に気づいた瞬間、彼は無事な飼育舎には目もくれず、燃え盛る事務所に突入する。

- **位置関係**: この時点で隼と亜紀人はB棟の反対側（東側）におり、善場の事務所突入を直接は目撃していない。ただし、煤だらけの善場が事務所方面から何かを抱えて戻ってくる姿は目にしている（後の推理材料になりうる）。
- **具体的行動**: 金庫にある「未申告の利益（現金）」と「手書きの取引帳簿の一部」を抱えて脱出する。PC本体は事務所に残され焼損する（完全破壊かどうかは不明）。
- **偽装**: 消防や周囲には「大切な家族（猫）の写真だけでも取り出したかった」と涙ながらに嘘をつく。
- **物語的効果**: 彼の歪んだ道徳軸を強烈に印象付けるシーン。「猫ではなく金を取りに行った」という事実自体が善場の本性を端的に示す。一方、PCの焼損状況が不明なことが、後の隠蔽工作（4-4）の動機となる。


### 4-2. 善良なブリーダーの演技（警察到着後）

- **飼育舎への誘導**: 燃えている事務所ではなく、無事な飼育舎の方で「被害」を訴える。「高価なブリーダー用の猫がパニックを起こしている、助けてくれ」と警察の意識を事務所から逸らす。
- **クリーンな飼育舎のアピール**: あえて見せることで「私は善良な被害者だ」と印象付ける。
- **効果**: 警察は「善場＝被害者」と認識し、初期段階で容疑者候補から除外。

### 4-3. 火葬車の緊急移動（実行者：隼）

警察到着前、B棟のプロパンガスボンベが火を噴く直前の混乱の中で、**隼が火葬車を移動させる**。

- **きっかけ**: 善場が「爆発するぞ！」と叫ぶ。隼は爆発危険を回避するために咄嗟に火葬車を移動。
- **善場の誤算**: 善場は火葬車を自分の手で移動し、証拠を隠蔽するつもりだった。しかし隼に先に動かされたことで、車の最終的な管理権を失う。
- **物語的皮肉**: 善場の「爆発する」という真実の叫びが、結果的に証拠物件を第三者（隼）の手に渡すきっかけとなる。隼はこの時点で火葬車の異常（異臭、重量感、冷凍ストッカーの音）に最初の違和感を覚える。

### 4-4. 入院中の隠蔽指示（2日間の猶予がある場合）

善場が入院中でも電話で共犯者（彼女）に指示を飛ばす。丹下は火災で死亡しているため、実行できるのは彼女のみ。

| 優先度                  | 内容                                                              | 指示先   |
| ----------------------- | ----------------------------------------------------------------- | -------- |
| **1. 飼育舎の「掃除」** | 台帳にない猫（引き取り屋の在庫）をすべて火葬車に移す              | 彼女     |
| **2. 火葬車の炉の清掃** | 灰を全て江戸川に廃棄、車内の血痕も完全消去                        | 彼女     |
| **3. データの破壊**     | 事務所のPCの焼損状況を確認。バックアップ（USBメモリ等）を物理破壊 | 彼女     |
| **4. 偽りの供述**       | 死亡した従業員（林・中嶋）に火災原因の責任を転嫁する証言の準備  | 善場本人 |

**物語的効果**: 善場は「悲劇の被害者」を演じながら、裏で彼女を唯一の「実行犯」に引きずり込む。丹下も中嶋も死亡しているため、死人に口なし――善場は死んだ仲間を「盾」にして責任を転嫁する。彼女は、すべての汚れ仕事を一人で背負わされる。

## 5. ニクロム線案（優真の偽装工作）と捜査のタイムライン

優真がドローントンビ＋ニクロム線案を実行した場合の、警察捜査の時系列。

### フェーズ1：偽装の成功（事件発生〜1日目）

- 「トンビが火のついた何かを落とした」という目撃証言＋火元から本物の炭の燃え残りが発見される。
- 「鳥獣害による失火（事故）」として処理開始。本格捜査は開始されない。

### フェーズ2：鑑識による逆転（1〜2日目）

- 鑑識が「炭の燃え残り」を分析。内部から**ニクロム線の断片**を発見。
- 「電熱線を使った発火装置」の動かぬ証拠 → **「事故」から「放火（刑事事件）」へ反転**。

### フェーズ3：保健所の介入要請（2日目〜）

- 「刑事事件」認定により、警察は犯罪現場として敷地全体（A棟含む）を保全・調査する法的権限を取得。
- 「被害者の事業に、放火される動機があったのでは？」との観点から、保健所に**捜査協力**を要請。
- 保健所が「登録事業者の飼育実態や行政指導歴、違法性」を専門家の目で調査。

**結論**: ニクロム線案は捜査開始を1〜2日遅らせるが、鑑識がニクロム線を発見した時点で「完全な放火事件の証拠」となり、保健所は「捜査協力」の大義名分で必ず介入する。

## 6. プロパンガスボンベの爆発：ジェットファイア

B棟に設置されたプロパンガスボンベが火災で加熱された場合の進行。

> ※ 本筋では、隼がジェットファイア発生の直前に火葬車を移動させている（4-3節参照）。このため火葬車はジェットファイアの直撃を免れているが、善場にとっての「悪夢」は、車を**自分の管理下に戻せなくなったこと**にある。

### 各フェーズ

| フェーズ                        | 時間目安     | 状況                                                                                        |
| ------------------------------- | ------------ | ------------------------------------------------------------------------------------------- |
| **第1：加熱**                   | 火災〜約10分 | 輻射熱がボンベを加熱。内部の液化プロパンが沸騰開始。外見上は沈黙                            |
| **第2：安全弁作動**             | 約10〜15分   | 内圧が限界（約1.6〜1.8MPa）に達し、安全弁が作動。高圧ガスが噴出→即座に引火                  |
| **第3：ジェットファイア最盛期** | 約15〜25分   | **ジェットエンジンのような轟音**。5〜10m以上の火炎流が噴射。現場の他の音を完全にかき消す    |
| **第4：終息 or BLEVE**          | 約25〜30分後 | ガスが燃え尽きれば鎮火。ボンベ金属が強度を失えば**BLEVE（沸騰液膨張蒸気爆発）**＝巨大な火球 |

### ジェットファイアの影響

- **轟音**: 人の声は一切聞こえない。指示や警告が無意味に。
- **超高温（1000℃超）**: 炎の進路上は即座に破壊。
- **輻射熱**: 炎に直接触れなくても、数メートル以内で立っていられない。深刻な火傷。
- **延焼**: 周囲の可燃物に次々引火。

### BLEVE（沸騰液膨張蒸気爆発）

- **発生条件**: 安全弁の放出能力を超える加熱、またはボンベの気相部が炙られ金属強度が低下。
- **結果**: ボンベが物理的に引き裂かれ、内部の液化プロパンが一瞬で気化・膨張。**直径数十メートル以上の火球**を形成し、衝撃波とボンベ破片を数百メートル四方にまき散らす。

## 7. 火葬車の危険性（移動後も残る問題）

> ※ 火葬車は隼により移動済みだが、以下の危険性は変わらない。むしろ「第三者が移動させた車」であるために、善場は証拠隠滅の機会をさらに失っている。

### 物理的危険：車両自体の爆発リスク

- LPGボンベや灯油タンクを搭載 → 何らかの事故や二次火災で引火・爆発の危険は常にある。
- 二重底の密閉空間に隠された灯油タンクが気化 → 圧力鍋のように爆発力増大。

### 証拠の露出リスク

- 冷凍ストッカーの長時間の電源喪失 → 内部の**大量の動物の死体が腐敗開始** → 強烈な腐臭。
- 車両を調べた第三者（隼、警察、鑑識）が二重底の構造や異臭に気づく。
- 消防・警察が車両を確認した際、「焼却されるはずのない大量の死体」が発見される。

### 善場のジレンマ（移動済みバージョン）

- 隼が移動させた火葬車は、善場の「手の届かない場所」にある。
- 取り戻しに行けば不自然（なぜ証拠を気にするのか）。
- 放置すれば腐臭や冷凍ストッカーの異常から証拠が露見する。
- **「善意の第三者」に証拠物件を預けてしまった**という、自業自得の窮地。

## 8. 捜査上の危険：火葬車の押収

刑事事件となった場合、鑑識は犯罪現場の全域を保全・調査する。火葬車は**最重要の証拠物件**。

押収された場合に暴かれるもの:

- 「供養」ではありえない大量の動物の骨片
- 引き取り屋として処理した雑多な動物の痕跡
- 保護猫カフェから横流しされた動物の処理記録
- → **善場の「裏の顔」の全てが暴露**される。
