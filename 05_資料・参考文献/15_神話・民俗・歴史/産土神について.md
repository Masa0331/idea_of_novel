# 『「あなた担当の神様」のみつけかた』書籍資料

本書は、私たち一人ひとりに生まれたときから死ぬまで、そして死後も寄り添い、守護する「あなただけの特別な存在（オンリーワンの神様）」すなわち「産土神様（うぶすながみさま）」の概念を紹介し、絆を深めることで豊かな人生が拓かれる道筋を示しています。

## 1. 産土神様（担当の神様）とは
私たちにはそれぞれ「担当の神様」が割り当てられています。
* **唯一無二の存在**：あなたのことを誰よりも深く理解しており、困りごとや願いごとをするのに「最強の神様」です。
* **産土神様の決定時期**：母親があなたを妊娠して5～6か月の時期に住んでいた場所の大自然の土地神様が担当となります。
* **生涯にわたる守護と死後の導き**：誕生後も生涯、遠い地へ離れても必ず見守り、亡くなった後でも担当から外れず、迷う魂を次の世界（浄土）へ導いてくれます。
* **「結び」の働きと開運**：運気が上昇する際に必要な人とのご縁を繋ぎます。特に「合格祈願」「就職祈願」「縁結び」など、努力する人間の姿を知った上で最大限の後押しをしてくださいます。
* **願いのお見極め**：人間の願いは叶えたいと思っているものの、それが魂の成長にとって本当に良いことかを見極めた上で最適な方法で成就させます（我欲による願いは無条件に叶えません）。
* **邪気からの保護**：有名神社などご利益目当ての人が多く集まる場所での「欲の念」からくる「念当たり」を防ぐため、絆があれば見えないバリアを張って守ってもらえます。

## 2. 産土神社の見つけ方
産土神様が鎮座する場所が「産土神社」です。神社庁が住所の割り振りで決めるものとは異なり、「魂の神縁による産土神社」は人によって（あるいは兄弟でも）異なるオンリーワンの神社です。

### 探すための手順
1. **生誕地の住所特定**
   * 母親があなたを妊娠して5～6ヶ月の時期に住んでいた家の住所（一時的な里帰り先や病院の住所ではない）を特定します。町名まで判明すれば大丈夫です。
2. **地図による神社候補の選定**
   * 判明した住所から直線距離で**半径約4キロメートル圏内**の神社をすべてピックアップします。
   * **産土神社になりにくい神社**：創建年代の浅い明治以降の神社（北海道は例外）、御霊神社・護国神社・靖国神社等（武将や民間人が主祭神）、稲荷神社、無人の小さな祠。
   * **候補になりやすい神社**：江戸時代以前に創建された神社（式内社など歴史が古い）、地名と神社名が一致する神社、天満宮、地名に「宮」の字が入る神社、3キロ以上離れていても神威や社格の高い神社（一宮など）、鎮座地が移転していない神社。
3. **実際の参拝と「サイン」の感知**
   * 残ったすべての候補の神社を実際に参拝し、五感を働かせて気配を感じ取ります。
   * **歓迎のサイン（例）**：自然と涙が溢れる、温かく包まれる感覚、お宮参りや七五三の家族に出会う、太鼓の音が響く、祈りの際に手のひらが温かくなる、風がないのに紙垂が揺れる、虹や彩雲が出る、動物（鳥・蝶・カエル・ヘビ等）に出会う、良い香りが漂うなど。
   * **外すべき感覚**：何も感じない、嫌な感じがする、心が重い、悪臭がする、すぐに離れたくなる（ただし「社殿が粗末」「手水舎が無い」「境内が荒れている」は人間の管理の問題なので除外理由になりません）。心の状態が良い時に参拝し直すことも推奨されます。
4. **専門家への依頼**
   * 自力での特定が難しい、確信が持てない場合は、結界を張り神事によって魂の神縁に基づき見つけ出す鑑定士へ依頼するのも有効です。

## 3. 正しい参拝作法と心構え
神様との感応度を格段に上げ、絆を深めるための作法です。参拝は回数よりも「質」であり、感謝の心を捧げることが重要です。

* **鳥居から参道へ**：鳥居は神域への入口であり、一礼してくぐります（くぐる度に「祓われている」とイメージ）。参道の真ん中は神様の通り道なので端を歩き、横切る際は軽く一揖（お辞儀）して心で「失礼いたします」と唱えます。
* **手水（ちょうず）での清め（禊の略式）**：
   * 右手で柄杓を持ち左手を洗い、左手に持ち替えて右手を洗います。再度右手で柄杓を持ち、左手に水をためて口をすすぎ、最後に柄杓の柄を洗い流します。
   * 手水舎がない場合（あるいは水が汚れている場合）は、「祓戸大神様（はらえどのおおかみさま）」をお呼びして「とってもありがたい祓戸大神我を祓え給い清め給え」とゆっくり2回唱えて代用します。
* **お賽銭**：神様は金額自体には興味がありません。お賽銭を捧げるときの心の状態や日頃のお金の使い方を知っているため、静かに丁寧に納めることが重要です。
* **二拝二拍手一拝**：お辞儀2回、拍手2回、最後にお辞儀1回の挨拶の作法。特に「拝」は上体が地面と平行になるくらいまで深くゆっくりと行い、拍手もしっかりと心地よい音を出します。
* **祈り詞（いのりことば）**：
   * 初回は名前・生年月日・干支・住所を伝えて自己紹介をします。
   * **自身の開運だけでなく、神様と神社のいやますますのご開運を祈る**ことが非常に重要です。
   * 祈りの例：「わが産土の大神様をはじめ、○○神社におわします大神様のいやますますのご開運をお祈り申しあげます。いつもお守りいただきまして、ありがとうございます。」
* **視線と姿勢**：目をしっかりと開けて正面のご神鏡（または御扉）を見据え、穏やかな微笑みをたたえます。合わせた手のひらも指先を正面に向け、みぞおちから30cm手前に少し突き出し、胸の直霊大神様（なおひのおおかみさま）から光の道が本殿へ届くイメージを持ちます。重い念ではなく、肩の力を抜いた「軽やかな思い」を込めます。
* **参拝の終わり**：祈りの後に再度、二拝二拍手一拝で丁寧な締めくくりを行い、静かに神域を立ち去ります。
* **正式参拝（年1回推奨）**：守護力・開運力を大幅にアップしたい場合は、年に一度、拝殿内で神職が祝詞を奏上する正式参拝を受け、神恩感謝を捧げることが推奨されます。

## 4. 日常の習慣と心構え（人と神様の相互扶助の関係）
神様からの後押しや、守護神様の数（応援）を増やすためには、日々の習慣が重要です。人間と神様は一方的に与える関係ではなく、相互に助け合っている関係です。

* **感謝と素直な心**：神様は努力を惜しまず、素直な心と感謝の思いを大切にしている成功者を好んで後押しします。
* **波動の高い言葉遣い**：「言霊（ことだま）」に魂が宿るとされるように、神様は波動の高い言葉を好みます。特に「ありがとうございます」「おめでとうございます」といった感謝・賞賛の言葉を十音で発することは天照大神様の波長に同調することにも繋がります。
* **「軽やかさ」と笑顔の追求**：神様は高い波動である「軽やかさ」を好みます。笑顔で過ごす人は高い波動を発しており神様との波長が共鳴しやすくなるため、意識的に笑う時間を増やすよう心がけます。
* **掃除と整理整頓**：開運の土台は掃除（自分で自宅を掃除する）です。部屋を清潔に保ち埃を掃うことは「心の祓い」にもなり自己の運気を高めます。
* **お金の扱い方**：お金にも意思が宿ります。「人に喜んでもらえる」ためにお金を使い、支払い義務のあるものは期日を守り「気前よく、すぐに支払う」ことで、循環がよくなりお金の神様にも好かれ金運アップと後押しが得られます。
* **ご先祖様との絆（母方の菩提寺）**：霊的な世界では母親の影響が色濃く出るとされ、母方の菩提寺は自身の重要な霊的ルーツです。母方のお墓参りや菩提寺への参詣は、自身の守護強化、開運、そしてご先祖様のご開運にも直結します。神仏を陰と陽として大切にします。
* **人間による神様への手助け（相互扶助）**：人間からの「感謝の祈り」は神様のエネルギー源となりパワーアップさせます。また、目に見えない世界は神仏が担当しますが、現実の清掃などは人間の行動（手助け）が必要です。さびれた神社は単なる放置ではなく、神様からの「清掃など協力を頼むSOS」だと捉えて行動します。

## 5. 神様ネットワークと参拝優先順位
産土神様は他の神様との縁を繋ぐ強力な「神様ネットワーク」を持っています。

* **鎮守神社（ちんじゅじんじゃ）**：産土神社が遠方にある場合は、現在住んでいる場所の近くにあり「日常生活全般を司る」鎮守神社に参拝することで、親戚のような間柄である産土神様と繋がれます。複数と縁を結べるため、引っ越し先・職場・学校の近くの神社も対象になります。
* **参拝の優先順位**：①産土神社（最も最重要）、②鎮守神社、③現在住んでいる地域を統括する「一宮・総社・総鎮守」、④有名な神社
* **有名神社に行く前のルール**：神威の高い有名神社へ行く前に、まず自分の産土神社や鎮守神社へ参拝し「紹介してもらうようお願い」することで、参拝先で特別待遇で歓迎され、願いが届きやすくなります。

## 6. おみくじやサインを通じた導き
* 神様は常に私たちを見守りサインを送っています。本書のように「産土神様」というテーマに触れること自体も導きの一つです。
* **おみくじとご神託**：誰でも受け取れる神様からのメッセージ（ご神託）がおみくじです。吉凶に一喜一憂するのではなく、書かれているメッセージを読み解くことが重要です。引く前に「今の私にメッセージをお願いします」と祈念し、結果は持ち帰って大切に保管します。
* **お守り（授与品）**：お守りはコレクションではなく「内符」が入った神聖なものです（開けて穢れを入れてはいけない）。「買う」のではなくお金を「奉納」して「授かる」ものであり、それによって神社の開運を助けることにもなります。

## 7. 用語集
過去項目に登場していない重要語句を中心とする。
* **産土神様（うぶすながみさま） / あなた担当の神様**：一人ひとりに生まれつき割り当てられ、生涯にわたってその人を見守り、守護し、人生のガイドとなる、固有の名前を持たない大自然の大神。
* **産土神社（うぶすなじんじゃ）**：産土神様が鎮座するオンリーワンの神社。魂の神縁によって決まる。
* **鎮守神社（ちんじゅじんじゃ）**：自宅、勤務先の職場、学校の近くなどに存在し、日常生活全般を司る神様。産土神社が遠方の場合の代替となり、複数と縁を結べる。
* **神縁（しんえん）**：神様との縁。魂の神縁は個人の魂のルーツに基づいて決定される。
* **ご神託（ごしんたく）**：霊感が強い人に限らず、おみくじ等を通して誰でも受け取れる神様からのメッセージやアドバイス。
* **神事（しんじ） / 結界（けっかい）**：産土神社の鑑定士が清浄な部屋に境界を作り、神事によって神様と繋がりながら調べる作業。
* **祓い（はらい） / 手水（てみず） / 禊（みそぎ）**：心身の穢れや災いを清める（外清浄および内清浄）行為の略式。
* **祓戸大神様（はらえどのおおかみさま）**：祓いを司る神様。手水舎が使えない場合やホテルの部屋などを清める際にお呼びする。
* **直霊大神様（なおひのおおかみさま）**：人間の胸のあたりに宿る内なる神様（一霊四魂）。
* **ご神鏡（ごしんきょう） / 御扉（みとびら）**：神様と相対する際に見つめる対象の鏡や扉。指先をこちらへ向け光の道をつくる。
* **祈り詞（いのりことば）**：自己紹介と、神様への感謝、神様・神社自身のご開運をお祈りする言葉。
* **念当たり（ねんあたり）**：有名なパワースポットなどで、ご利益目当ての重い我欲の念が溜まり、敏感な人が体調を崩す現象。
* **一宮（いちのみや） / 総社（そうしゃ） / 総鎮守（そうちんじゅ）**：旧国や地域を統括するレベルの格式の高い神社。
* **内符（ないふ） / 授与品（じゅよひん）**：頒布されるお守り。中身（内符）を開けて穢れを入れてはいけない。
* **言霊（ことだま） / 波動（はどう） / 軽やかさ**：言葉や人が持つエネルギー。神様は波動が高い（穏やか、笑顔、感謝）ものを好む。
* **神恩感謝（しんおんかんしゃ） / 初穂料（はつほりょう） / 祝詞（のりと）**：正式参拝時に納める料金とその際の奏上言葉。祈願がない場合は神恩感謝を捧げる。
