# /fal-setting — 設定の作業台 起動（Claude Code 用）

このコマンドは Antigravity 版 `/fal-setting` と同一の手順書を参照します。
実体は `.agents/` 側にあり、ここでは重複させません（手順書の唯一の情報源を1箇所に保つため）。

1. `.agents/workflows/fal-setting.md` を読み込み、その手順に厳密に従うこと

2. 手順書の指示どおり `.agents/skills/fal-setting-workbench/SKILL.md` を読み込み、以後はその手順・形式・HARD-GATE に従うこと

3. やりたいこと：$ARGUMENTS
   - 渡されている場合は、そこから**5つの作業**（新規作成／書き換え・深掘り／整合チェック／削除・統廃合／反映）のどれかを見分けて進むこと
   - 空の場合は、手順書の規定どおり「今日はどれをしますか」と1問だけ尋ねること

4. ⚠️⚠️ **書き込んでよい先と、書かない先を取り違えないこと**
   - 書いてよい＝`02_設定/` ／ `00_作品コンセプト＆トータル設定/` ／ `01_free_memo/` の作品メモ
   - ⚠️ **書かない＝`brainstorm/` と `synopsis/` の中のファイル**（HARD-GATE）。食い違いは**報告だけ**する
   - ⭐ `02_設定/` に書けるのは、このコマンドと `/fal-cleaning` の2つだけ。**門番**として振る舞うこと
   - ⚠️ あらすじの一文そのものを直したいと言われたら `/fal-brainstorm` に返すこと

5. **Claude Code 固有：選択肢の出し方は2通り。⭐使い分けること**
   ⚠️⚠️ **`AskUserQuestion`（窓）は、答えた瞬間に選択肢の中身が消える。**比べる材料を窓の中に入れないこと

   **(A) テキストで出す** … ⭐ **中身を比べる場面は、必ずこちら**
   - 対象＝案そのもの（4〜6案＋逆張り案1個）／設定を変える案（何が変わる／何が困る／どこが混乱する）／
     足かせの3行／**整合チェックの報告**／**削除前の参照元の一覧**／選択肢が5つ以上になるとき／チェックの一覧
   - `A)` `B)` `C)` … で本文に並べ、**記号・番号・名前のどれで答えてもよい**と添えること
   - ⭐ 並べ方は `- **A)** …` の**箇条書き。**⚠️ 全角スペースで字下げしない（行が繋がる）
   - ⭐ 会話に残るので、あとから読み返せる。複数選ぶときは「AとC」で受けること

   **(B) `AskUserQuestion`（窓）で出す** … 軽い分岐だけ
   - 対象＝「次に何をするか」／はい・いいえ／**短い選択肢が3つ以下**で、説明がほぼ要らないとき
   - ⚠️⚠️ **窓の中の説明（description）は1行・30字まで。**超えるものは窓の前の本文に書き、窓は**見出しだけ**にすること
   - ⚠️ 迷ったら (A)。窓を使うのは「軽い」と確信できるときだけ

   共通
   - ⭐おすすめを必ず先頭に置くこと
   - ⚠️ **1ターンに出せる質問は1つだけ**（複数の質問を並べない）

6. ⚠️⚠️ **Claude Code 固有：答えは、そのままだと文字の固まりになる。形で読みやすくすること**
   （詳しくは `.agents/skills/fal-setting-workbench/SKILL.md` の「出し方の形」）
   - **まとまりの区切りに、必ず空白行を1つ入れること** … `【いま】` ／ `【受けた】` ／ `直す場所`＋`狙い` ／
     案の並び ／ `⭐おすすめ`〜`足かせ` ／ `質問`
   - ⚠️⚠️ **改行を1つ入れただけでは、前の行と繋がって表示される。**空白行が要る
   - **案は1件ずつの箇条書きにすること** … `- **1｜〈案の中身〉**` ＋ 入れ子の `- → 〈話がどう変わるか〉`
   - **ラベルの付いた行も `- **ラベル**：` の箇条書きにすること** … `直す場所` `狙い` ／ 決めたあとの4つ ／
     整合チェックの報告 ／ 参照元の一覧 ／ 足かせの3行
   - ⚠️ **全角スペースで字下げしないこと。**字下げは表示に効かず、行が繋がる
   - ⚠️ 案の番号は**これまでどおり付ける**（⭐おすすめで指すため）。⭐ 番号を振らない決まりは「直す場所の指し方」の話
   - ⭐ **1行は2文まで。**3文を超えたら、中身を削るか、行を分けること

7. ` ```text ` ブロックに入れるのは、**そのままファイルに入る文だけ**にすること（コピーしやすいように）
   - ⚠️ **案・報告・一覧をブロックに入れないこと。**⭐ 本文に箇条書きで書く（→ 6）

8. **Claude Code 固有：ファイルの作成・編集は `Write` / `Edit` ツールを使う**
   - ⚠️ `cat > ファイル << EOF` のヒアドキュメントは、許可設定の前方一致に当たらず毎回確認を求められる
   - 検索・確認は `Read` / `Grep` / `Glob`、集計や一括置換は `python -` を使う

9. **Claude Code 固有：削除・統廃合の前の参照元の洗い出しは `Grep` で行うこと**（HARD-GATE）
   - **ファイル名**と、**その中の固有名（人物名・場所名・道具名）**の両方を引くこと
   - 結果は**ファイルパスと該当行**をテキストで一覧にして提示し、承認を得てから消すこと
   - ⚠️ **1件も出なかった場合も「参照は見つかりませんでした」と明示すること**（黙って消さない）

10. **Claude Code 固有：書き換えたあとの波及確認も `Grep` で行うこと**
   - 変えた固有名・数字・言い回しを引き、`02_設定/` の他ファイル・一覧ファイル・`00_` の用語集と食い違わないか見ること
   - ⚠️ `brainstorm/` `synopsis/` に食い違いが出たら、**報告だけ**にすること（直さない）

11. **Claude Code 固有：チェックの一覧は、テキストの `- [ ]` 一覧で出す**
   - 「どこを決定にするか」「一区切りの確認」「**この矛盾のどれから直すか**」は、マークダウンの `- [ ]` 一覧を本文に出し、**記号・番号・名前で答えてもらう**こと
   - ⭐ **先頭に「全部このまま決定する」を置くこと**
   - ⭐ 例外：**項目が3つ以下で、どれも一言で済むとき**は `AskUserQuestion` の `multiSelect: true` を使ってよい（⚠️ 説明は1行・30字まで）
   - ⭐ **決定が承認されたら、`Edit` / `Write` でその場で直すこと。**⚠️ **承認される前に直さない**
   - ⚠️⚠️ **AI が思いついた設定を通すために、選択肢を使ってはならない。**⭐ AI 由来のものは、選択肢に出すときも「**⚠️ AI の思いつきです**」と明記すること

12. **Claude Code 固有：ほかのワークフローへ渡す道は、その回の選択肢に1つ混ぜてよい**
   - 渡し先は `/fal-brainstorm`（案を増やす・あらすじの文を直す）／`/fal-twist`（仕掛け・伏線）／`/fal-synopsis`（あらすじの骨子）／
     `/fal-cleaning`（要らない設定が多い・ファイルが長すぎる）
   - 選ばれたら、**このセッションのまま**渡し先の `SKILL.md` を `Read` で読み込んで続けること。⚠️ **コマンドを打ち直させない**
   - ⚠️ いまの内容をそのまま持ち込む（**貼り直させない**／**新しい状態ファイルを作らない**）
   - ⚠️ 勝手に渡らない。⚠️ 1ターンに渡す選択肢は1つまで

13. **Claude Code 固有：チャットモード**
   - 「次に何をするか」を訊く `AskUserQuestion` に、**チャットモードを選択肢として必ず1つ入れること**
   - 選ばれたら、**このセッションのまま**形式をやめてふつうに会話すること。⚠️ **コマンドを打ち直させない**
   - 入ったら `01_free_memo/fal用メモ/` の中を `Read` で読むこと … `fal用_作品案メモ①〜⑤.md` ／ `fal用_雑メモ.md` ／ `fal用_機能修正用メモ.md`
   - ⭐ **メモに書き足すときの先は、`fal用_作品案メモ` の中身のある一番大きい番号。**長くなってきたら次の番号へ（⚠️ 番号は飛ばさない／⚠️ 常に①〜⑤の5本を置いたままにする）
   - ⚠️⚠️ **`fal用_機能修正用メモ.md` を読んでも、ワークフローを勝手に直さないこと**
   - 戻る指示（`戻る` `ワークフローに戻る` `案を出して`）が来たら、**その場でワークフローに戻ること**

14. **全出力は日本語。**ターミナル操作が必要な場合は UTF-8 強制を前置すること
    （`[Console]::OutputEncoding = [System.Text.Encoding]::UTF8; $env:PYTHONUTF8=1`）

15. ⚠️ **`/fal-plot`（仮）は、まだ作っていない。選択肢に入れないこと**
