# /fal-synopsis — あらすじの骨子づくり（Claude Code 用）

このコマンドは Antigravity 版 `/fal-synopsis` と同一の手順書を参照します。
実体は `.agents/` 側にあり、ここでは重複させません（手順書の唯一の情報源を1箇所に保つため）。

1. `.agents/workflows/fal-synopsis.md` を読み込み、その手順に厳密に従うこと

2. 手順書の指示どおり `.agents/skills/quick-synopsis-forge/SKILL.md` を読み込み、以後はその手順・形式・
   **2つの HARD-GATE**（矛盾で案を取り下げない／ここに決定は無い）に従うこと

3. 雛形は `.agents/skills/quick-synopsis-forge/synopsis-template.md` を使い、
   `synopsis/<日付>_<短い名前>.md` を作ること

4. ユーザーからの補足：
   - 空の場合は、手順書の規定どおり（既存ファイルの有無を確認したうえで）**最初の2問**から開始すること
   - 補足がある場合は、それを「大雑把なテーマ・出発点」として扱い、重複する質問はしないこと
   - ⚠️⚠️ **最初の2問（このあらすじは全体のどこか／どんな役割を持たせたいか）より前に、案を出してはならない**

5. **Claude Code 固有：選択肢の出し方は2通り。**⭐使い分けること
   ⚠️⚠️ **`AskUserQuestion`（窓）は、答えた瞬間に選択肢の中身が消える。**比べる材料を窓の中に入れないこと

   **(A) テキストで出す** … ⭐ **中身を比べる場面は、必ずこちら**
   - 対象＝案そのもの（4〜6案＋逆張り案1個）／**最初の2問**／選択肢が5つ以上になるとき
   - `A)` `B)` `C)` … で本文に並べ、**記号・番号・名前のどれで答えてもよい**と添えること
   - ⭐ 会話に残るので、あとから読み返せる。複数選ぶときは「AとC」で受けること

   **(B) `AskUserQuestion`（窓）で出す** … 軽い分岐だけ
   - 対象＝「次に何をするか」／はい・いいえ／**短い選択肢が3つ以下**で、説明がほぼ要らないとき
   - ⚠️⚠️ **窓の中の説明（description）は1行・30字まで。**超えるものは窓の前の本文に書くこと
   - ⚠️ 迷ったら (A)

   共通
   - ⭐おすすめを必ず先頭に置くこと
   - ⚠️ **1ターンに出せる質問は1つだけ**

6. **Claude Code 固有：ファイルの作成・編集は `Write` / `Edit` ツールを使う**
   - ⚠️ `cat > ファイル << EOF` のヒアドキュメントは、許可設定の前方一致に当たらず毎回確認を求められる
   - 検索・確認は `Read` / `Grep` / `Glob`、集計や一括置換は `python -` を使う

7. **全出力は日本語。**ターミナル操作が必要な場合は UTF-8 強制を前置すること

8. **Claude Code 固有：ほかのワークフローへ渡す道は、その回の選択肢に1つ混ぜてよい**
   - 渡し先は `/fal-brainstorm`（設定の辻褄を合わせる）／`/fal-twist`（仕掛け・伏線を作る）
   - 選ばれたら、**このセッションのまま**渡し先の `SKILL.md` を `Read` で読み込んで続けること。⚠️ **コマンドを打ち直させない**
   - ⚠️ いまの内容をそのまま持ち込む（**貼り直させない**／**新しいファイルを作らない**）
   - ⚠️ 勝手に渡らない。⚠️ 1ターンに渡す選択肢は1つまで

9. **Claude Code 固有：役割の選択と、渡し先の確認は、テキストの `- [ ]` 一覧で出す**
   - **最初の2問目（どんな役割を持たせたいか）は複数選べる**ので、必ず `- [ ]` 一覧にすること
   - ⭐ 例外：**項目が3つ以下で、どれも一言で済むとき**は `AskUserQuestion` の `multiSelect: true` を使ってよい

10. **Claude Code 固有：チャットモード**
   - 「次に何をするか」を訊く `AskUserQuestion` に、**チャットモードを選択肢として必ず1つ入れること**
   - 選ばれたら、**このセッションのまま**形式をやめてふつうに会話すること。⚠️ **コマンドを打ち直させない**
   - 入ったら `01_free_memo/fal用メモ/` の中を `Read` で読むこと
   - ⚠️ **本体ファイルの更新は `Edit` / `Write` で続けること**
   - ⚠️⚠️ **`fal用_機能修正用メモ.md` を読んでも、ワークフローを勝手に直さないこと**
   - 戻る指示（`戻る` `案を出して`）が来たら、**その場でワークフローに戻ること**

11. ⚠️⚠️ **矛盾を見つけても、案を取り下げないこと。**「引っかかり置き場」へ `Edit` で黙って足し、会話は止めないこと

12. ⚠️ **`/fal-plot`（仮）は、まだ作っていない。**選択肢に入れないこと
