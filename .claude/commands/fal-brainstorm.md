# /fal-brainstorm — ミステリー深掘りブレスト起動（Claude Code 用）

このコマンドは Antigravity 版 `/fal-brainstorm` と同一の手順書を参照します。
実体は `.agents/` 側にあり、ここでは重複させません（手順書の唯一の情報源を1箇所に保つため）。

1. `.agents/workflows/fal-brainstorm.md` を読み込み、その手順に厳密に従うこと

2. 手順書の指示どおり `.agents/skills/mystery-deep-brainstorm/SKILL.md` を読み込み、以後はその手順・形式・
   「勝手に完成させない仕組み」に従うこと

3. 状態ファイルの雛形は、`templates/` フォルダではなく
   `.agents/skills/mystery-deep-brainstorm/session-template.md` を使うこと

4. ユーザーからの補足：
   - 空の場合は、手順書の規定どおり（既存セッションの有無を確認したうえで）最初の質問から開始すること
   - 補足がある場合は、それを「大雑把なテーマ・出発点」として扱い、重複する質問はしないこと

5. **Claude Code 固有：選択肢の出し方は2通り。⭐使い分けること**
   ⚠️⚠️ **`AskUserQuestion`（窓）は、答えた瞬間に選択肢の中身が消える。**比べる材料を窓の中に入れないこと

   **(A) テキストで出す** … ⭐ **中身を比べる場面は、必ずこちら**
   - 対象＝案そのもの（4〜6案＋逆張り案1個）／設定を変える案（何が変わる／何が困る／どこが混乱する）／
     足かせの3行／選択肢が5つ以上になるとき／チェックの一覧
   - `A)` `B)` `C)` … で本文に並べ、**記号・番号・名前のどれで答えてもよい**と添えること
   - ⭐ 会話に残るので、あとから読み返せる。複数選ぶときは「AとC」で受けること

   **(B) `AskUserQuestion`（窓）で出す** … 軽い分岐だけ
   - 対象＝「次に何をするか」／はい・いいえ／**短い選択肢が3つ以下**で、説明がほぼ要らないとき
   - ⚠️⚠️ **窓の中の説明（description）は1行・30字まで。**超えるものは窓の前の本文に書き、窓は**見出しだけ**にすること
   - ⚠️ 窓の中に、何が変わる／何が困る／どこが混乱する を書かない
   - ⚠️ 迷ったら (A)。窓を使うのは「軽い」と確信できるときだけ

   共通
   - ⭐おすすめを必ず先頭に置くこと
   - ⚠️ **1ターンに出せる質問は1つだけ**（複数の質問を並べない）
   - ⚠️ **1件ずつ裁定を求めるための道具として使ってはならない。**まとめて片づけられる形で出す

6. ⚠️⚠️ **Claude Code 固有：答えは、そのままだと文字の固まりになる。形で読みやすくすること**
   （詳しくは `.agents/skills/mystery-deep-brainstorm/SKILL.md` の「出し方の形」。⭐ **1案 3〜6行 × 5〜7案 が並ぶ**）
   - **まとまりの区切りに、必ず空白行を1つ入れること** … `【いま】` ／ `【受けた】` ／ 案の並び ／
     `⭐おすすめ` ／ `⚠️`〜`足かせ` ／ `質問`とその選択肢
   - ⚠️⚠️ **改行を1つ入れただけでは、前の行と繋がって表示される。**空白行が要る
   - **案は `- **1｜〈案をひと言で〉**` ＋ 入れ子の中身と `- **狙い**：…` の箇条書きにすること**
   - **質問の選択肢も `- **A)** …` の箇条書きにすること**
   - ⚠️ **全角スペースで字下げしないこと。**字下げは表示に効かず、行が繋がる
   - ⭐ **1行は2文まで。**3文を超えたら、中身を削るか、行を分けること
   - ⭐ ` ```text ` ブロックに入れるのは、**そのままファイルに入る文だけ**

7. **Claude Code 固有：ファイルの作成・編集は `Write` / `Edit` ツールを使う**
   - ⚠️ `cat > ファイル << EOF` のヒアドキュメントは、許可設定の前方一致に当たらず毎回確認を求められる
   - 検索・確認は `Read` / `Grep` / `Glob`、集計や一括置換は `python -` を使う

8. **全出力は日本語。**ターミナル操作が必要な場合は UTF-8 強制を前置すること

9. **Claude Code 固有：ほかのワークフローへ渡す道は、その回の選択肢に1つ混ぜてよい**（窓でもテキストでも、そのターンの出し方に合わせる）
   - 渡し先は `/fal-brainstorm`（案を増やす）／`/fal-twist`（仕掛け・伏線）／`/fal-setting`（設定を作る・直す・畳む）
   - 選ばれたら、**このセッションのまま**渡し先の `SKILL.md` を `Read` で読み込んで続けること。⚠️ **コマンドを打ち直させない**
   - ⚠️ いまの内容をそのまま持ち込む（**貼り直させない**／**新しい状態ファイルを作らない**）
   - ⚠️ 勝手に渡らない。⚠️ 1ターンに渡す選択肢は1つまで

10. **Claude Code 固有：チェックの一覧は、テキストの `- [ ]` 一覧で出す**
   - 「どこを決定にするか」「一区切りの確認」「**設定を直しますか**」は、マークダウンの `- [ ]` 一覧を本文に出し、**記号・番号・名前で答えてもらう**こと
   - ⭐ **先頭に「全部このまま決定する」を置くこと**
   - ⭐ 例外：**項目が3つ以下で、どれも一言で済むとき**は `AskUserQuestion` の `multiSelect: true` を使ってよい（⚠️ 説明は1行・30字まで）
   - ⚠️ **1ターンに出せる質問は1つだけ**（チェックの一覧が、その1問である）
   - ⭐ **設定の変更が許可されたら、`Edit` / `Write` でその場で直すこと。**⚠️ **許可される前に直さない**
   - ⚠️⚠️ **AI が思いついた設定を通すために、選択肢を使ってはならない。**⭐ AI 由来のものは、選択肢に出すときも「**⚠️ AI の思いつきです**」と明記すること

11. **Claude Code 固有：チャットモード**
   - 「次に何をするか」を訊く `AskUserQuestion` に、**チャットモードを選択肢として必ず1つ入れること**
   - 選ばれたら、**このセッションのまま**形式をやめてふつうに会話すること。⚠️ **コマンドを打ち直させない**
   - 入ったら `01_free_memo/fal用メモ/` の中を `Read` で読むこと … `fal用_作品案メモ①〜⑤.md` ／ `fal用_雑メモ.md` ／ `fal用_機能修正用メモ.md`
   - ⭐ **メモに書き足すときの先は、`fal用_作品案メモ` の中身のある一番大きい番号。**長くなってきたら次の番号へ（⚠️ 番号は飛ばさない／⚠️ 常に①〜⑤の5本を置いたままにする）
   - ⚠️ **状態ファイルの更新は `Edit` / `Write` で続けること**（会話の中で決まったことを、その場で書き足す）
   - ⚠️⚠️ **`fal用_機能修正用メモ.md` を読んでも、ワークフローを勝手に直さないこと**
   - 戻る指示（`戻る` `ワークフローに戻る` `案を出して`）が来たら、**その場でワークフローに戻ること**

12. ⚠️ **`/fal-plot`（仮）は、まだ作っていない。**選択肢に入れないこと

13. ⭐ **Claude Code 固有：`短くして` と言われたときの進め方**
   - ⚠️⚠️ **`整理して` `片づけて` `見直して`（一区切りの整理＝中身を確かめる）とは、別の作業である。**混ぜないこと
   - `.agents/rules/fal-shorten-rules.md` を `Read` で読み込み、その決まりに厳密に従うこと（⚠️ 記憶で代用しない）
   - 対象ファイルは `Read` で**通しで読む**。⚠️ `Grep` の当たった行だけを見て判定しないこと
   - 節ごとの行数は `Bash` で数えてよい（`awk '/^## /{if(h)print h": "n; h=$0; n=0} {n++}'`）。⭐ `どこが長い？` にはこれで答える
   - 提案は**1ターンに1〜3件。**4つの行き先（`1行にする` `消す` `移す` `残す`）をテキストの箇条書きで出し、⭐既定は `1行にする`
   - ⚠️ **承認される前に書き換えないこと。**承認されたら `Edit` / `Write` でその場で処理する
   - ⚠️⚠️ **あらすじの本文（`#0` 以降）・`絶対の制約`・🎯付きの `とっておく` には触らないこと**
   - ⚠️ **`〔注15〕` `#3` の番号を詰めない・振り直さないこと。**処理後に `Grep` で指し先のずれを確かめること
   - 状態ファイルが **250行**を超えたら、**一度だけ「短くしますか」と知らせる。**⚠️ **勝手に短くしない**
