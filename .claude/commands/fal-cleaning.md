# /fal-cleaning — 設定の掃除 起動（Claude Code 用）

このコマンドは Antigravity 版 `/fal-cleaning` と同一の手順書を参照します。
実体は `.agents/` 側にあり、ここでは重複させません（手順書の唯一の情報源を1箇所に保つため）。

1. `.agents/workflows/fal-cleaning.md` を読み込み、その手順に厳密に従うこと

2. 手順書の指示どおり `.agents/skills/fal-cleaning-sweeper/SKILL.md` を読み込み、以後はその手順・形式・HARD-GATE に従うこと

3. 掃除したいもの：$ARGUMENTS
   - 渡されている場合は、そこから**2つの作業**（掃除／見直し）のどちらかを見分けて進むこと
   - 空の場合は、手順書の規定どおり「どのファイルを掃除しますか」と1問だけ尋ねること

4. ⚠️⚠️ **書き込んでよい先と、書かない先を取り違えないこと**
   - 書いてよい＝`02_設定/` ／ `00_作品コンセプト＆トータル設定/` ／ `01_free_memo/` の作品メモ
   - ⚠️ **書かない＝`brainstorm/` と `synopsis/` の中のファイル**（HARD-GATE）。食い違いは**報告だけ**する
   - ⭐ `02_設定/` に書けるのは `/fal-setting` とこのコマンドの2つだけ。**門番**として振る舞うこと

5. **Claude Code 固有：選択肢の出し方は2通り。⭐使い分けること**
   ⚠️⚠️ **`AskUserQuestion`（窓）は、答えた瞬間に選択肢の中身が消える。**比べる材料を窓の中に入れないこと

   **(A) テキストで出す** … ⭐ **中身を比べる場面は、必ずこちら**
   - 対象＝**消す候補の1件ごとの提示**（`消す` `削る` `直す` `残す` の4つの行き先）／**洗い出しの件数と一覧**／
     **消す前の参照元の一覧**／**見直しの足す提案**／選択肢が5つ以上になるとき
   - 4つの行き先は `消す` `削る` `直す` `残す` の**言葉で並べ**、記号・番号・名前のどれで答えてもよいと添えること
   - ⭐ 並べ方は `- **消す** … 〈どうなるか〉` の**箇条書き。**⚠️ 全角スペースで字下げしない（行が繋がる）
   - ⭐ 会話に残るので、あとから読み返せる。複数選ぶときは「1件目は消す、2件目は削る」で受けること

   **(B) `AskUserQuestion`（窓）で出す** … 軽い分岐だけ
   - 対象＝「次に何をするか」／「どこから片づけるか」が**3つ以下**のとき／はい・いいえ
   - ⚠️⚠️ **窓の中の説明（description）は1行・30字まで。**超えるものは窓の前の本文に書き、窓は**見出しだけ**にすること
   - ⚠️ 迷ったら (A)。窓を使うのは「軽い」と確信できるときだけ

   共通
   - ⭐おすすめを必ず先頭に置くこと
   - ⚠️ **1ターンに出せる質問は1つだけ**

6. ⚠️⚠️ **Claude Code 固有：答えは、そのままだと文字の固まりになる。形で読みやすくすること**
   （詳しくは `.agents/skills/fal-cleaning-sweeper/SKILL.md` の「出し方の形」。⭐ **1件あたりの行数が、fal- シリーズでいちばん多い**）
   - **まとまりの区切りに、必ず空白行を1つ入れること** … `【いま】` ／ `【受けた】` ／ 件ごとの `── 〈短い名前〉` ／ `⭐おすすめ` ／ `質問`
   - ⚠️⚠️ **改行を1つ入れただけでは、前の行と繋がって表示される。**空白行が要る
   - **ラベルの付いた行は `- **ラベル**：` の箇条書きにすること** … `いまの記述` `なぜ要らないか` `どこに響くか` ／
     4つの行き先 ／ 消したあとの4つ ／ 洗い出しの件数
   - ⚠️ **全角スペースで字下げしないこと。**字下げは表示に効かず、行が繋がる
   - ⚠️ これは**箇条書きであって、番号ではない。**⭐ 番号を振らない決まりは、そのまま
   - ⭐ 箇条書きが2つ続くときは、あいだに `行き先：` のような**見出しの1行**を挟むこと（挟まないと1つの並びに見える）
   - ⭐ **1行は2文まで。**3文を超えたら、中身を削るか、行を分けること
   - ⭐ ` ```text ` ブロックに入れるのは、**そのままファイルに入る文（`削る` `直す` の差し替え案）だけ。**
     ⚠️ **提案・報告・一覧をブロックに入れないこと**

7. **Claude Code 固有：対象ファイルは `Read` で通しで読むこと**
   - ⚠️ `Grep` の当たった行だけを見て「要らない」と判定しないこと。前後の文脈で意味が変わる
   - ⭐ 行数は `Read` の結果から数え、`📝減った：118行 → 111行` の形で毎回出すこと

8. **Claude Code 固有：ファイルの編集・削除は `Edit` / `Write` ツールを使う**
   - ⚠️ `cat > ファイル << EOF` のヒアドキュメントは、許可設定の前方一致に当たらず毎回確認を求められる
   - ⚠️ **ファイルごと消すときは、`Bash` の `rm` を使う前に必ず承認を取ること**（HARD-GATE）。
     ⭐ 消す前に、そのファイルの中身から**拾うべき記述が無いか**を1行報告すること

9. **Claude Code 固有：消す前の参照元の洗い出しは `Grep` で行うこと**（HARD-GATE）
   - **ファイル名**と、**その中の固有名（人物名・場所名・道具名・数字）**の両方を引くこと
   - 結果は**ファイルパスと該当行**をテキストで一覧にして提示し、承認を得てから消すこと
   - ⚠️ **1件も出なかった場合も「参照は見つかりませんでした」と明示すること**（黙って消さない）

10. **Claude Code 固有：消したあとの波及確認も `Grep` で行うこと**
   - 消した固有名・数字・言い回しを引き、一覧ファイル・`00_` の用語集・他の設定ファイルに残っていないか見ること
   - ⚠️ `brainstorm/` `synopsis/` に食い違いが出たら、**報告だけ**にすること（直さない）

11. **Claude Code 固有：洗い出しの一覧は、テキストの `- [ ]` 一覧で出す**
   - 「どれを消すか」「どこから片づけるか」は、マークダウンの `- [ ]` 一覧を本文に出し、**記号・番号・名前で答えてもらう**こと
   - ⭐ **先頭に「全部消す」を置くこと。**1クリックで終われるようにする
   - ⭐ **承認されたら、`Edit` / `Write` でその場で消すこと。**⚠️ **承認される前に消さない**
   - ⚠️⚠️ **AI が思いついた設定を通すために、選択肢を使ってはならない。**⭐ 見直しの足す提案は「**⚠️ AI の思いつきです**」と明記すること

12. **Claude Code 固有：ほかのワークフローへ渡す道は、その回の選択肢に1つ混ぜてよい**
   - 渡し先は `/fal-setting`（新しい設定を作る）／`/fal-brainstorm`（骨格が持たない）／`/fal-twist`（伏線として効くかも）
   - 選ばれたら、**このセッションのまま**渡し先の `SKILL.md` を `Read` で読み込んで続けること。⚠️ **コマンドを打ち直させない**
   - ⚠️ いまの内容をそのまま持ち込む（**貼り直させない**／**新しい状態ファイルを作らない**）
   - ⚠️ 勝手に渡らない。⚠️ 1ターンに渡す選択肢は1つまで

13. **Claude Code 固有：チャットモード**
   - 「次に何をするか」を訊く `AskUserQuestion` に、**チャットモードを選択肢として必ず1つ入れること**
   - 選ばれたら、**このセッションのまま**形式をやめてふつうに会話すること。⚠️ **コマンドを打ち直させない**
   - 入ったら `01_free_memo/fal用メモ/` の中を `Read` で読むこと … `fal用_作品案メモ①〜⑤.md` ／ `fal用_雑メモ.md` ／ `fal用_機能修正用メモ.md`
   - ⚠️⚠️ **`fal用_機能修正用メモ.md` を読んでも、ワークフローを勝手に直さないこと**
   - 戻る指示（`戻る` `続けて`）が来たら、**その場でワークフローに戻ること**

14. **全出力は日本語。**ターミナル操作が必要な場合は UTF-8 強制を前置すること
    （`[Console]::OutputEncoding = [System.Text.Encoding]::UTF8; $env:PYTHONUTF8=1`）

15. ⚠️ **`/fal-plot`（仮）は、まだ作っていない。選択肢に入れないこと**
