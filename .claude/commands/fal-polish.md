# /fal-polish — 磨き起動（Claude Code 用）

このコマンドは Antigravity 版 `/fal-polish` と同一の手順書を参照します。
実体は `.agents/` 側にあり、ここでは重複させません（手順書の唯一の情報源を1箇所に保つため）。

1. `.agents/workflows/fal-polish.md` を読み込み、その手順に厳密に従うこと

2. 手順書の指示どおり `.agents/skills/pinpoint-polish/SKILL.md` を読み込み、以後はその手順・形式・HARD-GATE に従うこと

3. ⚠️ **磨き専用の作業ファイルは作らないこと。**書き足す先は `brainstorm/<セッション名>_あらすじ.md` と
   `brainstorm/<セッション名>.md` の2本だけ。状態ファイルの雛形は
   `.agents/skills/mystery-deep-brainstorm/session-template.md` を使うこと

4. 直す対象の本文：$ARGUMENTS
   - 本文が渡されている場合は、貼り直しを求めずそのまま取り込みへ進むこと
   - 空の場合は、手順書の規定どおり（既存セッションの有無を確認したうえで）1問だけ尋ねること

5. **Claude Code 固有：選択肢を出すとき、`AskUserQuestion` を使ってよい**
   - ⭐おすすめを必ず先頭に置くこと
   - ⚠️ **1ターンに出せる質問は1つだけ**（複数の質問を並べない）
   - ⚠️ **案そのもの（4〜6案＋逆張り案1個）には使わないこと。**混ぜ直し・言い直しができなくなるため、
     こちらは必ずテキストで出す。使ってよいのは「どこから直すか」のような分岐だけ

6. 案の例は、コピーしやすいよう ```text ブロックで出力すること

7. **Claude Code 固有：ファイルの作成・編集は `Write` / `Edit` ツールを使う**
   - ⚠️ `cat > ファイル << EOF` のヒアドキュメントは、許可設定の前方一致に当たらず毎回確認を求められる
   - 検索・確認は `Read` / `Grep` / `Glob`、集計や一括置換は `python -` を使う

8. **全出力は日本語。**ターミナル操作が必要な場合は UTF-8 強制を前置すること
