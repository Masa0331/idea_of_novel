# /fal-polish — ピンポイント磨き上げ起動（Claude Code 用）

このコマンドは Antigravity 版 `/fal-polish` と同一の手順書を参照します。
実体は `.agents/` 側にあり、ここでは重複させません（手順書の唯一の情報源を1箇所に保つため）。

1. `.agents/workflows/fal-polish.md` を読み込み、その手順に厳密に従うこと
2. 手順書の指示どおり `.agents/skills/pinpoint-polish/SKILL.md` を読み込み、以後はその手順・フォーマット・HARD-GATEに従うこと
3. 作業ファイルの雛形は、`templates/` フォルダではなく `.agents/skills/pinpoint-polish/polish-sheet-template.md` を使うこと
4. 磨く対象の本文：$ARGUMENTS
   - 本文が渡されている場合は、貼り直しを求めずそのままフェーズ0の取り込みへ進むこと
   - 空の場合は、手順書の規定どおり（既存の `*_polish.md` の有無を確認したうえで）1問だけ尋ねること
5. **Claude Code 固有：** 2〜4択の分岐（「🔧修正／🔍深掘り／✅終了」、保存先フォルダの確認、タイトルの承認）には
   `AskUserQuestion` を使ってよい。ただし **6案＋ワイルドカード2案の選択肢リストには使わないこと**
   （選択肢数が上限を超え、`3+5合` のような合成指定もできなくなるため。こちらは必ず番号付きテキストで出す）
6. 選択肢と枠指定の記法例は、コピーしやすいよう ```text ブロックで出力すること
7. 保存先フォルダを尋ねるときは、`Glob` などで**プロジェクト内の実在フォルダを確認してから**候補を並べること
   （存在しないフォルダを提案しない）
