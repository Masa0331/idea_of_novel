## 3. 特殊設定・能力

| 用語                   | 説明                                                                                                                                                                                                                                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| シマハヤブサ           | ハヤブサの亜種（Falco peregrinus fruitii）。伊豆・小笠原諸島の固有亜種で、学術的には絶滅扱い。隼の母・ラーテンはシマハヤブサの最後の一羽だった。                                                                                                                                                 |
| 変身                   | 隼はシマハヤブサに変身できる。ただしハヤブサとして過ごす時間は人間の約3倍の速度で消費される。人間に戻る際は裸になる。                                                                                                                                                                            |
| ハヤブサモード         | 人間の状態のままハヤブサの能力を使うこと。元は亜紀人が面白がって命名した。隼自身は「ゲームみたいで嫌だ」と難色を示したが、結局わかりやすさに負けて現在では自らも渋々使っている。感覚・神経を人間離れした領域にまで高められるが、使用後は激しい筋肉痛や神経痛が生じる。                           |
| 加速する時間感覚       | 鳥類特有の高い時間分解能。ハヤブサモード時は人間時の1秒が約3秒に感じられ、周囲がスローモーションのように見える。                                                                                                                                                                                 |
| 探偵ガジェット         | 亜紀人（および望）が製作する探偵用の特殊道具。ハヤブサ時に使う鳥用小型電話機、網捕獲器などがある。                                                                                                                                                                                               |
| カナリア               | 亜紀人特製の超高感度有害ガス検知器。ハヤブサの弱点である有毒ガスから身を守るため、隼の腕時計バンドや亜紀人のスマートグラスに極小モジュールとして組み込まれている。                                                                                                                               |
| 鳥の言葉               | 隼は鳥の言葉を話せる唯一の人間。野鳥の仲間たちと会話し、情報収集に活用する。                                                                                                                                                                                                                     |
| PTFE（テフロン）中毒   | テフロン加工の調理器具が高温で発するガスにより、鳥類は致命的なダメージを受ける。隼にとって日常に潜む深刻な弱点。                                                                                                                                                                                 |
| 揮発性化学物質への過敏 | 隼は鳥類由来の呼吸器構造を持つため、アロマオイル・香水・殺虫剤などの人工的な香りに対して強い不快感と健康被害を受ける。                                                                                                                                                                           |
| 隼眼（しゅんがん）     | ハヤブサのように鋭い眼光・眼力を意味する熟語。「鷹眼（ようがん）」が広範囲を俯瞰する威厳を表すのに対し、「隼眼」は**一点に標的をロックオンするスピード感と一点突破の鋭さ**というニュアンスが強い。ミステリーにおける「犯人の嘘を見抜く一瞬の目」「決定的な証拠を見つける眼力」の表現として最適。 |
| 隼視（しゅんし）       | ハヤブサが獲物を狙って鋭く見下ろすこと。転じて、油断なく鋭い目つきで見回すこと。「周囲を隼視する」のように動詞的にも使用できる。                                                                                                                                                                 |
| 人相術（観相学）       | 顔や体の特徴から性格や運勢を読み解く占術。天川光の得意分野であり、専門的な書籍資料に基づいた深い洞察力を要する。                                                                                                                                                                                 |
