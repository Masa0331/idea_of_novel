# 世界観設定（ワールドセッティング）

## 時間軸

* **現代（2026年9月〜秋）**
  * 「2026年基準」として物語が進行する。

## 舞台・地理設定

物語は、千葉県に実在する流山市をモデルとした架空の市**「千葉県流丘（ながれおか）市」**を中心として進行する。

### 1. 流丘市（ながれおかし）
* 千葉県北西部に位置する。都心へのアクセスが良く、近年はファミリー層のベッドタウンとして人口が増加しているという設定。
* 緑と水辺の豊かな自然環境が残る地域でもあり、野鳥も多く生息する。

### 2. 流丘おおたかの郷（さと）駅周辺
* **ショッピングモール**: 天川光が占いブースを出店している場所。

### 3. ハヤブサ探偵事務所と周辺
* **ハヤブサ探偵事務所**: 流鉄流丘線「流丘駅」近くの古い雑居ビル3Fにある。
* **たんぱくキッチン**: 同ビル1Fにある軽食屋。隼と亜紀人が行きつけ。

### 4. 江戸川土手内側沿い / 農耕地帯
* 流丘市から少し離れた（あるいは外れの）自然豊かな場所。
* マロンやモンブラン姉弟の縄張り近く（武蔵野線鉄橋あたり）。
* 近くには空き地と畑が広がり、野焼きが行われている。
* 物語劇中、シャーリーン（天川の猫）が捕獲された場所であり、善場の小屋（キトンミル現場）が建っている。

### 5. オオタカ山 / オオタカの丘
* モデルは三輪野山。
* 地域最強の猛禽である「女王（オオタカ）」の縄張りとして知られる。
* 放火事件のあった小屋から北東へおよそ1kmほど離れた高台の丘。

### 6. 流丘小川公園 / 坂川水辺公園林
* モデルは野々下水辺公園。人気の少ない丹下があり、隼たちがアカメなどハヤブサ飛行隊の訓練場所として活用する。

### 7. その他
* **望の工房**:
  * 閉店した電気屋を改装して使用している作業場。アナログ的・手工業的なエリアAと、デジタルな開発系のエリアBに分かれている。
* **ドローンに関する法規制**:
  * 千葉県および流丘市においては、2020年代からドローンに対する法規制・条例やプライバシー保護の観点が非常に厳しくなっている。探偵業務での安易な使用は「違法行為」と見なされる環境下にある。詳細は[ドローン使用に関する法規制と探偵業務への影響](ref/ref_drone_regulations.md)を参照。
* **探偵業法と警察連携**:
  * 探偵業法に基づく遵守事項や、警察（特に流丘署）との微妙な協力・対立関係が、執筆上の重要な制約・背景となっている。詳細は[探偵業法・警察連携に関する総合資料（実務・法的制約・倫理）](references/02_法律・業界・倫理/探偵業法と警察連携.md)を参照。
