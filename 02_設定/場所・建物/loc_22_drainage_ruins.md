# 旧国営野田排水機場跡（きゅうこくえいのだはいすいきじょうあと）

特定の廃墟がモデルというわけではないのですが、**利根川・江戸川流域の治水事業の歴史に基づいた、極めて説得力のある設定の場所**です。

* **おおよその位置**: 江戸川河川敷、「旧流丘橋（初代流丘橋）の橋脚跡」からさらに上流（野田方面）へ1kmほど進んだ、サイクリングロードからも外れた葦原（あしはら）の奥深くに位置する。ハヤブサ探偵事務所からは、自転車で約15分の距離。  
* **設定詳細**: 昭和30年代、周辺の田畑を水害から守るために作られたコンクリート製の小さな排水機場。より大規模な治水設備ができたことで役目を終え、数十年が経ち、今は蔦に覆われた廃墟となっている。巨大な錆びたポンプや、折れ曲がった鉄パイプが剥き出しになっており、どこか不気味で退廃的な雰囲気を漂わせている。ほとんど人が立ち入らないため、サギやクイナといった警戒心の強い水鳥の隠れ家となっている。  
* **物語上の役割**:  
  * **ミステリアスな舞台**: 廃墟ならではの雰囲気は、密談や死体の遺棄場所など、サスペンス展開の舞台として非常に魅力的です。隼が鳥の仲間たちと秘密の会合を開く場所としても機能します。  
  * **差別化とリアリティ**: 利根運河の「明治のロマン」を感じさせるレンガ造りとは対照的な、「昭和の無骨な産業遺産」という明確な差別化ができます。地域の治水の歴史に基づいた設定のため、物語にリアリティを与えます。  
  * **視覚的インパクト**: コンクリートと錆びた鉄、そしてそれらを覆う緑というビジュアルは、読者に強い印象を残し、物語の記憶に残る風景となります。
