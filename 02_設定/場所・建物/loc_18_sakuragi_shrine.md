# 櫻木神社（さくらぎじんじゃ）※実在神社

* **コンセプト**: **日常と非日常が交差する「境界の神社」** 多くの人々が訪れる明るい雰囲気の裏で、登場人物たちの知られざる悩みや、事件に繋がる人間模様が交錯する舞台。  
* **所在地**: 千葉県野田市桜台。  
* **地理とアクセス**: 最寄り駅は東武アーバンパークライン「野田市駅」。ハヤブサ探偵事務所からは車や電車で20分程度。大きな駐車場を備え、野田市民だけでなく広域から多くの参拝客が訪れる。  
* **景観と雰囲気**: 広く明るい境内は常に手入れが行き届いており、清潔で開放的な雰囲気。その名の通り**桜がシンボル**であり、春には様々な種類の桜が咲き誇り、多くの花見客で賑わう。社殿や社務所も比較的新しく、特にトイレは「日本一美しいトイレ」とも称されるほど綺麗に管理されている。  
* **祭神と信仰**:  
  * **主祭神**: 倉稲魂命（ウカノミタマノミコト）など、生活に根ざした神々。  
  * **ご神木**: 境内の中央付近に、樹齢数百年とされる**大杉**がそびえ立っている。注連縄（しめなわ）が巻かれたその幹は力強く、訪れる人々に静かな畏敬の念を抱かせる。  
  * **厄割石（やくわりいし）**: 境内の一角にあり、参拝客に人気のスポット。「厄玉」と呼ばれる素焼きの玉に自身の厄や災いを息で吹き込み、この石に投げつけて割ることで災厄を祓うとされる 。  
  * **御朱印**: 季節ごとにデザインが変わる美しい御朱印が有名で、桜の時期には限定の御朱印を求めて遠方から参拝客が訪れるほど人気が高い。  
  * **境内社**: **川屋神社（かわやじんじゃ）**。トイレの神様として知られ、健康や安産にご利益があるとされる 。  
* **物語上の役割と活用アイデア**:  
  * **情報の交差点**: 多様な参拝客が集まるため、聞き込みや人間観察の舞台となる。亜紀人が、絵馬や人気の**御朱印**を求める人々の列を観察し、事件の背景にある人間模様や地域の動向を読み解く。  
  * **伏線の舞台**: 「最も見過ごされやすい場所（トイレ）」に証拠が隠されていたり、健康志向の堀口店長が**川屋神社**に熱心に参拝している姿が、後のアリバイ証言に繋がったりする。  
  * **キャラクターの内面描写**: 絶望した人物（例えば優真）が、わらにもすがる思いで**厄割石**に厄玉を叩きつけるシーン。涙の代わりに感情を物理的に解放するその行為を、別の登場人物が目撃してしまう…といった展開で、キャラクターの深い内面を描写できる。
