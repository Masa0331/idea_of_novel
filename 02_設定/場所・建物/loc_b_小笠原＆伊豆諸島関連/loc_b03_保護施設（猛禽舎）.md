> ⭐⭐⭐**設計の芯＝「この施設は、鳥を人から切り離すために作られている」。**野生に返すために、人に慣れさせてはいけないからである。

## 基本情報

* **名称**: **小笠原希少鳥類保護増殖施設**
* **通称・略称**: **猛禽舎**（正しくは施設の中の一棟の名前だが、島の人も職員も施設全体をこう呼ぶ）／**保護センター**
* **種類**: 野生鳥類の保護・治療・繁殖・終生飼養をおこなう施設。**国の保護増殖事業の枠組みで運営され、実務の一部が民間の自然保護団体へ委託されている**
* **所在地・立地**: **父島の山手、集落から車で十数分。**⚠️**わざと人の来ない場所にある。**観光ルートからも外れており、案内看板も小さい。⭐**鳥を人に慣れさせないことが、この施設のいちばん大事な仕事だからである**
  * 敷地は**戦時中の施設跡地を転用**したもの。地面をならすとコンクリートの基礎が出てくる。

## 構造・設備

### 敷地の構成

* **管理棟**（事務室・記録室・処置室・餌の保管庫）
* **治療舎**（運び込まれた直後の個体を診る。獣医が本土から定期的に来る）
* ⭐**隔離舎** … 保護してすぐの個体を入れる小さな部屋。**暗く、静かで、人が立ち入らない**
* ⭐⭐**猛禽舎（終生飼養舎）** … **野生に返せないと判断された個体を、一生ここで飼うための棟**
* ⭐⭐⭐**飛翔訓練用の細長いケージ** … 返せる見込みのある個体を飛ばして鍛える。⚠️**この設備は二十年後に効く**（→「歴史・曰く」の最後）
* **一般の見学者は敷地に入れない。**年に数回の公開日と、学校の見学だけが例外

### ⭐⭐⭐ 猛禽舎の構造（本作の心臓部）

* **外側は板張りで、外から中は見えない。**金網をむき出しにすると鳥が羽を傷めるので、**内側は目の細かい布で覆ってある。**
* ⭐**のぞき窓がある。**⚠️**担当者だけのものではない。**調査で出入りする者は開けてよい。
  * ⚠️**ただし、長く見ることは慎まれる。**⭐**人の顔を覚えさせないためである。**用が済んだら閉じて離れる、というのがこの施設の作法である。
  * **餌は外から給餌口を通して入れる。**——**中に入らずに世話ができるように作ってある。**
* ⭐⭐**板壁のいちばん下に、換気と排水のための細い隙間がある。**
  * ⚠️**この隙間から、六歳の子どもが中をのぞける高さにある。**
  * ⭐⭐⭐**二十年後、同じ隙間の前に立つと、しゃがまなければ見えない。**——**あの日の目の高さを、もう失っている。**
* **鍵**：⭐**棟ごとに鍵がかかる。**調査で出入りするNPOの担当者は**合鍵を預かっている**（→ 閉館後でも入れる理由はこれ）
* **個体票**：⭐⭐⭐**ケージの外側に、その個体の札が下がっている。**種名・保護した日・保護した場所・状態・担当者名が書いてある。**中は見えなくても、札はいつでも読める。**

### 設備・セキュリティ

* 夜間は無人になる。**常駐の宿直はいない。**
* 電気柵や監視カメラはない。**盗む人間がいないので、鍵だけで足りている。**
* ⚠️**猫よけの柵はある。**島では野生化した猫が最大の脅威で、雛はまず猫にやられる。

## 人間関係・歴史

* **所有者・管理者**: 国（保護増殖事業）と東京都・小笠原村。**日々の運営は自然保護団体（NPO）へ委託されている**
* **主な関係者・居住者**:
  * **時風誠一郎** … NPOの調査員として、**六年間、週に4〜5日ここへ出入りしていた。**
    * ⚠️**猛禽舎の担当ではなかった。**だが**見る用があれば、のぞき窓を開けてよい立場**にはあった。
    * ⭐⭐⭐**つまり彼は、見ようと思えば見られた。**⚠️**そして実際に、何度も見ている。**——**それでも、確かめなかった。**
    * ⭐**来るたびに、あの札の前を通った。**⚠️**そこに書かれている「近縁亜種の迷鳥」という一行は、彼自身が書いたものである。**
  * **ラーテン** … 弱ったハヤブサとして運び込まれ、**野生に返せないと判断されて、この猛禽舎で六年を過ごした**
  * **弟と妹（ラーテンの子）** … ⭐**檻の中で生まれた二羽。**弟は飛べるようになり、⚠️**妹はまだ雛で飛べなかった**
  * **時風隼** … 六歳のとき、父に連れられて一度だけここへ来た。
    * ⚠️**彼は中を見ていない。**⭐⭐⭐**檻の鳥の声が聞こえたから、「あの鳥はおかあさんだ」と言った。**
    * ⚠️**父は、息子が鳥の言葉を分かることを知らなかった。**だから六年、誰も気づかなかった。
  * **職員たち** … ⚠️**誰も悪いことをしていない。**決まりを守り、鳥のためを思って判断している。**それでもこうなった、という書き方をする**
  * **柏木稔** … ⚠️**本土（流丘市）の職員なので、ここに常駐はしていない。**父島を訪ねたときに、誠一郎に案内されてこの施設を見ている
* **歴史・曰く**:
  * ⭐⭐⭐**「終生飼養」の決定** … ラーテンは治療のあと、**野生に返せないと判断された。**その決定書にも、**保護した本人として誠一郎の名前が載っている。**⚠️**彼は、妻をこの島に閉じ込める書類に、二度署名したことになる**（登録票と、この決定書）。
  * ⭐⭐⭐**檻の中の番（つがい）** … 施設は**繁殖にも取り組んでいる。**その結果、**檻の中に番ができ、二羽の子が生まれた。**
    * ⚠️**三十年、誠一郎が探していたのは「まだどこかで卵を産んでいる番」だった。檻に入れる一羽ではなかった。**
    * ⭐⭐⭐**その番を、施設が檻の中に作ってしまった。**——**彼の三十年は、彼の職場で、いちばん残酷な形で叶えられた。**
  * ⭐⭐⭐**最後の夜（誰も逃がさなかった）**
    * ⚠️⚠️**檻は開け放たれていない。**⭐**弟と妹は、生まれてからずっと施設の中で育っている。野生には戻れない。**誠一郎もそれを知っていた。
    * ⭐⭐⭐**だから彼は、二羽を逃がさなかった。**——**外の世界を知らないまま、この檻の中で、小さな幸せを見つけて暮らしてほしい。**そう願って別れた。
    * ⭐**去りぎわに、彼は妹を一度だけ手のひらに乗せている。**外の闇を見て、**戻した。**
    * **彼が連れ出したのは、ラーテンだけである。**
  * ⚠️**施設の記録上、ラーテンがどうなったことになっているかは未確定**（→ 下の「要検討」）。
  * ⭐⭐⭐**そのあとの二羽** … **妹は、母が消えて二週間ほどで死んだ。**⚠️**弟については、記録に「その一年ほどのちに死亡」と書かれている。**
    * ⭐⭐⭐**だが、それは記録に書いてあることであって、事実ではない。**弟は**実際にはもっと長く生きた。**——**番になり、子を残し、その子に話を伝えるだけの時間があった。**
    * ⚠️**二十年後、隼は団体職員から「一年ほどで死んだ」と聞かされる。**⭐**職員は記録を伝えただけであり、悪意はない。**⚠️**記録と事実がずれた理由は未確定**（→ 下の「要検討」）
    * ⚠️**二羽は標本にされ、いまは父島の展示施設に置かれている。**ラベルには「**シマハヤブサの交雑亜種か**」とある。
    * ⭐⭐⭐**彼は妻を標本から守った。だが、その子どもたちが標本になった。**
  * ⭐⭐⭐**弟の子** … 弟が死ぬ前に、一羽だけ子が残っていた。
    * ⚠️**「交雑」と断定されたのではない。「近縁亜種」と判断された。**——**つまり、ただのハヤブサとして扱われた。**
    * ⭐**だから飛翔訓練用のケージで鍛えられ、訓練ののち、空へ放たれた。**
    * ⭐⭐⭐**母を檻に入れたのと同じ一行が、その孫を空へ返した。**⚠️**誠一郎はそれを知らずに死んでいる。**
    * ⭐**放たれた鳥は、いまも施設のあたりを飛んでいる。**——**檻の外にいるのに、檻のそばから離れない。**

## 物語上の役割

* **主な用途**:
  * **誠一郎の職場。**六年間、週に4〜5日通った場所。
  * **六歳の隼が、板壁の外で母の声を聞いた場所。**
  * **最後の夜、彼が二羽と別れた場所。**
  * ⭐**二十年後、隼が訪ねる場所。**——⚠️**檻は空いている。**⭐**そして、その上を一羽が飛んでいる。**
* **象徴するテーマ**:
  * ⭐⭐⭐**見られたのに、確かめなかった** … 「ファインダーの裏側を想像しろ」と言い続けた男が、**いちばん近くの檻の中だけは確かめなかった。**⚠️**見えなかったのではない。見なかったのでもない。**——**見ていて、なお、問わなかった。**⭐**だから逃げ場がない**
  * ⭐⭐**書類がないと、人としては生きられない。鳥としてなら、檻の中で生かしてもらえる** … 制度は彼女を、人としては助けられず、鳥としては助けた。⚠️**助けた結果が、六年の檻である**
  * ⭐⭐⭐**札は外にある** … 中は見えないのに、**名前だけはいつでも読める場所に下がっている。**⭐**彼は来るたびに、自分で書いた一行の前を通っていた**
  * ⭐⭐⭐**同じ一行が、母を閉じ込め、孫を自由にした** … 「近縁亜種」と書かれたから、母は貴重な個体として檻に入れられ、孫はただのハヤブサとして空へ返された。⚠️**貴重さが、そのまま不自由だった**
  * ⭐⭐**見えなかったものは、聞こえていた** … 大人にも子どもにも、中は見えない。⭐**それでも六歳には、声が届いた**
