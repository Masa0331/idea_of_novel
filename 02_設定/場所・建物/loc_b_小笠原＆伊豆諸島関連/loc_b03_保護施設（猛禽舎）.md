# 保護施設（猛禽舎）

> **📝 2026-08-24 全面設計しなおし。**⚠️**この施設は原作にも実在にも下敷きがほとんど無い。**そのぶん**本作の設定がいちばん活きる形に作り直した**（ユーザー指示・2026-08-24）。
> ⭐⭐⭐**設計の芯＝「猛禽舎は、中が見えないように作られている」。**野生に返すために、人に慣れさせてはいけないからである。
> ⭐⭐⭐**これで、誠一郎が六年間ここに通いながら妻に気づかなかったことに、物理的な理由がついた。**——**見なかったのではない。見ないのが、彼の仕事だった。**

---

## 基本情報

* **名称**: **小笠原希少鳥類保護増殖施設**（★2026-08-24 命名）
* **通称・略称**: **猛禽舎**（正しくは施設の中の一棟の名前だが、島の人も職員も施設全体をこう呼ぶ）／**保護センター**
* **種類**: 野生鳥類の保護・治療・繁殖・終生飼養をおこなう施設。**国の保護増殖事業の枠組みで運営され、実務の一部が民間の自然保護団体へ委託されている**
* **所在地・立地**: **父島の山手、集落から車で十数分。**⚠️**わざと人の来ない場所にある。**観光ルートからも外れており、案内看板も小さい。⭐**鳥を人に慣れさせないことが、この施設のいちばん大事な仕事だからである**
  * 敷地は**戦時中の施設跡地を転用**したもの。地面をならすとコンクリートの基礎が出てくる。

---

## 構造・設備

### 敷地の構成

* **管理棟**（事務室・記録室・処置室・餌の保管庫）
* **治療舎**（運び込まれた直後の個体を診る。獣医が本土から定期的に来る）
* ⭐**隔離舎** … 保護してすぐの個体を入れる小さな部屋。**暗く、静かで、人が立ち入らない**
* ⭐⭐**猛禽舎（終生飼養舎）** … **野生に返せないと判断された個体を、一生ここで飼うための棟**
* **飛翔訓練用の細長いケージ**（返せる見込みのある個体を飛ばして鍛える）
* **一般の見学者は敷地に入れない。**年に数回の公開日と、学校の見学だけが例外

### ⭐⭐⭐ 猛禽舎の構造（★2026-08-24 新設・本作の心臓部）

* **外側は板張りで、中は見えない。**金網をむき出しにすると鳥が羽を傷めるので、**内側は目の細かい布で覆ってある。**
* ⭐⭐⭐**のぞき窓は、担当者用に一つだけ。**それも普段は閉じている。**餌は外から給餌口を通して入れる。**——**中に入らずに世話ができるように作ってある。**
* **中に入っていいのは、その個体の担当者だけ。**⚠️**用もなく中を見るのは、この施設では「やってはいけないこと」である。**
* ⭐⭐**そのかわり、板壁のいちばん下に、換気と排水のための細い隙間がある。**
  * **大人はしゃがまないと見えない。**
  * ⭐⭐⭐**六歳の隼は、しゃがまなくても見えた。**
* **鍵**：⭐**棟ごとに鍵がかかる。**調査で出入りするNPOの担当者は**合鍵を預かっている**（→ 誠一郎が閉館後に檻を開けられた理由はこれ）
* **個体票**：⭐⭐⭐**ケージの外側に、その個体の札が下がっている。**種名・保護した日・保護した場所・状態・担当者名が書いてある。**中は見えないが、札はいつでも読める。**

### 設備・セキュリティ

* 夜間は無人になる。**常駐の宿直はいない。**
* 電気柵や監視カメラはない。**盗む人間がいないので、鍵だけで足りている。**
* ⚠️**猫よけの柵はある。**島では野生化した猫が最大の脅威で、雛はまず猫にやられる。

## 人間関係・歴史

* **所有者・管理者**: 国（保護増殖事業）と東京都・小笠原村。**日々の運営は自然保護団体（NPO）へ委託されている**
* **主な関係者・居住者**:
  * **時風誠一郎** … NPOの調査員として、**六年間ほぼ毎日ここへ出入りしていた。**⚠️**猛禽舎の担当ではなかった**（だから中を見る用がなかった）
  * **ラーテン** … 弱ったハヤブサとして運び込まれ、**野生に返せないと判断されて、この猛禽舎で六年を過ごした**
  * **弟と妹（ラーテンの子）** … ⭐**檻の中で生まれた二羽。**弟は飛べるようになり、⚠️**妹はまだ雛で飛べなかった**
  * **時風隼** … 六歳のとき、父に連れられて一度だけここへ来た。⭐**板壁の下の隙間から中を見て、「あの鳥はおかあさんだ」と言った**
  * **職員たち** … ⚠️**誰も悪いことをしていない。**決まりを守り、鳥のためを思って判断している。**それでもこうなった、という書き方をする**
  * **柏木稔** … ⚠️**本土（流丘市）の職員なので、ここに常駐はしていない。**父島を訪ねたときに、誠一郎に案内されてこの施設を見ている
* **歴史・曰く**:
  * ⭐⭐⭐**「終生飼養」の決定** … ラーテンは治療のあと、**野生に返せないと判断された。**その決定書にも、**保護した本人として誠一郎の名前が載っている。**⚠️**彼は、妻をこの島に閉じ込める書類に、二度署名したことになる**（登録票と、この決定書）。
  * ⭐⭐⭐**檻の中の番（つがい）** … 施設は**繁殖にも取り組んでいる。**その結果、**檻の中に番ができ、二羽の子が生まれた。**
    * ⚠️**三十年、誠一郎が探していたのは「まだどこかで卵を産んでいる番」だった。檻に入れる一羽ではなかった。**
    * ⭐⭐⭐**その番を、施設が檻の中に作ってしまった。**——**彼の三十年は、彼の職場で、いちばん残酷な形で叶えられた。**
  * ⭐**檻が開いた夜** … 閉館後、誠一郎が合鍵で猛禽舎を開け放った。ラーテンは一度だけ振り返って飛び、**飛べるようになっていた弟が続いた。**⚠️**妹は飛べず、檻に残った。**誠一郎は雛を手のひらに乗せて外へ出たが、**闇と猫を見て、檻に戻した。**
  * ⚠️**そして二十年、妹はこの猛禽舎にいる。**

## 物語上の役割

* **主な用途**:
  * **誠一郎の職場。**彼が六年間、毎日通った場所。
  * **六歳の隼が、板壁の隙間から母を見た場所。**
  * **檻が開いた夜の現場。**
  * ⭐**二十年後、隼が訪ねる場所。**——**妹がまだそこにいる。**
* **象徴するテーマ**:
  * ⭐⭐⭐**見ないのが正しい仕事だった** … 「ファインダーの裏側を想像しろ」と言い続けた男が、**いちばん近くの檻の中だけは想像しなかった。**⚠️**それは怠慢ではなく、職務だった。**⭐**だからこそ取り返しがつかない**
  * ⭐⭐**書類がないと、人としては生きられない。鳥としてなら、檻の中で生かしてもらえる** … 制度は彼女を、人としては助けられず、鳥としては助けた。⚠️**助けた結果が、六年の檻である**
  * ⭐⭐⭐**札は外にある** … 中は見えないのに、**名前だけはいつでも読める場所に下がっている。**⭐**誠一郎は毎日、「近縁亜種の迷鳥」と自分で書いた札の前を通っていた**
  * **大人には見えず、子どもには見えた** … ⭐**同じ壁の、同じ隙間である。**見えるかどうかを分けたのは、目の高さだけだった
