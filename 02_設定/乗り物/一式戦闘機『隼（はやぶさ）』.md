# 史実資料：一式戦闘機『隼（はやぶさ）』

## 1. 基本情報・スペック【実在】

大日本帝国陸軍が第二次世界大戦で運用した主力戦闘機。海軍の「零戦」と並び、当時の日本を代表する名機として知られる。

* **制式呼称**: キ43 ／ **制式名**: 一式戦闘機
* **愛称**: 隼（はやぶさ）
* **連合軍コードネーム**: **Oscar（オスカー）**
* **設計・製造**: 中島飛行機（設計主務：小山悌）
* **生産数**: 約5,700機以上。**陸軍機として最多。**開戦から終戦まで全戦域で主力として運用された

**主な特徴**

* **卓越した運動性能** … 「蝶型空戦フラップ」により、格闘戦（ドッグファイト）で極めて高い旋回性能を発揮した
* **長大な航続距離** … もともと**重爆撃機の長距離援護**を目的に開発されたため、広い空域を飛べた
* ⚠️**弱点も知られている** … 武装が軽く（機首の機関銃2挺が基本）、防弾も薄い。**初期には主翼の強度に起因する事故もあった。**⭐**「よく曲がるが、打たれ弱い」**——**この性格づけは、そのまま人物の比喩にも使える**

⚠️**混同しやすい点**：**「隼」は陸軍機、「零戦」は海軍機**である。小笠原・硫黄島は海軍のイメージが強いが、**陸軍も大規模に展開していた。**

## 2. 小笠原・伊豆諸島における運用【実在】

太平洋戦争末期、小笠原諸島は本土防衛の最前線として極めて重要な拠点となり、陸軍（小笠原兵団／第109師団）が大規模に展開した。**陸軍機である「隼」も、間違いなく伊豆・小笠原の空を飛んでいた。**

### 硫黄島への進出

* ✅**飛行第23戦隊は、千葉県を基地とし、帝都防衛を任務としていた部隊である。**
* ✅**1944年（昭和19年）11月、その第23戦隊が硫黄島へ進出した。**輸送船団の掩護と、来襲する米軍機への邀撃（迎撃）任務に就いている。**その作戦に「隼」が使われた。**
* ⭐**つまり「隼」は、千葉から飛んできて、小笠原の空で戦った機体である。**⚠️**本作の現在の舞台は千葉県流丘市**——**同じ空の続きに、あの機体が飛んでいた**

### 中継地としての伊豆諸島

* 本土（関東周辺）から小笠原方面へ向かう際、**伊豆諸島（青ヶ島・八丈島など）は重要な航空経路の中継地**だった。増援部隊の移動や哨戒任務で、**隼が伊豆諸島の上空を飛ぶことは日常的にあった。**

### 数字で見る当時の島【実在】

* ✅**1944年3月**、硫黄島へ陸軍4,000名以上が送られる
* ✅**1944年5月**、栗林忠道中将を長とする**第109師団**が編成される
* ✅**1944年8月までに、硫黄島に12,700名が集結。うち5,000名は父島から移された**
* ✅**1944年7月**、父島では**強制疎開が完了**（島民6,886名が本土へ／軍属825名が残留）
* ⭐**人が島から消え、兵と機体が入ってきて、そして両方とも去った。**（→ `場所・建物/父島の戦跡（塹壕・洞窟陣地）.md`）

## 3. ★★★ この機体の「名前」は、本作の主題そのものである【実在・最重要】

> ⭐⭐⭐**2026-08-22 に判明。ここが、この資料でいちばん使える部分である。**

### ✅ 事実：「隼」は、後から人がつけた名前である

* **本当の名は「キ43」、制式名は「一式戦闘機」。**
* ⚠️**だが 1942年（昭和17年）3月の一般公表にあたり、制式名「一式戦闘機」は伏せなければならなかった。**——軍の機密だったからである。
* **「新型戦闘機」では芸がない。**そこで**陸軍航空本部の報道官・西原勝少佐**が、愛称をつけることを発案した。
* ✅**1942年3月8日、「新鋭陸鷲、隼、現わる」の見出しで、各新聞に載った。**
* 名の由来は、**第64戦隊の部隊歌**の冒頭——**「エンジンの音 轟々と 隼は征く 雲の果て——」**
* 背景：当時の日本では、航空部隊に「鷲」「鷹」「隼」「翡翠」といった**鳥の呼び名**が盛んに使われており、**敵連合軍の「バッファロー」「ハリケーン」のようなニックネームが欲しい**という声もあった。
* ✅**加藤建夫少佐が率いた第64戦隊は「加藤隼戦闘隊」と呼ばれ、戦時中に映画化されて大ヒットした。**⭐**そのため、陸軍の「隼」は海軍の零戦よりも国民に知られた存在だった。**

### ⭐⭐⭐ 同じ機体に、三つの名がある

```text
書類の名 … キ43／一式戦闘機   ← 伏せなければならなかった
人の名  … 隼               ← 報道のために、あとからつけられた
敵の名  … Oscar            ← 向こうが勝手につけた
```

**そして、誰も書類の名では呼ばなかった。**

**◆ 東台所神社**
* **書類（村社申請）の祭神は「大己貴神」。**明治の国学者が当てはめた名である
* ⚠️**だが青ヶ島では、今日でも誰一人として祭神をオオナムチとは思っていない**

**◆ 石場宮の祠**
* **苔がのっていて、名が読めない。**⭐**苔をはがすと「ハヤムシ」と彫られている**

**◆ 保護施設の登録票**
* **書類の名は「近縁亜種の迷鳥」。**誠一郎が自分で書いた
* ⚠️**本当は、この世界に一羽だけ残ったシマハヤブサだった**

**◆ そして一式戦闘機**
