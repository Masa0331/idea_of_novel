# ドローントンビ

## 概要

平優真が自ら製作した、トビを精巧に偽装した特注ドローン。優真は事前に鍛冶屋望に依頼して作らせた「[ドローンキジバト](itm_18_drone_kijibato.md)」を分解・解析（リバースエンジニアリング）し、その基板からカスタムファームウェアや「ソアリング姿勢制御（ゆらぎ）プログラム」などの設定データ（ダンプデータ）を吸い出し、自身が購入したトンビ用の大型・高電圧対応のフライトコントローラーにコピー（フラッシュ）して流用した。
機械技術の専門家ではない優真にとって高度な制御システムの構築は本来困難であったが、キジバト製作の際に望から様々な鳥型ドローンのアイデアや仕様（特に滑空制御の構成）について情報を巧みに引き出していたことで、独力での完成にこぎつけた。外観の精巧なカモフラージュは、手先の器用な優真自身が手掛けている。

## 1. 基本スペック

**ベース機体**: クアッドコプター（マルチコプター）方式

### サイズ

| 部位 | 数値 | 備考 |
| ---- | ---- | ---- |
| 翼開長（全幅） | **約 155 cm** | 実物トビ（145〜165 cm）の中央値。目撃距離での違和感なしが条件 |
| 全長（頭部〜尾羽末端） | **約 65 cm** | 同上 |
| 全高（ホバリング時） | **約 15〜20 cm** | プロペラを外装シルエット内に収める制約から |

### 重量

| 構成要素 | 重量 |
| -------- | ---- |
| 機体外装（カーボンフレーム＋スタイロフォーム） | 約 350〜500 g |
| モーター×4 ＋ ESC ＋ プロペラ | 約 200〜300 g |
| フライトコントローラー ＋ GPS | 約 80〜120 g |
| FPVカメラ ＋ 映像送信機 | 約 60〜100 g |

| ペイロード（発火装置 ＋ LED偽装枝） | 約 150〜200 g |
| **総離陸重量（設計目標）** | **約 1.5〜2.0 kg** |

### 飛行性能・通信システム

| 項目 | 数値 | 備考 |
| ---- | ---- | ---- |
| 実用航続距離 | **約 10〜12 km** | 往復 8 km ＋ 現場滞空マージン 30% を確保した設計目標値 |
| 最大飛行時間 | **約 25〜30 分** | 巡航主体、ホバリング時間を含む |
| 巡航速度（オートパイロット時） | **約 40〜50 km/h** | 往路の GPS 自動航行区間 |
| 操縦・通信距離（RC リンク） | **最大 4 km** | ロングレンジ RC システムの限界値 |
| 映像伝送距離（デジタル FPV） | **最大 4 km** | オオタカ山〜目標エリア間の見通し線を活用 |
| 飛行中騒音（機体直下 1 m） | **約 75〜85 dB** | 洗濯機の脱水音（80 dB）・幹線道路沿い（75 dB）と同程度 |

> [!NOTE]
> **騒音の距離減衰・音質・スピーカーによるマスキングについて**
> 音圧は距離が 2 倍になるごとに約 6 dB 低下する。
> * **5 m 離れると**: 約 63〜73 dB ——エアコン室外機（60〜65 dB）・普通の会話（60〜65 dB）と同程度
> * **20 m 離れると**: 約 55〜65 dB ——静かなオフィス（60 dB）・閑静な住宅地（50 dB）と同程度
> * **100 m 以上**: 約 45 dB 以下 ——図書館内（40〜45 dB）以下となり、風音や環境音に埋もれやすい
>
> **音質**: 大型・低回転プロペラ特有の**中低音域の重いうなり音（ブォーン）**。ドローンスワローの高周波ジリジリ音とは対照的。周波数帯（約167〜333 Hz）はスズメバチやカナブンの羽音（約100〜200 Hz）と部分的に重なるが、音量（直下1mで75〜85 dB）が虫の羽音（20〜40 dB程度）と桁違いに大きく、有機的な揺らぎのない均一な機械音である点でも明確に異なる。近距離では「大型ラジコン機のモーター音」として認識され、「虫」と聞こえることはない。中低音域は距離による減衰が穏やかで遠くまで届きやすい反面、風音・葉擦れ音など環境の低周波ノイズに埋もれやすいという性質もある。
>
> **スピーカーによるマスキング**: 機体内蔵のスピーカーが再生するトビの鳴き声（ピーヒョロロロ）は、エンジン音の帯域を効果的に覆い隠す役割を果たす。地上から鳥を見上げた人間にとっては「鳴きながら飛ぶトビ」の印象が勝り、プロペラ音への注意が向きにくくなる。ただし真下・近距離では機械的なうなりも感知される。

> [!NOTE]
> 「操縦距離（最大 4 km）」と「航続距離（10〜12 km）」は別概念。今作戦では通信距離の制約が先に効くため、機体バッテリーには常に余裕がある設計になっている。

## 2. 機体構造と外装

| 部位           | 仕様                                                                                                                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **骨格**       | 軽量カーボンフレーム                                                                                                                                                                       |
| **胴体**       | スタイロフォーム削り出し。極めて軽量                                                                                                                                                       |
| **シルエット** | トビ特有の「翼先端が指のように分かれる形状」と「三味線のバチ型（M字/凹型）の尾羽」を忠実に再現                                                                                             |
| **羽根**       | シルエットが重要な翼先端・尾羽のフチには、本物のトビの羽根を移植。風を受けた際の「しなり」や逆光での透け感を実現。胴体部分は精巧なエアブラシ塗装＋マット塗料で不自然な光沢を消去 |
| **目**         | 半球状のガラス製カボションを埋め込み、内側から塗装。光を反射するリアルな眼球を再現                                                                                                         |

> [!NOTE]
> この羽根は「倫理的に入手」したものではない。善場が自分の敷地に侵入したトビを意図的に殺害し放置していた死骸を、優真が密かに回収して移植したものである。善場の犯罪の痕跡を直接「凶器」に転用したこの事実は、優真の復讐心の深さを象徴する重要な伏線。詳細は [evt_01_drone_tonbi_arson.md](../events/evt_01_drone_tonbi_arson.md) 参照。

## 3. 飛行制御と音響

* **飛行パターン**: フライトコントローラーに「ゆらぎ」プログラムを搭載。元々は望がドローンキジバト用に開発した、羽ばたきを最小限に抑えて風を捉え滑空する「ソアリング姿勢制御プログラム」だったが、優真は設定データをコピーした後、2kgのトンビの巨体に合わせて何度もテスト飛行と墜落を繰り返し、泥臭いトライ＆エラーによるパラメータ（ゲイン）の手動調整を重ねて適合させている。これにより、機体がわずかに左右に傾いたり高度を微妙に上下させ、風に乗っているかのような生物的な飛行パターン（帆翔飛行）を再現している。
* **鳴き声**: 機体内部に超小型MP3プレーヤーとスピーカーを内蔵。「ピーヒョロロロ…」という本物のトビの鳴き声を再生し、プロペラ音をカモフラージュ

## 4. 発火・投下装置

* **LED偽装枝**: カーボンファイバー芯＋発泡スチロール＋パテで本物の枯れ枝を再現。先端に高輝度オレンジ色LEDを埋込み、マイクロコントローラーで不規則に明滅（フリッカー）させ、遠目には燃える熾火に見せかける。サーボモーター式アームで懸架し遠隔で切り離し可能
* **投下物（発火装置）**: キャンプ用の炭や工業用の布に見せかけた「偽装運搬物」。内部に小型のニクロム線ヒーターと少量の着火剤が仕込まれている
* **投下装置**: 機体下部にサーボモーター式「解放アーム」を装備。上記の偽装運搬物を保持・投下する
* **照準・航法システム**:
  * **GPS自動航行**: 事前にターゲットのGPS座標を精密計測し、フライトコントローラーにプログラム→目標上空まで自動飛行
  * **FPV手動微調整**: 目標エリア直上（半径200〜300m）に到達後、FPVゴーグルでカメラ映像をリアルタイム確認しながら手動操縦に切替え。風などの影響を補正し、確実にホバリング
  * **操縦拠点**: オオタカ山（loc_12）。事件現場から直線距離約3〜4kmの高台。デジタルFPV映像伝送＋ロングレンジRCコントロールリンクの組み合わせにより、高台からの見通し線を活かした安定した遠距離操縦を実現。詳細は [evt_01_drone_tonbi_arson.md](../events/evt_01_drone_tonbi_arson.md) 参照。

## 5. 放火の手順（概要）

このドローントンビを用いた平優真の放火計画は、「鳥が野焼きの火を拾って運んだ」ように見せかける**劇場型犯罪**である。

1. **偽装飛行**: ドローンにLED偽装枝を懸架し、野焼きの煙のそばを飛行。上昇時にLEDを点灯させることで、目撃者に「トビが火のついた枝を拾った」と錯覚させる。
2. **通電→発火→投下**: 目標の上空でホバリングし、LEDの枝をこすりつけるような動作を見せる。その直後、優真が手元のスイッチを押すと、解放アームの接点ピンを経由してドローン本体のバッテリーからニクロム線に給電され、偽装炭の内部で一瞬赤熱・着火が始まる。内部燃焼が開始した直後にアームが開き、偽装炭が投下される。
3. **延焼**: 投下された偽装炭は表面が本物の燃えさしのように赤く見え始め、徐々に段ボールや農薬の容器へ延焼していく。切り離し後はドローンとの電気的接続が断たれるため、残留する電気的痕跡は最小限に抑えられる。

> [!NOTE]
> 犯行の全体計画（各機関の対応や捜査の流れなど）は [evt_01_drone_tonbi_arson.md](../events/evt_01_drone_tonbi_arson.md) を参照。

## 6. 隠しきれない「嘘」（＝物語上の伏線）

精巧な偽装をもってしても、専門家や注意深い観察者から見れば以下の決定的な欠陥が残る。

| 欠陥 | 詳細 |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **動かない頭** | 本物の鳥は飛行中も絶えず首を動かし警戒するが、ドローンは頭部が固定されたまま |
| **無反応な羽根** | 風を受けても個々の羽根が震えたり逆立ったりせず、全体が一枚の板のように動く |
| **機械的な飛行** | ゆらぎプログラムを組んでも、旋回時や回避時の動きは機械的な軌道を描く。トビ特有の上昇気流（サーマル）を使った無羽ばたき旋回は再現不可能。風がないのに垂直上昇、不自然なホバリングは鳥の生態を知る者には極めて異常 |
| **消せないプロペラ音** | 鳴き声でカモフラージュしても、風が止んだ瞬間や近距離では「ブォーン」という低周波の重いモーター音が聞こえてしまう |

## 7. 物語上の機能

*   **習性のカモフラージュ**: トビが野焼きの火や煙に驚き逃げ出す小動物を狙って集まるのは、農村地帯ではごくありふれた日常風景である。この「野焼きにはトンビが集まる」という自然の摂理を逆手に取ることで、不自然な空の動きを「通常の狩り行動」に紛れ込ませる完璧な計算が働いている
*   **隼の超感覚との連動**: 隼の常人離れした視力と聴覚が、「あのトンビ、一度も首を動かさなかった」「鳴き声の下に妙な羽音が混じっていた」という微細な違和感を捉え、事件の真相をこじ開ける鍵となる
*   **目撃証言の再検証**: 警察が田辺義男の証言を再検証する中で、「風もないのにスゥーッと真上に上がっていった」という些細な証言が事件の様相を一変させる
*   **物語テーマの象徴**: ドローントンビは、善場がSNSで見せる「善人面」と同じ構造。一見本物に見えるが、細部には隠しきれない嘘が滲み出ている。優真が作った「偽物の鳥」は、物語テーマ「仮面」そのものを体現する存在

## 8. 鳥キャラクターたちの反応

鳥たちは、亜紀人が作ったハヤブサ型ドローン（害鳥追い払い用。外見の出来はそれほど良くない）を知っている。だからこそ、平優真作の精巧なドローントンビを間近で見た時の違和感と嫌悪感は、より強烈なものとなる。

### 共通して感じる「生命感の欠如」

* **音が違う**: 羽ばたきや風を切る音ではなく、「ブォーン」という鈍く重低音のモーター駆動音が聞こえる
* **目が死んでいる**: どんなに精巧でも、目はただのガラス玉（カメラレンズ）。獲物を探す動きも、周囲を警戒する動きもなく、ただ一点を見つめるかのように動かない

### アブラーゲ（トビ）の反応：「冒涜的で、不愉快なやつ」

同族の姿をしているからこそ、最も強い嫌悪感を抱く。
* 翼の動きが全くないこと、風に乗るのではなく力任せに飛んでいることに、プライドを傷つけられたような怒りを感じる
* 「飛び方がなってない。風を読まず、力任せに飛んでいる。あれは空を飛ぶんじゃない、空を『進んでいる』だけだ。我々トンビへの冒涜だ！」
* **匂いの違和感にも気づく**（トビは腐肉食の傾向があり嗅覚が比較的発達している）。生き物の匂いが一切せず、代わりに油やプラスチックのような無機質な匂いがすることに不快感を覚える

### マロン（チョウゲンボウ）の反応：「気持ち悪い、虫みたいなやつ」

ホバリングの達人であるマロンは、ドローンの不自然な静止飛行に注目する。
* 「空中でピタリと止まるけど、羽を震わせるでもなく、奇妙な音を立てて浮かんでいる。生き物じゃない。大きな虫みたいで、とにかく気持ちが悪い！」
* 生物としての「魂」が感じられないことに気づく。「獲物を探す目をしていない」「ただ飛んでいるだけの張りぼて」

### 女王（オオタカ・メス）の反応：「腹立たしい、魂のないやつ」

森の王者にとって、すべての生き物は「狩るもの」か「争うもの」か「無視するもの」。しかしドローントンビはそのどれにも当てはまらない。
* 「威嚇しても反応がない。恐怖も敵意も感じられない。抜け殻だ。魂のない人形が私の空をうろついているのが腹立たしい」
* 獲物としての手応えのなさに苛立ちを感じる、不気味な存在として映る

## 9. 補足：本機体の実現可能性（リアリティ設定）

本機体は、オーバーテクノロジー（魔法のような謎技術）に頼らず、現代の民生用・自作ドローンのパーツ（FPVドローン界隈の標準的な技術）と物理法則の延長線上で構築された極めて現実的なガジェットである。平優真の執念と手先の器用さ、そして鍛冶屋望から盗み出した天才的な技術力が合わさることで成立している。

* **優真による内部構造・通信システムの構築（望の技術の盗用と執念）**:
  * **通信システムと制御プログラム**: 機械技術の専門家ではない優真にとってゼロからの構築は不可能だったが、望に作らせた「ドローンキジバト」の基板から設定データを吸い出し、自身で用意した大型機用（6S対応）のフライトコントローラーにフラッシュ（上書き）することで解決した。さらに、機体重量の違いによって発生する動作不良を、数え切れないほどの墜落と手動パラメータ調整で泥臭く克服している。また, キジバト製作の過程で望から鳥型ドローンの通信仕様やロングレンジ通信のアイデアを巧みに聞き出しており、それを元に既存のロングレンジFPV通信システム（ExpressLRS等）やデジタルFPVを組み込んだ。オオタカ山の高台から見通しを確保すれば数kmの通信は十分に可能であり、6S 5000mAhのバッテリー構成で30分弱の飛行時間も現実的である。
  * **投下・発火装置**: フライトコントローラーのAUXチャンネルを用いたサーボモーター制御や、リレー回路によるニクロム線発火は、ラジコンやモデルロケット愛好家の間では基礎的な技術であり、独学と望から得た知識の応用で優真にも実装可能であった。
* **優真による外装製作（カモフラージュ）**:
  * **重量とペイロード**: スタイロフォームと軽量カーボンフレームで外装を350〜500gに収めることは十分可能。
  * **外装のクオリティ**: 優真は自身の欠損した指の簡易エピテーゼ（義指）を自作できるほど手先が極めて器用。死骸から本物の羽根を回収し、軽量な胴体に移植・塗装を施すことで、遠目には本物と見紛うシルエットを作り出せる。
* **リアリティを補強する「限界（嘘）」**:
  「首が動かない」「羽が風になびかない」「無羽ばたき旋回（サーマル上昇）ができず機械的な軌道になる」「モーター音を消しきれない」といった、ドローンの物理的制約から来る欠陥が**あえて残されている**。これが物語上で鳥キャラクターたちの違和感（伏線）として機能し、ガジェットとしての説得力を極限まで高めている。
