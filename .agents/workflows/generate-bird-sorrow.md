# /generate-bird-sorrow ワークフロー

ユーザーが小説の原稿執筆中、指定（ハイライト等）した文章の箇所に、鳥のキャラクターの深い悲しみや喪失感、切なさを表現する身体描写を挿入したい場合に使用するワークフローです。

## 1. ヒアリング（情報が不足している場合）
基本的にはユーザーが対象箇所の文章を選択した状態でコマンドを実行します。しかし、もし提供された情報だけでは「どのキャラクターの感情か」「どのような原因の悲しみか（死別、敗北、孤独など）」が不明瞭な場合、AIは推測で無理に生成せず、まずヒアリングを行ってください。
- 「誰の、どのような悲しみ・喪失感を描写したいですか？」
など、短く簡潔に質問を投げかけます。

## 2. 参照ファイル
以下の設定ファイルを**必ず**読み込み、ルールを厳守してください。
- `05_references/00_文章表現・例文/ref_鳥の悲哀と切なさを描く身体描写例.md`
- `01_settings/style_guideline.md`

## 3. 生成のルール
- **擬人化の禁止**: 人間のように「涙を流す」「泣き崩れる」「肩を落とす」といった安易な擬人化表現は**絶対に使用しない**こと。
- **生態に基づく間接描写**: 結膜の充血、瞬膜の痙攣、羽毛を膨らませる、風切羽の乱れ、飛翔時の不自然な挙動、声の出ない喉の震え、浅い呼吸など、鳥類特有の身体的反応を通して感情を描写する。
- **トーン**: 特定の文体には固執せず、選択された前後の文脈（トーン）に自然に馴染むようにする。
- **間接的な悲哀**: 悲しみを直接「悲しい」と言葉にするのではなく、五感や身体の異変を通して読者に痛切さを伝えること。

## 4. 出力形式
前後の文脈を読み取り、AIが「最も効果的だと思われる身体の部位（目、翼、呼吸、飛翔など）」を**適宜判断**して、異なる切り口から**3〜5パターン**の例文を作成し、ユーザーに提案してください。

出力例（切り口のバリエーション）：
- 目の描写（充血や瞬膜）を中心にしたアプローチ
- 姿勢や羽毛（膨らみや震え）を中心にしたアプローチ
- 喉や呼吸（鳴けない苦しみ）を中心にしたアプローチ
- 飛翔や動作の乱れを中心にしたアプローチ

出力後、「どの身体表現が文脈に一番合いそうでしょうか？ さらに微調整することも可能です」とユーザーに問いかけ、対話を継続して完成形へと近づけてください。
