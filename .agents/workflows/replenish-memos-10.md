# メモファイル自動補充ワークフロー (10個版)

このワークフローは、`memo` フォルダ内のファイルを確認し、足りなくなっているメモファイル（`memo_01.md` から `memo_10.md` のうち存在しないもの）を検知して、自動的に補充作成するためのものです。

## 手順

// turbo-all

1. **対象ファイルの確認と作成**
   エージェントのツール（`run_command`によるPowerShellスクリプトの実行など）を使用して、`memo` フォルダ内に `memo_01.md` から `memo_10.md` までの10個のファイルが揃っているか確認し、足りないファイルのみを新しく作成してください。

2. **書き込む内容（免責事項）**
   新しく作成する各ファイルには、必ず以下の内容（文字列）をファイルの冒頭にそのまま書き込んでください。

   ```markdown
   > [!NOTE]
   > このファイルは小説執筆のためのアイデアを記したメモであり、決定事項ではありません。
   > AIがストーリー案を考える際などに参考にすることは推奨されますが、ここに書かれた内容に縛られる必要はなく、必要に応じて臨機応変に最も相応しい形へ改変・改良・修正してください。
   ```

3. **ユーザーへの報告**
   補充したファイル（例: `memo_03.md`, `memo_07.md`など）をユーザーに報告し、補充作業が完了した旨を伝えてください。
