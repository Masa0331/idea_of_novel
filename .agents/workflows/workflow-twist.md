# /twist — どんでん返し・叙述トリック錬成起動

1. `twist-trick-forge` スキル（SKILL.md）を読み込み、以後はその手順・フォーマット・HARD-GATEに厳密に従うこと
2. `brainstorm/` フォルダ内の既存ファイルを確認する
   - `*_tree.md` がある場合：「既存のブレストセッションに接続しますか？　それとも単体でトリック設計を始めますか？」と確認（質問はこれ1つだけ）
   - 接続する場合：tree.md と preferences.md を読み込み、現在のプロット文脈と嗜好を引き継いだ上でフェーズ0の残り確認へ進む
3. 単体起動の場合：セッション名を日付＋短いテーマ名で自動決定し、`.agents/skills/twist-trick-forge/twist-sheet-template.md` を元に twist_sheet.md を初期化する（tree.md／preferences.md がなければ `.agents/skills/mystery-deep-brainstorm/` の各テンプレートを元に新規作成）
4. フェーズ0の質問（1ターン1問）から開始する
5. 全出力は日本語。ターミナル操作が必要な場合はUTF-8強制を前置すること
