# /prompt — プロンプト・ディスパッチャー起動

使い方：`/prompt 第5章の伏線が回収できてるか見て` のように、やりたいことを一言添えて起動する（引数なしでも可）。

1. `prompt-dispatcher` スキル（SKILL.md）を読み込み、以後はその手順・フォーマット・HARD-GATEに厳密に従うこと
2. `01_free_memo/プロンプト集.md` を読み込む（記憶で代用しない。テンプレートの内容は必ずこのファイルから取得する）
3. 起動時の引数を「意図」として解釈する
   - 引数がある場合：フェーズ1（テンプレート選定）へ直行する
   - 引数がない場合：「今日は何をしますか？」と1問だけ尋ね、よく使う入口を4つ程度添える（質問はこれ1つだけ）
4. 腰を据えたブレスト（あらすじ・プロットを煮詰める）や、どんでん返し・叙述トリックの設計に該当する場合は、
   このスキルで処理せず `/brainstorm`（mystery-deep-brainstorm）または `/twist`（twist-trick-forge）への切り替えを1問で提案すること
5. 完成プロンプトを提示し、ユーザーの承認を得てから実行する（HARD-GATE）
6. 実行後、プロンプト集に追記すべきテンプレート案・条件行があれば提案する
7. 全出力は日本語。ターミナル操作が必要な場合はUTF-8強制を前置すること
