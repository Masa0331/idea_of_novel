# /generate-uv-vision ワークフロー

ユーザーが小説の原稿執筆中、指定（ハイライト等）した文章の前後に「鳥の四色型色覚」を生かした描写を挿入したい場合に使用するワークフローです。

## 1. ヒアリング（情報が不足している場合）
基本的にはユーザーが対象箇所の文章を選択した状態でコマンドを実行しますが、もし提供された情報だけでは「何の色覚描写を追加したいのか（対象物）」や「どういうニュアンスを出したいのか」が不明瞭な場合、AIは推測で無理に生成せず、まずヒアリングを行ってください。
- 「どの対象物（例：敵の羽、血痕、ネオンサイン、匂いなど）の描写を深めたいですか？」
- 「強調したい感情や感覚（恐怖、威圧感、温度、など）はありますか？」
など、短く簡潔に質問を投げかけます。

## 2. 参照ファイル
以下の設定ファイルを**必ず**読み込み、ルールを厳守してください。
- `05_references/00_文章表現・例文/ref_鳥の四色型色覚を描く表現技法.md`
- `01_settings/style_guideline.md`

## 3. 生成のルール
- **造語の禁止**: 「紫光」「燐紫」といった安易な造語・特殊な漢字の組み合わせは使わない。
- **異質な組み合わせ**: 「誰もが知っている言葉の見慣れない組み合わせ（例：冷たい火、音のない稲光、ざらつく光）」を使用する。
- **共感覚**: 色を単なる視覚としてではなく、温度、音、質感などの五感に変換して描写する。
- **日常性**: 鳥にとってその視界は「当たり前のもの」であるため、過剰に驚いたり説明口調にならないこと。
- **トーン**: 特定の文体には固執せず、あくまで選択された前後の文脈（トーン）に自然に馴染むようにする。

## 4. 出力形式
文脈と対象物に合わせ、以下の切り口から**3〜5パターン**の異なる例文を作成し、ユーザーに提案してください。

1. **温度・触覚重視のアプローチ**
2. **音・光の明滅重視のアプローチ**
3. **状態・形状重視のアプローチ**
4. （その他、情報としての色など）

出力後、「どの方向性がイメージに近いでしょうか？ さらに微調整することも可能です」とユーザーに問いかけ、対話を継続して完成形へと近づけてください。
