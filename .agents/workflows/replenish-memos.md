# メモファイル補充ワークフロー

このワークフローは、`02_plot/memo_for_scene` フォルダ内にアイデア書き出し用のテンプレートファイル（`memo_01.md`、`memo_02.md`、`memo_03.md`）を作成・補充するためのものです。

## 手順

// turbo-all

1. **対象ファイルの作成**
   エージェントのファイル操作ツール（`write_to_file`など）を使用して、`02_plot/memo_for_scene` フォルダ内に以下の3つのファイルを作成してください。すでに存在する場合はスキップするか、空であれば上書きしてください。
   - `memo_01.md`
   - `memo_02.md`
   - `memo_03.md`

2. **書き込む内容（免責事項）**
   各ファイルには、必ず以下の内容（文字列）をそのまま書き込んでください。

   ```markdown
   > [!NOTE]
   > このファイルに書かれた内容は、まだすべて仮設定や設定案の段階であり、ストーリー案作りの際に参考にすることはよいが、ここに書かれた内容に従う必要はなく、必要に応じて臨機応変に最も相応しいストーリーになるために改変・改良・修正して用いるためのメモである。
   ```

3. **ユーザーへの報告**
   ファイルの補充が完了したことをユーザーに報告してください。
