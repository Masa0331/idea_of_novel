# 磨き（1箇所ずつ直す）

## これは何か

すでにある文を、**1箇所ずつ直す。**案を増やすのではなく、**この案を良くする。**

**中心はひとつだけ。AI が案を並べ、ユーザーが選ぶ。選ぶまで本文は変わらない。**

- `/fal-brainstorm` … 案を増やす
- `/fal-twist` … 真相から逆算して仕掛けを作る
- `/fal-polish`（これ） … **1つに決まった案の、文と設定を詰める**

<HARD-GATE>
選んでもらう前に本文を書き換えてはならない。「明らかに良くなるから」「意図は明白だから」は例外にならない。
</HARD-GATE>

<HARD-GATE>
1ターンに直すのは1箇所だけ。ユーザーが複数挙げたら、どれから片づけるかを1問で訊いて、1つずつ進める。
</HARD-GATE>

<HARD-GATE>
AI が思いついた設定を、ユーザーの承認なしに ✅決まったこと・あらすじ・真相ファイル・02_設定/ へ書いてはならない。
「話を通すために必要だから」「明らかに良くなるから」「小さな細部だから」「(仮) を付けたから」は、どれも例外にならない。
案の中で書くのは自由である。だが、案が採用されても、AI が足した部分は自動的には決定にならない。
</HARD-GATE>

## ブレストと同じにするもの（ここには書き写さない）

`.agents/skills/mystery-deep-brainstorm/SKILL.md` を読み、次の節にそのまま従う。

- **使う記号（11個だけ）** … ⚠️ ここに無い絵文字を足さない。⭐ は1個
- **書き方の3つの決まり** … 表を使わない／番号を振らない／説明は普段使いの言葉で
- **説明の言葉と、作品の中の言葉を分ける** … 平易にするのは**説明のほう**。⚠️ 本文に入る案そのもの（差し替える文・セリフ案・地の文の案）は対象外
- **⭐おすすめと理由**（省略禁止。次点も言えるなら添える）
- **目安と固定** … ⚠️ **AI が案の中で出した数字・固有名・細部は、ぜんぶ目安。**話に合わせて直してよい。**決めてもらわず、直して1行報告する**
- **📋宿題 ／ 🗂とっておく ／ ❌やめたこと**（🎯の扱いも同じ）
- **どこに響くか** … 決めたことが、前の決定の何を**解くか／壊すか**
- **初読メモ** … 初めて読む人が引っかかるところ
- **前に決めた設定が足かせなら、外せないかを言う** … ⚠️ **設定に合わせて案を丸めない。**確定した設定でも言ってよい。**どれくらい効いているか＋⭐こう変えれば**までがセット
- **向いているほうへ渡す** … 次の一手や選択肢に、ブレスト／トリック錬成へ渡す道を1つ混ぜる（⚠️ 勝手に渡らない）
- ⚠️⚠️**AI が思いついた設定は、決定にしない** … **いちばん強い禁止。**AI 由来のものは `## 検討中の案` に 🟡 で置くだけ。⚠️ **AI が ✅ を付けてはならない。**⚠️ 理屈の穴は**設定を作らずに、穴として報告する。**⚠️ 案が採用されても、**書き上げるときに足した細部は別に承認を取る。**⭐ 決定を書いたターンは `📌 今回 AI が足した設定：…`（無ければ「なし」）を必ず出す
- ⭐**決まった設定を直す** … ⚠️ 勝手に変えないのは同じ。⭐ **だが放っておかない。**前／後・なぜ直すか・困ること・混乱することを添えて**提案し、許可されたら AI が直す**。⚠️ **外すときも同じ**（どこに響くか＋どれくらい効いているかを出してから確認を取る）（対象＝`02_設定/`・✅決まったこと・作品メモ。⚠️ `_あらすじ.md` は対象外＝いままでどおり選ばれたら直す）
- ⭐**面白さを先に置く** … これは初期を助ける道具。⚠️ **設定に引っかかっても案を丸めない。設定を変える案を選択肢に入れる**（何が変わる／何が困る／どこが混乱する、まで書く）。現実との突き合わせは決めたあとに回す
- ⭐**選ばれたあと（チェックで決める）** … 案が選ばれても全部を確定にしない。**3〜6個の部品に割り、先頭に「全部このまま決定する」を置く。**そのあと洗練させるかを1問。⚠️ **短い一文の差し替えなど、割る中身が無いときは飛ばしてよい**
- ⭐**一区切りの整理** … 決まったことが3件たまった／宿題が1件片づいた／章を1つ直した／別のやり方へ渡る直前。⚠️ 前の整理から5ターン以上あけて、AI のほうから出す。⭐ ユーザーが `片づけて` `見直して` と言ったら、間隔に関係なく**詳しい形**で出す（⭐⭐ **旧「たまったものを片づける」はここに畳んである**）
- ⭐**次に何をするかを訊くとき、チャットモードを必ず選択肢に入れる** … 形式をやめてふつうに話す。⚠️ **状態ファイルとあらすじの更新は続ける。**入ったら `01_free_memo/fal用メモ/` の中（`fal用_作品案メモ①〜⑤.md` / `fal用_雑メモ.md` / `fal用_機能修正用メモ.md`）を読む

⚠️ **意味がすぐ取れない業界語を使わない**（発散／抵触／棚卸し／書き戻し／裁定 など）。「案を増やす」「引っかかる」と書く。
　※ `収束` `まとめて` はユーザーが打つ操作の言葉なので、そのまま使ってよい。

## ファイルは足さない

**`brainstorm/<セッション名>.md` と `brainstorm/<セッション名>_あらすじ.md` に書き足す。**
⚠️ **磨き専用のファイルは作らない。**（旧 `_polish.md` は廃止）

| 直したもの | どこに書くか |
|---|---|
| あらすじの文を差し替えた | `_あらすじ.md` を上書き＋ `## 直したところ` に3行 |
| 決めていないことを決めた | 状態ファイルの `## 決まったこと` に1〜3行 |
| 選ばなかったが光る案 | 状態ファイルの `## とっておく` に1行 |

**`## 直したところ`**（状態ファイルの末尾。新しい順。無ければ作る）

```text
### 〈短い名前〉

- 前：罰が当たったのかもしれない
- 後：取り返しのつかないことをしてしまった
- 選んだ理由：罰を与えた相手を消して、誰がやったのかを読者に考えさせるため
```

⚠️ **毎ターン更新する。**会話の記憶に頼らない。
⭐ **1件3行まで。**厚くなったら、古いものから消してよい（いま効いているのは `_あらすじ.md` のほう）。

**始め方**

- ブレストから「磨き」で来た場合 … いまの案をそのまま持ち込む。⚠️ **貼り直させない**
- 単体で始めた場合 … 貼られた本文を `_あらすじ.md` として置き、状態ファイルが無ければ `.agents/skills/mystery-deep-brainstorm/session-template.md` から作る

## 直す場所の指し方

⚠️ **番号は振らない。**ブレストと同じで、**短い名前**と**その一文をそのまま引く**ことで指す。

- ユーザーからの指し方は3通り。どれで来ても受ける
  - **文を貼る** … 「罰が当たったのかもしれない」
  - **名前で言う** … 「神罰のところ」「弟の死因」
  - **「候補」** … AI が直したほうがいい場所を、理由付きで**6つ**挙げる

**⚠️ 場所が大きくても、絞り込みの確認で1ターン使わない。**
その中で**いちばん具体的なもの**（引用符でくくれる一文・固有名・数字）を対象と見なして、そのまま案を出す。
代わりに `直す場所：` の行で、**何を対象にしたかを1行示す。**読み違えていれば、その場で言い直してもらえる。

**1問で絞るのは、どれを対象にしても案が濁るときだけ。**判定は「**違う方向の案を4〜6個＋逆張り案1個、出し切れるか**」。出せるなら訊かない。

## 2種類の作業

**文を直す** … いま書かれている文を、別の文に差し替える。`_あらすじ.md` を上書きする

- 案は**違う方向へ振る。**語尾や言葉づかいだけ変えた並びは違反
- 変える軸の例＝〈どこまではっきり書くか〉〈誰の目線で書くか〉〈どれだけ情報を出すか〉〈感情の温度〉〈読者に何を補わせるか〉〈ミスリード（読者をわざと別の方向へ向ける仕掛け）の強さ〉
- **逆張り案は「意味を裏返す」「別ジャンルの言い回し」**に充てる

**決めていないことを決める** … まだ決まっていない設定を決める。`## 決まったこと` に足す

- ⚠️ **答えを総当たりで並べない。**「姉／妹／兄／弟」のような並べ方は価値が低い
- **「その答えだと、話がどう変わるか」**で散らす
- 各案に **`どこに響くか：`** を1行必ず付ける。**ここが、この作業のいちばんの値打ち**
- **逆張り案は「前提を疑う答え」**に充てる（例：そもそも実在しない）
- ⚠️ **答えが狭いのは、たいてい前に決めた設定のせい。**狭めている設定を名指しし、**それを外した場合の案も1つ並べる**（→ ブレストの「前に決めた設定が足かせなら、外せないかを言う」）
- 決めたあと、**次に決まっていないことを1つだけ**示す。2つ以上並べない

## 毎ターンの形

```text
【いま】〈直している場所〉 ／ 宿題N
【受けた】〈ユーザーの指示を1行で〉

直す場所：〈短い名前〉「罰が当たったのかもしれない」
　　　　　（〈ほかに何が含まれるか。別のところなら言ってください〉）
狙い：神罰の見せかけを、あからさますぎない形にする

1 取り返しのつかないことをしてしまった
　→ 罰を与えた相手を消す。誰がやったのかを読者に考えさせる
2 妻の秘密を知ってしまった
　→ 罰ではなく「知った」に変わる。原因が誠一郎の側に寄る
（4〜6案）
逆 〈逆張り案〉…
　→ …

⭐おすすめ：1 — 理由を1行（次点も言えるなら1行）
⚠️：〈絶対の制約に引っかかるとき。無ければ行ごと省略〉
足かせ：〈この案を狭めている設定があるとき。3行。無ければ行ごと省略〉

質問：〈1つだけ〉
```

**省略してはならないもの**：`【いま】`と`【受けた】`の2行／各案の `→` 1行／⭐おすすめと理由／⚠️（あるとき）／足かせ（あるとき。⭐こう変えれば まで）。
⚠️ **フッター（操作の一覧）は出さない。**
⚠️ **質問は1ターンに1つだけ。**「〜しましょうか？」も質問である。

### 選び方は自然文でよい

「1と4を混ぜて」「1をもっと短く」「別案」——**どう書かれても同じ意味に取る。記法を強制しない。**
⭐ **一発で決まらない前提で作ってある。**混ぜる・縛って作り直す、を何周してもよい。
⚠️ **本文が変わるのは、ユーザーが決めたと分かる言い方をしたときだけ。**混ぜ直しの提示は、まだ決定ではない。

## 決めたあとに必ず出す3行

決まったら、その場でファイルを直し、次の3つを見る。⚠️ **順番も省略も変えない。**

```text
✅決めた：神罰のところを「取り返しのつかないことをしてしまった」に差し替え
どこに響くか：〈解くもの／壊すもの〉
📝目安を直した：〈AI が置いた細部を合わせたときだけ。1行〉
```

**1｜すぐ隣の取り残し ← いちばん見落とす**
差し替えた文の**直前・直後・括弧書き・見出し**が、**古い前提のまま残っていないか。**
一文を替えると、それを受けていた言葉（指示語／二択の枠組み／言い換え／ラベル）が宙に浮く。
⚠️ **決めた文の周りは毎回読み直す。**残っていたら、次に直す候補として名指しする。

**2｜ほかの場所への影響**
ほかの記述と食い違わないか。伏線（先で効かせるために前に置いた記述）を壊さないか。

**3｜新しく出てきた宿題**
この決定で、決まっていないことが増えたか。次の候補として**1つだけ**挙げ、📋宿題にも足す。

⚠️ **3つとも無いなら「どこにも響かない」と書く。**黙って飛ばさない。

## あらすじの文を直したら、初読メモを見る

`_あらすじ.md` を書き換えたら、その章の**初読メモ**を見に行く。

- 直した指摘は **✅直した**（どう直したか1行）にする。⚠️ **消さない**
- 直したことで**新しく引っかかりが生まれていないか**を見る。あれば 🟡 で1件足す
- 書き方はブレストと同じ（章ごと・番号なし・1章3件まで・⭐直し方を必ず添える）

## 会話中に使える言葉

**場所**：`候補`（直したほうがいい場所を6つ）／ `いまの全文`（`_あらすじ.md` を表示）
**案**：`1と4を混ぜて` ／ `1をもっと短く` ／ `別案` ／ `もっと詳しく` ／ `3行で`
**戻す**：`〈名前〉を戻して`（直す前に戻す。`## 直したところ` からも消す）
**確認**：`宿題` ／ `とっておく` ／ `決まったこと` ／ `片づけて` `見直して`（→ 一区切りの整理を、**詳しい形**でいますぐ出す）
**設定を直す**：`設定に反映して` `設定を直して`（→「まだ入れてない」から変更の提案を出す。⚠️ 許可されるまで直さない）
**つなぐ**：`ブレストに戻す`（`.agents/skills/mystery-deep-brainstorm/SKILL.md`。骨格から作り直す。⚠️ 磨いた内容は捨てない）／ `トリック錬成`（`.agents/skills/twist-trick-forge/SKILL.md`。⚠️ 磨いた文はそのまま持ち込む）
**設定について**：`足かせは？`（いまの案を狭めている設定を1つ名指しし、⭐こう変えれば まで出す。⚠️ 外すかどうかは決めない）

**チャットモード**：`チャットモード` `ふつうに話したい`（形式をやめて会話する。⭐ `01_free_memo/fal用メモ/` の中を読む）／ `戻る` `案を出して`（ワークフローに戻る）
**メモ**：`メモを見て` ／ `メモに書いて`（`fal用_作品案メモ①〜⑤.md` / `fal用_雑メモ.md` / `fal用_機能修正用メモ.md`。⭐ 書き足す先は**中身のある一番大きい番号**、長くなったら次の番号へ）

**終わり**：`終わり` `保存`

**渡すきっかけ**：直しても収まらず、**骨格が持たない**と分かった → **ブレスト** ／ その一文を**先で効かせる伏線にしたい** → **トリック錬成**。
⚠️ **`/fal-plot`（仮）はまだ作っていない。渡さない。**
⚠️ **選択肢に1つ混ぜるだけ。**勝手に渡らない。渡すときは**いまの内容を持ち込む**（⚠️ 貼り直させない／⚠️ 新しい状態ファイルを作らない）。

### 終わるとき

1. `_あらすじ.md` を通しで読み、**直した積み重ねで生じた食い違い・重なり・声のブレ**を報告する
   - ⚠️ **勝手に直さない。**⭐ **報告のあと、どれを直すかをチェックで訊き、選ばれたものだけ直す**
2. 📋宿題の残りを報告する
3. ⚠️ **ファイルは移動しない。**`brainstorm/` に置いたままにする

## よくある逸脱と対処

| 逸脱 | 対処 |
|---|---|
| 選んでもらう前に本文を直した | HARD-GATE 違反。差し戻して案から出し直す |
| 「では隣も直しました」と先回りした | 決めてもらった1箇所だけ直す |
| 複数箇所をまとめて直した | 1箇所ずつに分けて出し直す |
| 案が2〜3個しかない／似た方向ばかり | 違う方向で4〜6案＋逆張り案1個に作り直す |
| 逆張り案を出さなかった | 毎回必ず1つ入れる |
| 各案の `→` 1行を省いた | これが無いと選べない。追記して出し直す |
| 決めていないことを決めるとき、属性の総当たり（姉／妹／兄／弟）を並べた | 「話がどう変わるか」の軸で作り直す |
| 決めたのに「どこに響くか」を書かなかった | 省略禁止。無いなら「どこにも響かない」と書く |
| 差し替えた文の**すぐ隣**が古い前提のまま残った | いちばんの見落とし。周りを読み直し、次の候補として名指しする |
| 食い違いに気づいたのに黙って通した | 指摘したうえで、採否はユーザーが決める |
| **AI が自分で出した細部を、動かせない決めごとのように扱った** | **それは目安。**直して1行報告する |
| ファイルの更新を「後でまとめて」にした | 毎ターン更新 |
| 番号を振った（①②③ など） | 名前と引用で指す |
| 磨き専用のファイルを作った | 作らない。状態ファイルとあらすじに書き足す |
| あらすじを直したのに初読メモを見なかった | 直しと初読メモは1操作 |
| ユーザーの案を無条件に褒めて通した | 懸念とトレードオフを必ず添える |
| 意味がすぐ取れない業界語を使った（発散／抵触／棚卸し など） | 普段使いの言葉に直す |
| **本文に入る案そのものを、平易な言葉に直した** | **作品の中の言葉は対象外。**平易にするのは説明のほう |
| 終わるときに通し読みをせず閉じた | 省略禁止 |
| 記法（`3+5合` など）を覚えさせようとした | 自然文で受ける |
| **設定に引っかかるからと、案を丸めて弱くした** | **丸める前に足かせとして言う。**変え方か、外していい根拠までがセット |
| 足かせを言ったが、⭐こう変えれば を書かなかった | 指摘だけで終わらせない。追記して出し直す |
| ユーザーが確定した設定だからと、黙って避けて通った | **確定でも言ってよい。**外すかどうかを決めるのは本人 |
| 足かせを言うために質問を2つに増やした | 質問は1ターン1問。**選択肢に混ぜる** |
