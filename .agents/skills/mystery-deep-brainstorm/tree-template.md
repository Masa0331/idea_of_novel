## 🔢 採用ID索引（P-／S- → 全文のあるノード）

> **この節は省略できない。**採用カウンタの真下に置き、**採番と同時に1行足す**（別作業にしない）。
> ⚠️**検算**：採用カウンタの数字と、この索引が持つ**番号の数**は**必ず一致する。**ズレたら索引の書き漏らしである。
> （**枝番 `S-11a` / `S-11b` は1番号として数える。**分離しても採番は増えないため、行数は番号数より多くなりうる）
> **ここは目次であって内容ではない。**全文は必ずノード側にあり、この節に書き足してはならない（3本で同じ内容を二重に持たない原則）。
> 🔎 **探し方**：ここで ID → ノードID を引き、そのノードへ飛ぶ。新規の定義行は `S-07【` で直接検索することもできる（下の書式規則）。

**1行の書式（6項目・固定）**

```text
- **S-07** 〈一言〉 … 🎚〈ランク〉／〈状態〉／全文＝**N1-2**（発案 **N1-1**）／論点マップ **B-3**
```

- **ID** … `P-01` / `S-07`。分離した場合は `S-11a` `S-11b` のように枝番で書く
- **一言** … 検索でこの行に当たるよう、**内容語を入れる**（「傷の一致」「登録票の一行」）。抽象語だけにしない
- **🎚ランク（必須度）** … `◎必須`／`○優先`／`△希望`／`▽自由`。**AI の提案段階では `?` を付ける**（`◎?`）。⚠️**記号だけで書かず、言葉を付ける**（△と▽は形が似ている）。⚠️**▽自由は「採用」である。**🗂保留・❌却下とは別物
- **状態** … ✅確定／🔵有力／🟡検討中／🗂保留／❌破棄（破棄も**行ごと消さず**、❌で残す。同じ番号の再利用を防ぐため）
- **全文＝ノードID** … **その内容の全文が置かれているノード。**確定ノードと発案ノードが違う場合は `（発案 N1-1）` を併記する
- **論点マップの節** … `A-1` `B-3` 等。主題側から見たいときの飛び先

**書き方の例（ノード別にまとめる。時系列順でよい）**

**N1（第1世代）**
- **P-01** 〈タイトル的な一言〉 … 🎚◎必須／✅確定／全文＝**N1**／論点マップ **B-1**
- **S-01** 〈一言〉 … 🎚▽自由／🟡仮置き（理由が未構想）／全文＝**N1**／**F**

**N1-2**
- **S-07** 〈一言〉 … 🎚○?／✅確定／全文＝**N1-2**（発案 **N1-1**）／**B-3**

> ⚠️**新しい定義行の書式規則**：ノード側で S番号を初出させるときは、行頭を **`**S-07【状態】見出し**`** の形にする。
> ⚠️**ランクが決まっていれば状態と並べて書く**：`**S-07【✅確定・○優先】見出し**`。
> これにより `S-07【` で**定義行だけ**を直接検索できる（`S-07` だけだと言及箇所が大量にヒットして埋もれる）。
