# トリックの型カタログ（引き出し）

「裏切る思い込み」が決まったあとに読み、それに合う型を選ぶための一覧。実在作品名は挙げず、型と成り立つ条件だけを書く。

⚠️ **番号は振らない。名前で呼ぶ**（「人数の思い違いで行こう」で通る）。
⚠️⚠️ **型をそのまま当てはめた案は弱い。**必ず**この話でしか成り立たない一点**を足す。
⭐ **実際にあったこと・実在の技術に載る形にできないか**を先に考える。作り物の型より強くなる。

---

## 何をひっくり返すか（どんでん返しの型）

- **犯人の意外性** … いちばん疑われない立場の人物が犯人（相棒役／依頼人／被害者を装った者／探偵役自身／すでに退場したはずの人物）
- **被害者の反転** … 被害者だと思われていた人物が、加害者・共犯・自作自演だった
- **事件かどうかの反転** … 事件だと思っていたものが事故・偶然・善意の行いだった。またはその逆
- **構図の反転** … 守る側と狙う側、追う側と追われる側が入れ替わる
- **動機の反転** … 憎しみに見えた行いが、愛情から出ていた。またはその逆
- **答えの反転** … 一度出した答え（偽の答え）が、あとから覆される二段構え

---

## 読者の思い違いを使う型（文章だから成り立つ）

**人物の思い違い**

- **性別の思い違い** … 一人称・役職・行動の書き方が、どちらとも取れることを使う
- **年齢の思い違い** … 子どもと大人、若者と老人の取り違え
- **人数の思い違い** … 二人を一人だと思わせる／一人を二人だと思わせる
- **呼び名の思い違い** … 同じ名前・呼び方の使い分けで、別の人格に見せる
- **立場の思い違い** … 職業・立場・関係（夫婦と思わせて親子、など）

**時間の思い違い**

- **並べ替え** … 同時に進んでいるように見せた二つの筋が、実は別の時代だった
- **経った時間の思い違い** … 一晩と思わせて数年、など
- **順序の思い違い** … 結果を原因より先に見せて、因果を逆に読ませる

**場所の思い違い** … 同じ場所だと思わせて別の場所／その逆。国・地域・建物の大きさの取り違え

**視点の思い違い**

- **語り手の正体** … 人間だと思わせて動物・機械・幼児・死者だった
- **視点人物のすり替え** … 章ごとに別人なのに同じ人物に読める（逆も）
- **作中の文書** … 手記・日記・記録の「書き手」や「書かれた時期」を取り違えさせる

**状況の思い違い** … 日常だと思わせて非常時／自由だと思わせて閉じ込められている、など、舞台そのものの取り違え

**本の作りを使う** … 章立て・目次・作中作など、本の構造そのものを仕掛けに使う

---

## 組み合わせて使う技

- **疑わしく見える別人を置く** … 偽の謎で読者の注意を占領する
- **ついでに置く** … 本当の手がかりを「別の話のついで」に置き、覚えてはいるが注目されない状態を作る
- **二通りに読める記述** … 初めてと二度目で意味が変わる文。手がかりの基本形
- **読者の常識を使う** … ジャンルの慣習や世間の思い込みという「作中に書いていない前提」を裏切る
- **偽の答え → 本当の答え** … 「答えの反転」と組み合わせる。⭐ **偽の答えは八割正しくすると効く**
- **感情の置き方** … 驚きの直後に納得、その直後に感情の反転（切なさ・恐怖・救い）を置くと余韻が残る

---

## どれを選ぶかの目安

- 裏切る思い込みが**人物**に関するもの → 人物・視点の思い違い ＋ 犯人の意外性／被害者の反転
- **時間・順序**に関するもの → 時間の思い違い ＋ 答えの反転
- **舞台・状況**に関するもの → 場所の思い違い／状況の思い違い
- **善悪や構図**に関するもの → 構図の反転／動機の反転 ＋ 読者の常識を使う
- **ラスト一撃の大逆転**が欲しい → 何をひっくり返すかを主軸に、思い違いの型を1つ補助で
- **中盤に小さな驚きを連打**したい → 偽の答え → 本当の答えを多段にして、小さめの思い違いを散らす

---

## 成り立っているかの確かめ（「ずるくないかを見る」で使う）

- その思い違いは**読者が自分で補った**結果か。⚠️ 地の文の嘘になっていないか
- 真相を明かす瞬間、根拠として指せる記述が本文に**3か所以上**あるか
- 二度目に読んだとき、食い違う描写が**ゼロ**か
- その思い違いを**最後まで保つ理由**が話の側にあるか（⚠️ 仕掛けのための仕掛けになっていないか）
- 明かすタイミングと明かし方は、**そのあとに置きたい感情**から逆算されているか
