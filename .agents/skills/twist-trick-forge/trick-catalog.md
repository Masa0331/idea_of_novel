# トリック型カタログ（参照資料）

フェーズ2で読み込み、選ばれた「読者の思い込み」に適合する型を提示するための分類。実在作品名は挙げず、型と成立条件のみを記す。案の提示時は、この型をそのまま使わず**必ず独自のひねりを加えること**。

## A. どんでん返しの対象による分類（何の認識を覆すか）

- A1 犯人の意外性：最も疑われない立場の人物が犯人（相棒役／依頼人／被害者を装った者／探偵役自身／すでに退場したと思われた人物）
- A2 被害者の反転：被害者と思われた人物が加害者・共犯・自作自演
- A3 事件性の反転：事件だと思っていたものが事故・偶然・善意の行為／その逆
- A4 構図の反転：守る側と狙う側、追う側と追われる側が入れ替わる
- A5 動機の反転：憎悪と見えた行動が愛情由来／その逆。動機の意外性で刺す型
- A6 解決の反転：一度提示された解決（偽の解決）が覆される二段構え

## B. 叙述トリックの型（読者の誤認を利用する。文章媒体特有）

- B1 人物誤認
  - B1a 性別誤認：一人称・役職・行動描写の中立性を利用
  - B1b 年齢誤認：子どもと大人、若者と老人の取り違え
  - B1c 人数誤認：二人を一人と思わせる／一人を二人と思わせる
  - B1d 同名・呼称トリック：呼び名の使い分けで別人格を演出
  - B1e 属性誤認：職業・立場・関係性（夫婦と思わせて親子等）
- B2 時間誤認
  - B2a 時系列シャッフル：並行して見せた二つの筋が実は別時代
  - B2b 経過時間の誤認：一晩と思わせて数年、等
  - B2c 順序誤認：結果を原因より先に見せて因果を逆に読ませる
- B3 場所誤認：同一の場所と思わせて別の場所／その逆。国・地域・建物のスケール誤認
- B4 視点誤認
  - B4a 語り手の正体：人間と思わせて動物・AI・幼児・死者など
  - B4b 視点人物のすり替え：章ごとに別人だが同一人物に読める（逆も）
  - B4c 作中文書トリック：手記・日記・記録の「書き手」や「書かれた時期」の誤認
- B5 状況誤認：日常と思わせて非常時／自由と思わせて監禁下など、舞台状況そのものの誤認
- B6 メタ構造トリック：章立て・目次・作中作など、本の構造自体を仕掛けに使う

## C. 支援技法（型と組み合わせて使う）

- C1 ミスリード役の配置：疑わしい別人・偽の謎で注意を占有する
- C2 焦点操作：真の手がかりを「別の話題のついで」に置き、記憶に残るが注目されない状態を作る
- C3 二重の意味の記述：初読と再読で意味が変わる文。伏線の基本形
- C4 読者の常識の利用：ジャンル慣習・社会通念という「作中に書かれていない前提」を裏切る
- C5 偽の解決→真の解決：A6と併用。偽の解決は八割正しくすると効果が高い
- C6 感情の設計：驚きの直後に納得、その直後に感情的な意味の反転（切なさ・恐怖・救い）を置くと余韻が残る

## 型選択の指針

- 「裏切る思い込み」が人物に関するもの → B1/B4系＋A1/A2
- 時間・順序に関するもの → B2＋A6
- 舞台・状況に関するもの → B3/B5
- 物語の構図・善悪に関するもの → A4/A5＋C4
- ラスト一撃の大逆転が欲しい → A系主軸＋B系1つを補助に
- 中盤ツイスト連打 → C5の多段構成＋小さめのB系を分散配置

## 成立条件チェック（フェーズ5で使用）

- 誤認は「読者が勝手に補完した」結果か（地の文の虚偽になっていないか）
- 真相開示の瞬間、根拠として指せる記述が本文に3か所以上あるか
- 再読時に矛盾する描写がゼロか
- その誤認は最後まで維持する必然性があるか（トリックのためのトリックになっていないか）
- 開示のタイミングと開示役（探偵の指摘か、描写の反転か）は感情効果から逆算されているか
