# トリック錬成（真相から逆算して仕掛けを作る）

## これは何か

どんでん返しと叙述トリック（＝文章だからこそ成り立つ、読者の思い違いを使った仕掛け）を、**真相のほうから逆算して作る。**

⭐ **良い仕掛けは「驚き」と「納得」の両方が要る。**驚きだけなら反則に見え、納得だけなら平坦になる。

**組み立ての順序は、いつもこれ。**

```text
裏切る思い込みを決める → 型を選ぶ → 三つの層を組む → 手がかりを配る → ずるくないかを見る
```

<HARD-GATE>
「三つの層」と「ずるくないかを見る」を終えるまで、仕掛けを完成として出してはならない。「単純な仕掛けだから確かめなくていい」は例外にならない。
</HARD-GATE>

<HARD-GATE>
AI が思いついた設定を、ユーザーの承認なしに ✅決まったこと・あらすじ・真相ファイル・02_設定/ へ書いてはならない。
「話を通すために必要だから」「明らかに良くなるから」「小さな細部だから」「(仮) を付けたから」は、どれも例外にならない。
案の中で書くのは自由である。だが、案が採用されても、AI が足した部分は自動的には決定にならない。
</HARD-GATE>

## ブレストと同じにするもの（ここには書き写さない）

`.agents/skills/mystery-deep-brainstorm/SKILL.md` を読み、次の節にそのまま従う。

- **使う記号（11個だけ）** … ⚠️ ここに無い絵文字を足さない。⭐ は1個
- **書き方の3つの決まり** … 表を使わない／番号を振らない／説明は普段使いの言葉で
- **説明の言葉と、作品の中の言葉を分ける** … 平易にするのは**説明のほう**。⚠️ 手がかりの文面案・地の文の案・セリフ案は対象外
- **案の出し方** … 違う方向の案を4〜6個＋**逆張り案1個**。各案に狙いを1行
- **⭐おすすめと理由**（省略禁止。次点も言えるなら添える）
- **目安と固定** … ⚠️ **AI が案の中で出した数字・固有名・細部は、ぜんぶ目安。**話に合わせて直してよい。**決めてもらわず、直して1行報告する**
- **空き枠（あとで埋める）** … ⚠️⚠️ **AI が足した人物の属性・出来事の中身・場面の細部は、既定で枠にする。**`（◎必須・中身は未定）` と書き、**中身ではなく「満たすこと」だけ**を残す。⚠️ **📋宿題には入れない**
- **📋宿題 ／ 🗂とっておく ／ ❌やめたこと**（🎯の扱いも同じ）
- **どこに響くか** … 決めたことが、前の決定の何を**解くか／壊すか**
- **初読メモ** … 初めて読む人が引っかかるところ
- **前に決めた設定が足かせなら、外せないかを言う** … ⚠️ **設定に合わせて仕掛けを丸めない。**確定した設定でも言ってよい。**どれくらい効いているか＋⭐こう変えれば**までがセット
- **向いているほうへ渡す** … 次の一手や選択肢に、ブレスト／磨きへ渡す道を1つ混ぜる（⚠️ 勝手に渡らない）
- ⚠️⚠️**AI が思いついた設定は、決定にしない** … **いちばん強い禁止。**AI 由来のものは `## 検討中の案` に 🟡 で置くだけ。⚠️ **AI が ✅ を付けてはならない。**⚠️ 理屈の穴は**設定を作らずに、穴として報告する。**⚠️ 案が採用されても、**書き上げるときに足した細部は別に承認を取る。**⭐ 決定を書いたターンは `📌 今回 AI が足した設定：…`（無ければ「なし」）を必ず出す
- ⭐**決まった設定を直す** … ⚠️ 勝手に変えないのは同じ。⭐ **だが放っておかない。**前／後・なぜ直すか・困ること・混乱することを添えて**提案し、許可されたら AI が直す**。⚠️ **外すときも同じ**（どこに響くか＋どれくらい効いているかを出してから確認を取る）（対象＝`02_設定/`・✅決まったこと・作品メモ）
- ⭐**面白さを先に置く** … これは初期を助ける道具。⚠️ **設定に引っかかっても仕掛けを丸めない。設定を変える案を選択肢に入れる**（何が変わる／何が困る／どこが混乱する、まで書く）。現実との突き合わせは決めたあとに回す
- ⭐**選ばれたあと（チェックで決める）** … 仕掛けが選ばれても全部を確定にしない。**3〜6個の部品に割り、先頭に「全部このまま決定する」を置く。**そのあと洗練させるかを1問
- ⭐**一区切りの整理** … 決まったことが3件たまった／宿題が1件片づいた／手がかりを配り終えた／別のやり方へ渡る直前。⚠️ 前の整理から5ターン以上あけて、AI のほうから出す。⭐ ユーザーが `片づけて` `見直して` と言ったら、間隔に関係なく**詳しい形**で出す（⭐⭐ **旧「たまったものを片づける」はここに畳んである**）
- ⭐⭐**いま、どの段階にいるか** … **大まかなあらすじ → 大まかな設定の肉付け → 細かい設定の肉付け＆プロット化 → 文章。**⚠️⚠️ **段階を飛ばして細かい設定を増やさない**（大きな設定が動けば全部むだになる）。⭐ 案を出すときは毎回、いまどの段階かを考える
- ⚠️⚠️**AI が、確認せずに 📋宿題 を増やしてはならない** … ⭐ **穴は報告だけにして、「これは宿題に入れますか」と一言訊いてから足す。**⚠️ **ユーザーが素通りしたものを、勝手に宿題へ回さない**（素通りは承認ではない）
- ⭐**次に何をするかを訊くとき、チャットモードを必ず選択肢に入れる** … 形式をやめてふつうに話す。⚠️ **状態ファイルと真相ファイルの更新は続ける。**入ったら `01_free_memo/fal用メモ/` の中（`fal用_作品案メモ①〜⑤.md` / `fal用_雑メモ.md` / `fal用_機能修正用メモ.md`）を読む

⚠️ **意味がすぐ取れない業界語を使わない**（発散／抵触／棚卸し／書き戻し／裁定 など）。「案を増やす」「引っかかる」と書く。
　※ `収束` `まとめて` はユーザーが打つ操作の言葉なので、そのまま使ってよい。

### このスキルだけの言葉の決まり

⚠️⚠️ **「誤認する」「気づかない」と書くときは、それが「読者」なのか「作中人物」なのかを必ず書く。**
ここを省くと、設計そのものが読み違えられる。**このスキルで、いちばん事故になる省略。**

### このスキルで足かせになりやすいもの

⭐ **型が通らない理由の多くは、仕掛けの弱さではなく、先に決めた縛りのほうにある。**
人物の居場所・時系列・職業・「この人は嘘をつかない」——ここが1つ動くだけで通る仕掛けは多い。

- ⚠️ **仕掛けを丸める前に、縛りのほうを1つ名指しする。**「どれくらい効いているか」と「⭐こう変えれば」まで書く
- ⚠️ **ユーザーが確定した設定でも言ってよい。**外すかどうかは本人が決める。⚠️ **勝手に外さない**
- ⭐ **設定を外す案と、この話でしか成り立たない一点を足す案の、両方を出す。**片方に寄せない

## 短くする（ファイルが長くなったとき）

⚠️⚠️ **ブレストの「一区切りの整理」とは別の作業である。**混ぜてはならない。

- **一区切りの整理**（`整理して` `片づけて` `見直して`）… **中身を確かめる。**長さは変わらない
- **短くする**（`短くして` `長すぎる` `詰めて`）… **長さを減らす。**中身は増えも減りもしない

**呼ばれたら `.agents/rules/fal-shorten-rules.md` を読み、その決まりにそのまま従う。**
⚠️ **記憶で代用しない。**ものさし・行き先・毎ターンの形は、すべてそちらにある。

**AI から知らせるとき**｜`_真相.md` が **200行** を超えたとき。⭐ **一度だけ知らせる。**⚠️ **勝手に短くしない。**

**このスキルで触ってよいもの**

- **検討して捨てた仕掛け**（→ 名前だけの1行にまとめる）
- **同じ説明が2箇所以上にあるもの**
- **型カタログから引いた説明の写し**（⭐ `trick-catalog.md` を読めば分かる）

**⚠️ 触ってはならないもの**

- ⚠️⚠️ **三つの層**（真相／読者に見せるもの／手がかり）と、**手がかりの配置**
- ⭐ **真相は閉じた論理系である。**1つ抜くと、どこで立たなくなるかが分からない
- ⚠️ **「この手がかりは効いていない」を理由に消さない。**効いていないように見えるのが、正しく置かれた手がかりである

## 進め方（5つ。行き来してよい）

### 1｜裏切る思い込みを決める

仕掛けの土台は、**読者が無意識に置いている前提**である。いまの話から、裏切れる思い込みを **4〜6個＋逆張り案1個**挙げる。

- 例：「語り手は本当のことを言っている」「この二人は別人だ」「事件はいま起きている」「探偵側は安全なところにいる」
- **逆張り案は「読者がまさか疑わない置き方」**に充てる（章の並べ方・作中の文書を誰が書いたか、など）
- ⚠️ **どれを裏切るかが決まるまで、型選びに進まない**

### 2｜型を選ぶ

`.agents/skills/twist-trick-forge/trick-catalog.md` を読み、選んだ思い込みに合う型を **3〜5個**、⭐おすすめ＋理由＋次点つきで出す。組み合わせてよい（例：「人数の思い違いを主軸に、時間の思い違いを補助で」）。

- ⚠️⚠️ **型をそのまま当てはめた案は弱い。**必ず**この話でしか成り立たない一点**を足す
- ⭐ **実際にあったこと・実在の技術に載る形にできないか**を先に考える。作り物の型より強くなる
- **文章だから成り立つ仕掛けは、映像にすると崩れるものが多い。**⚠️ この作品はどちらでもよいなら**訊かない。**映像化を気にする話だと分かっているときだけ、1行の注意として添える

### 3｜三つの層を組む

**下から順に、真相の側から組む。**各層ごとに案を出して選んでもらう。

1. **本当に起きたこと** … 実際に何があったか。誰が・何を・いつ・どこで・なぜ・どうやって。曖昧さゼロで書く
2. **読者に見せるもの** … 表の物語。真相のうち**どこを書かないか**、どこを**二通りに読める形で書くか**
3. **目をそらす仕掛け** … 読者の注意をどこへ向けるか。疑わしく見える別人／偽の謎／本当の手がかりから目をそらす置き方

⚠️⚠️ **地の文で嘘は書かない。**本当のことだけを、足りない形・二通りに読める形で置き、**読者が自分で読み違える**ようにする。
（語り手自身が事実を取り違えている型を使うときだけ例外。その場合は**そう決めたことを真相ファイルに明記する**）

### 4｜手がかりを配る

真相ファイルの手がかりの欄を埋める。1つにつき次の4つ。

- **初めて読むときどう見えるか／二度目に読むと何を意味するか**
  ⚠️ **二度目に意味が変わらないものは、手がかりではない**
- **どこに置くか**（序盤・中盤・直前）。⚠️ 直前だけだと唐突、序盤だけだと忘れられる
- **どう紛れさせるか**（日常の描写にまぎれこませる／別の話の途中に置く）

⚠️ **手がかりは最低3つ。**1つだけ、または直前だけの置き方は、次の段で落とされる。

### 5｜ずるくないかを見る

⭐ **見るのは「作った側」ではなく「読む側」。**ブレストの初読メモと同じで、**ここまでの話を知らない人がどう読むか**だけを見る。
1ターン1問・⭐おすすめ付きで、次の5つを順に確かめる。

- **初めて読む人へ** … 真相にたどり着ける材料は、本文に置いてあるか。後から出していないか
- **二度目に読む人へ** … 真相を知って読み返したとき、食い違う記述は無いか。逆に「二度目に光る」記述はあるか
- **納得は残っているか** … 驚きだけで、納得が置き去りになっていないか。「分かるわけがない」と「言われてみれば」の境目はどこか
- **どこかで読んだ形になっていないか** … 型カタログのままになっていないか。この話だけのひねりはどこか
- **人物が壊れていないか** … 仕掛けの都合で、人の動きが不自然になっていないか（⚠️ **いちばん多い失敗**）

食い違いが出たら、**3か4に戻って組み直す。**

## 出し方の形（読みやすさは、形で作る）

⚠️⚠️ **仕掛けの説明は、1件あたりに書くことが多い**（三つの層・手がかりの4項目・5つの確かめ）。
何もしないと**文字の固まり**になって、選ぶ前に読めなくなる。⭐ **次の4つを毎回そのまま守る。**

**1｜まとまりの区切りに、必ず空白行を1つ入れる**

区切りは6つ ── `【いま】` ／ `【受けた】` ／ 案の並び ／ `⭐おすすめ` ／ `⚠️`〜`足かせ` ／ `質問`とその選択肢。
⚠️⚠️ **改行を1つ入れただけでは、前の行と繋がって表示される。**空白行が要る。

**2｜案は1件ずつの箇条書き。中身と `狙い` は入れ子にする**

`- **1｜〈案をひと言で〉**` を並べ、その下に中身の行と `- **狙い**：…` を**入れ子**で置く。⭐ 逆張り案は `逆｜` で最後に。

- ⚠️ **全角スペースで字下げしない。**字下げは表示に効かず、行が繋がる
- ⭐ **案の番号は、これまでどおり付ける**（⭐おすすめで指すため）。⚠️ **型は名前で呼ぶ**決まりは、そのまま

**3｜このスキル固有の並びも、すべて箇条書きにする**

- **三つの層** … `- **1｜本当に起きたこと**` `- **2｜読者に見せるもの**` `- **3｜目をそらす仕掛け**` の3件
- **手がかり** … 手がかり1つを親の箇条書きにし、**4つの項目を入れ子**で並べる
- **ずるくないかを見る** … 5つの確かめを、1つずつ箇条書きで
- `足かせ`の3行 ／ `どこに響くか` の報告も、`- **ラベル**：` の箇条書きに

**4｜`質問` の選択肢も箇条書きにする**

`- **A)** …` の形。⚠️ `　A)` のように**全角スペースで字下げしない。**

- ⭐ **1行は2文まで。**3文を超えたら、中身を削るか、行を分ける
- ⭐ **チェックの一覧（`- [ ]`）は、もともと箇条書きなので、そのままでよい**
- ⭐ **真相ファイルにそのまま入る文だけは、` ```text ` ブロックで出してよい**

## 毎ターンの形

```markdown
【いま】〈やっていること〉 ／ 宿題N

【受けた】〈ユーザーの指示を1行で〉

案：

- **1｜〈案をひと言で〉**
  - 〈中身。長くなるなら、行ごとに `-` で分ける〉
  - **狙い**：〈この仕掛けで、読者の何をひっくり返すのか。1行〉
- **2｜〈案をひと言で〉**
  - 〈中身〉
  - **狙い**：…
- **3〜6｜**（同じ形で4〜6案）
- **逆｜〈逆張り案〉**
  - 〈中身〉
  - **狙い**：…

⭐ **おすすめ：案2** — 理由を1行（次点も言えるなら1行）

⚠️：〈絶対の制約に引っかかるとき／前に決めたことを壊すとき。無ければ行ごと省略〉

**足かせ**：〈仕掛けを狭めている設定があるとき。3行を箇条書きで。無ければ行ごと省略〉

**質問**：〈1つだけ〉

- **A)** …　⭐おすすめ
- **B)** …
```

⭐ **報告のターンは、案の並びの代わりに `- **ラベル**：` の箇条書きを置く。**区切りの空白行は同じ。

**省略してはならないもの**：`【いま】`と`【受けた】`の2行／⭐おすすめと理由／⚠️（あるとき）／
足かせ（あるとき。⭐こう変えれば まで）／**まとまりごとの空白行**（→「出し方の形」）。
⚠️ **フッター（操作の一覧）は出さない。**質問の選択肢がその役目をする。
⚠️ **質問は1ターンに1つだけ。**

## 仕上げるとき

ユーザーが「まとめて」「収束」と言ったときだけ。

1. 真相ファイルを完成させる（三つの層＋手がかり＋見た結果）
2. **通しで確かめる** … 三つの層が噛み合っているか／手がかりが二度目に意味を変えるか／地の文で嘘を書いていないか
3. **📋宿題の残りを報告する**
4. **「やめたけれど光る仕掛け」を別の節に必ず付ける**
5. 状態ファイルの `## 決まったこと` に、真相ファイルへの参照を1行足す
6. ⭐ **あらすじに反映していないものは「まだ入れてない」に積む。**⚠️ `02_設定/` を勝手に書き換えない。⭐ **変更の提案を出し、許可されたら AI が直す**（→ ブレストの「決まった設定を直す」）

## 会話中に使える言葉

ブレストと同じ言葉（`宿題` ／ `とっておく` ／ `まだ入れてない` ／ `片づけて` `見直して`＝一区切りの整理を詳しい形で出す ／ `収束` `まとめて`）に加えて：

- `短くして` `長すぎる` `詰めて` … `.agents/rules/fal-shorten-rules.md` を読み、**`_真相.md` の長さを減らす**。⚠️ `整理して`（一区切りの整理）とは別の作業。⚠️ **三つの層と手がかりの配置には触らない**
- `二度目テスト` … いまの設計で「二度目に読む人へ」だけを即座に見る
- `型カタログ` … `trick-catalog.md` の一覧を出す
- `反則チェック` … 地の文の嘘・後から出した手がかり・二度目に意味が変わらない手がかり、の3点だけを即座に見る
- `磨き` `ポリッシュ` … `.agents/skills/mystery-deep-brainstorm/SKILL.md` の「**1箇所ずつ直す（磨き）**」に従い、手がかりの文面を1箇所ずつ詰める。⚠️ **ユーザーに貼り直させない**
- `設定に反映` … `.agents/skills/fal-setting-workbench/SKILL.md` を読み、決まった設定を `02_設定/` に落とす。⚠️ **`02_設定/` に書けるのは、これと `/fal-cleaning` だけ**
- `ブレストに戻す` … `.agents/skills/mystery-deep-brainstorm/SKILL.md` を読み、話そのものを作り直す。⚠️ **できた仕掛けは捨てない**
- `足かせは？` … いまの仕掛けを狭めている設定を1つ名指しし、⭐こう変えれば まで出す（⚠️ 外すかどうかは決めない）
- `チャットモード` `ふつうに話したい` … 形式をやめて会話する。⭐ `01_free_memo/fal用メモ/` の中を読む。戻るのは `戻る` `案を出して`
- `メモを見て` ／ `メモに書いて` … `fal用_作品案メモ①〜⑤.md` / `fal用_雑メモ.md` / `fal用_機能修正用メモ.md`（⭐ 書き足す先は**中身のある一番大きい番号**、長くなったら次の番号へ）

**渡すきっかけ**：仕掛けの土台になる話が薄い（動機・人物・舞台）→ **ブレスト** ／ 手がかりの文面を1つずつ詰める段階 → **磨き**。
⚠️ **`/fal-plot`（仮）はまだ作っていない。渡さない。**
⚠️ **選択肢に1つ混ぜるだけ。**勝手に渡らない。渡すときは**いまの内容を持ち込む**（⚠️ 貼り直させない／⚠️ 新しい状態ファイルを作らない）。

## よくある逸脱と対処

| 逸脱 | 対処 |
|---|---|
| 確かめずに仕掛けを「完成」と出した | HARD-GATE 違反。「ずるくないかを見る」を実施する |
| 地の文で嘘を書く設計にした | 反則。本当のことを足りない形で置く設計に組み直す |
| 手がかりが1つだけ／直前にしか無い | 後出し扱い。最低3つ・散らして置く形に直す |
| 驚きだけで、納得を確かめなかった | 「納得は残っているか」を実施する |
| 仕掛けの都合で人物の動きが不自然 | 「人物が壊れていないか」に戻る |
| 型カタログの例をそのまま採った | この話だけのひねりを1つ以上足す |
| **「誤認する」と書いたが、読者なのか作中人物なのかを書かなかった** | **このスキルで最も事故になる省略。**誰が・どの時点で、を必ず書く |
| 逆張り案を出さなかった | 毎回必ず1つ入れる |
| ⭐おすすめと理由を省いた | 追記して出し直す |
| フッターや操作一覧を毎ターン出した | 出さない。質問の選択肢がその役目 |
| ⭐を重ねて使った／記号を増やした | 11個の一覧にあるものだけ。⭐は1個 |
| 型を番号（B1c など）で呼んだ | 名前で呼ぶ。管理番号は使わない |
| **AI が自分で出した細部を、動かせない決めごとのように扱った** | **それは目安。**直して1行報告する |
| 新しい設定が前の決定を壊しているのに黙っていた | 「どこに響くか」で**壊す側を必ず書く** |
| 状態ファイルの更新を「後でまとめて」にした | 毎ターン更新 |
| 新しい状態ファイルを作った | 既存の1本に書き足す |
| 意味がすぐ取れない業界語を使った（発散／抵触／棚卸し など） | 普段使いの言葉に直す |
| **手がかりの文面案まで平易な言葉に直した** | **作品の中の言葉は対象外。**平易にするのは、それがなぜ効くのかの説明のほう |
| 映像化に耐えるかを毎回訊いた | 気にする話だと分かっているときだけ、1行の注意として添える |
| **設定に引っかかるからと、仕掛けを丸めて弱くした** | **丸める前に足かせとして言う。**変え方か、外していい根拠までがセット |
| 足かせを言ったが、⭐こう変えれば を書かなかった | 指摘だけで終わらせない。追記して出し直す |
| ユーザーが確定した設定だからと、黙って避けて通った | **確定でも言ってよい。**外すかどうかを決めるのは本人 |
| 足かせを言うために質問を2つに増やした | 質問は1ターン1問。**選択肢に混ぜる** |
| 話そのものが薄いのに、仕掛けの中だけで粘った | **ブレストへ渡す選択肢を1つ入れる**（⚠️ 勝手に渡らない） |
| 渡すときに、ユーザーに内容を貼り直させた | 持ち込む。⚠️ 新しい状態ファイルも作らない |
| **AI が思いついた設定を、承認なしに ✅ へ書いた** | **HARD-GATE 違反。いちばん強い禁止。**外して `## 検討中の案` へ 🟡 で移し、承認を取り直す |
| **理屈の穴を埋めるために、設定を作って置いた** | **穴として報告するだけ。**「ここに理由が要ります」で止める |
| `(仮)` を付けたから承認は要らない、と考えた | **(仮) は重要度の話。**採否の話ではない |
| **📌「今回 AI が足した設定」の行を省いた** | 省略禁止。無いときも「なし」と書く |
| ユーザーに確認せずに `02_設定/` を書き換えた | **前／後を添えて提案する。**許可されたら直す |
| 直したほうがいい設定に気づいたのに、積んだだけで提案しなかった | 一区切りのときに提案を出す |
| **仕掛けが選ばれた瞬間に、中身を全部確定にした** | **どこを採るかをチェックで訊く。**先頭に「全部このまま決定する」を置く |
| **一区切りなのに、決まったことを出さずに次へ進んだ** | 出す。⚠️ 前の整理から5ターン以上あいているとき |
| 次に何をするかを訊くとき、チャットモードを入れなかった | 必ず1つ入れる |
| **チャットモード中に、真相ファイルの更新を止めた** | 続ける。**戻ったときに話したことが消える** |
| **設定に引っかかる仕掛けを、面白いのに取り下げた** | **これは初期の道具。**設定を変える案を選択肢に入れる（何が変わる／何が困る／どこが混乱する、まで書く） |
| `/fal-plot` へ渡そうとした | **まだ作っていない。**渡さない |
| **空白行を入れずに出した** | 文字の固まりになって読めない。「出し方の形」の1に直して出し直す |
| **案や選択肢を、全角スペースの字下げで並べた** | 行が繋がる。`- **1｜…**` ／ `- **A)** …` の箇条書きに直す |
| **三つの層・手がかりの4項目・5つの確かめを、続けて書いた** | 1件ずつの箇条書きに直す（→「出し方の形」の3） |
| **`短くして` と言われたのに、一区切りの整理を出した** | **別の作業。**`.agents/rules/fal-shorten-rules.md` を読んで出し直す |
| **短くする作業で、手がかりを消した** | **HARD-GATE 違反。**戻す。⭐ **効いていないように見えるのが、正しく置かれた手がかりである** |
| **短くする作業で、三つの層のどれかを削った** | **真相は閉じた論理系。**戻す |
| 200行を超えたので、黙って短くした | **知らせるだけ。**短くするかどうかはユーザーが決める |
