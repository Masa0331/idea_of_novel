# あらすじの骨子を作る

## これは何か

**面白い話の骨だけを、速く作る。**細かい設定・辻褄・整合は、ここでは扱わない。

⭐⭐ **面白いあらすじができれば、設定はあとから帳尻を合わせられる。**逆はできない。
——設定をどれだけきれいにしても、骨がつまらなければ、つまらない作品になる。

<HARD-GATE>
矛盾・辻褄・既存設定との食い違いを理由に、面白い案を取り下げてはならない。
「前に決めた設定と合わない」「現実にはありえない」「あとで困る」は、どれも案を弱める理由にならない。
気づいたことは「引っかかり置き場」へ黙って足し、会話は止めずに進める。直すのは次の工程である。
</HARD-GATE>

<HARD-GATE>
ここで書いたものは、何ひとつ決定ではない。全部が案である。
✅ を付けない。`02_設定/` を書き換えない。`brainstorm/` の状態ファイルも触らない。
</HARD-GATE>

<HARD-GATE>
細かい設定の提案をしてはならない。ここは設定を考える場所ではない。
新しい案を、既存の設定に合わせようとしてもならない。それは案に余計な制約を付けるだけである。
</HARD-GATE>

---

## 設定の扱い（⭐ ここがこのスキルの肝）

**気にするのは、キャラクターとストーリーの根幹だけ。**⚠️ それ以外は**気にしなくてよい。**
⭐ **骨子を作り直すのだから、細かい設定が変わるのは当たり前である。**

**⚠️⚠️ やってはいけないこと**

- **新しい案を、既存の設定に合わせようとする**（⭐ **案に余計な制約が付くだけ**）
- **細かい設定の提案をする**（⚠️ **はっきり言って邪魔になる**）
- 「この案だと〈設定〉と食い違います」と報告して、話を止める（⭐ 気づいたら**引っかかり置き場へ黙って足す**）

**⭐⭐ 逆に、やってほしいこと**

- ⭐ **設定を壊して、出た案をいちばん活かす形になる設定を提案する。**——⚠️ **合わせにいくのではない。作りにいく**
- ⭐ **すばらしい設定を思いついたときは、積極的に提案する**（⚠️ ただし**骨子に効くもの**だけ。細部は出さない）

**決めておく設定は、2種類だけ**

1. **これが無いと骨子が立たない設定**（誰が死ぬ・何が隠されている・誰が何を知らないか、など）
2. **ユーザーが指摘したところの設定**

⚠️ **それ以外は、決めない。**⭐ 決めるのは `/fal-brainstorm` の仕事である。

## 使う記号（4つだけ）

```text
👤 ユーザーが言ったこと    🤖 AI が足したこと
⭐ おすすめ・要点          ⚠️ 注意
```

⚠️ **これ以外の記号を足さない。**⚠️ **`⭐⭐⭐` のような重ね技を使わない**（⭐⭐ まで）。

## 始めるとき（2問。1ターンに1問）

### 1問目｜このあらすじは、全体のどこか

```text
- [ ] 話ぜんぶのあらすじ
- [ ] 全体の一部（→ どこか一言。縦軸／過去編／第一話 など）
- [ ] まだ決まっていない（作りながら決める）
```

### 2問目｜このあらすじに、どんな役割を持たせたいか（⭐ 複数選んでよい）

```text
- [ ] 驚かせる（どんでん返し）
- [ ] 読者を誤らせる（ミスリード・叙述トリック）
- [ ] 伏線を張る（あとで効く）
- [ ] 伏線を回収する（前に張ったものが、ここで効く）
- [ ] 謎を出して引っ張る
- [ ] 感情を動かす（切なさ・救い・後味）
- [ ] 世界と人物を見せる（説明の回）
```

⭐⭐ **選ばれたもので、案の出し方が変わる。**

- **驚かせる／誤らせる** → 各案に**裏切りの1行**を付け、型カタログを読む（→「借りてくる3つ」）
- **伏線を張る／回収する** → 各案に「**どこで効くか**」を1行足す
- ⚠️ **「世界と人物を見せる」だけが選ばれたら、驚きの案を無理に並べない**

⚠️ **この2問より前に、案を出してはならない。**

## 入り口は2つ

### モードA｜作り直す（既にあるものを、もっと面白くする）

- **入力**｜すでにある `brainstorm/<セッション名>_あらすじ.md` など
- **人物設定はそのまま使う**（`02_設定/キャラクター/` を読む）
- ⚠️ **細かい設定は無視してよい。**あとで設定のほうを合わせる
- **最初の一手**｜⭐ **元のあらすじを骨子（15〜30行）に圧縮して、1回だけ見せる。**そこから「もっと面白くする案」を出す
  - ⚠️ **圧縮した時点では、まだ何も変えない。**土台を確かめてもらうだけ

### モードB｜骨子をゼロから作る

- 話は1から作る
- ⭐ **最低限必要なファイルだけ参照する。**読まないことが速さになる
- ⚠️ 迷ったら、参照するファイルを1問で確かめる

---

## 作る順番

⭐ **あらすじを頭から書かない。山場から置く。**

```text
1. 一行の芯       … この話は何の話か（1行）
2. 驚く場所を3つ  … どこで読者がひっくり返るか（⭐ 順不同でよい）
                    ⭐ 「驚かせる／誤らせる」を選んだなら、それぞれに裏切りの1行
3. 結び           … 読み終わったとき何が残るか（1行）
4. あいだを埋める … ここで初めて通しのあらすじにする
5. 別バージョン   … 気に入らなければ 2 に戻る
```

⚠️⚠️ **4 まで行かずに、2 と 3 を何度もやり直すのが正しい使い方。**
⚠️ **1 が決まる前に 4 へ進まない。**

---

## 案の出し方

**方向の違う案を 4〜6個 ＋ 逆張り案1個**出す。各案は 3〜6行。

各案に、**必ず1行**。

```text
狙い：読者が〈ここ〉で〈驚く／裏切られる／嬉しくなる〉
```

⚠️ **これが書けない案は、出さない。**

**役割に応じて、もう1行だけ足す**（⚠️ 両方は付けない）

```text
裏切り：〈読者が置いている、どの思い込みを裏切るか〉   ← 驚かせる／誤らせる を選んだとき
効く先：〈これがあとで、どこで効くか〉                 ← 伏線を張る／回収する を選んだとき
```

⚠️ **毎回3行にすると重くなる。**狙い1行が基本、足すのは1行まで。

**ユーザーの返し方は自然文でよい。**「1と3を混ぜて」「⭐A」「2は舞台だけ残して」——どう書かれても同じ意味に取る。
**明らかなら、確認せずそのまま作る。**⚠️ 分からないところだけを1問で訊く。

⚠️ **言及の無かった案は、やめた扱いにする。**聞き返さない。⭐ 惜しいものは AI の判断で1〜2件だけ「別バージョン」に回してよい。

---

## 借りてくる3つ（`/fal-twist` から）

⭐ **ミステリーの骨子は、出来事だけでは決まらない。**「読者がどこで読み違えるか」まで決めないと、あとから仕掛けを乗せられない。

1. **裏切る思い込み** … 「驚く場所3つ」に1行ずつ。例＝「語り手は本当のことを言っている」「この二人は別人だ」「事件はいま起きている」

2. **型カタログ** … `.agents/skills/twist-trick-forge/trick-catalog.md` を読む
   - ⚠️⚠️ **コピーしない。**同じ1本を参照する（二重に持つと必ずずれる）
   - ⭐ 読むのは前半だけ＝**「何をひっくり返すか」の6つ**と**「読者の思い違いを使う型」**（人物／時間／場所／視点／状況／本の作り）
   - ⚠️ 後半（手がかりの配り方・成り立っているかの確かめ）は**読まない**
   - ⚠️⚠️ **型をそのまま当てはめた案は弱い。**必ず**この話でしか成り立たない一点**を足す

3. **偽の答え → 本当の答え** … ⭐ **骨子の段階で決めないと構成が組めないのは、これだけ**
   - ⭐ **偽の答えは八割正しくすると効く**
   - 「真相を知らないと、そう見えてしまう」形は、これである

**⚠️ 借りないもの**（`/fal-twist` の仕事のまま置く）
三つの層 ／ 手がかりを配る（1つにつき4項目・最低3つ）／ ずるくないかを見る（5つの確かめ）／ 真相ファイル。
⚠️ **ここを持ち込むと、会話が重い側へ流れる。**

---

## 長さ（目安）

**骨子あらすじ＝15〜30行を目安。**

- ⭐ 超えたら「細部が入り込んでいる合図です」と**一度だけ知らせる**
- ⚠️ **強制的に削らない。**決めるのはユーザー

---

## 出どころの印

あらすじの各行の頭に **`👤`（ユーザーが言ったこと）／`🤖`（AI が足したこと）** を付ける。

⚠️ **これは承認の門ではない。ただの印である。**——⭐ 次の工程へ渡したとき、**どこを承認すべきかが一目で分かる**、それだけのためにある。
⭐ だから、印を付けたうえで**会話は一度も止めない。**

---

## 引っかかり置き場

ファイルの末尾に1つ置く。矛盾・穴・辻褄の破れを、ここへ溜める。

- ⭐ **AI が気づいたら、確認せず黙ってここへ足してよい**
- ⚠️⚠️ **足したことを会話で話題にしない。議題にしない。**案出しを止めない
- ⭐ **渡すとき、この置き場ごと持って行く**

⚠️ **これは宿題ではない。**次の工程へ渡すための荷物置き場である。

---

## ファイル

| ファイル | 中身 |
|---|---|
| `synopsis/<日付>_<短い名前>.md` | 本体1本。雛形は同じフォルダの `synopsis-template.md` |
| `synopsis/<日付>_<短い名前>_案B.md` | 別バージョン（⭐ 気に入らない案は上書きせず、こちらへ分ける） |

- **毎ターン、本体を更新する。**会話の記憶に頼らない
- ⭐ **設定を壊す案こそ、別バージョンで置く。**そのほうが安全で速い
- ⚠️ `brainstorm/` にも `02_設定/` にも書かない

---

## 毎ターンの形

```text
【いま】〈どこを作っているか〉

（案 4〜6個 ＋ 逆張り案1個）

⭐おすすめ：案N — 理由を1行（次点も言えるなら1行）

質問：〈1つだけ〉
　A) …　⭐おすすめ
　B) …
```

**省略してはならないもの**：`【いま】`の1行 ／ ⭐おすすめと理由 ／ 各案の狙い1行。
⚠️ **質問は1ターンに1つだけ。**「〜しましょうか？」も質問である。
⚠️ **フッター（操作の一覧）は出さない。**選択肢がその役目をする。

---

## 渡すとき（卒業）

骨子ができたら、AI から**1回だけ**訊く。

```text
- [ ] まだここで練る　⭐おすすめ
- [ ] 設定の辻褄を合わせに行く → /fal-brainstorm
- [ ] 仕掛けを本気で作りに行く → /fal-twist
```

- ⚠️ **1ターンに渡す選択肢は1つまで。**⚠️ 勝手に渡らない
- **渡すときは、本体＋引っかかり置き場＋`👤`/`🤖` の印を、そのまま持ち込む**（⚠️ 貼り直させない）
- ⚠️ **`/fal-plot`（仮）はまだ無い。**渡さない

**渡すきっかけ**（迷ったらこれ）

- 骨が面白くなり、**設定の辻褄を合わせたくなった** → `/fal-brainstorm`
- 骨はできたが、**手がかりをどこに置くか・二度目にどう光るかを詰めたくなった** → `/fal-twist`
- ⭐ **どちらへ行っても、戻り先はここ。**骨が弱いと分かったら戻ってくる

---

## チャットモード

**やめるもの**｜`【いま】` ／ 案4〜6個＋逆張り ／ ⭐おすすめ ／ 1ターン1問。⭐ ふつうに会話する
**続けるもの**｜⚠️ **本体の更新は続ける**（⭐ 戻ったときに話したことが消えない）

入ったら `01_free_memo/fal用メモ/` を読む。⚠️ **ユーザーが持ち出さないかぎり、メモの中身を勝手に議題にしない。**
戻り方＝`戻る` `案を出して`。⚠️ **コマンドを打ち直させない。**⚠️ 新しいファイルも作らない。

---

## 操作の言葉

**案について**：`1と3を混ぜて` ／ `2は舞台だけ残して` ／ `4は別バージョンへ` ／ `5はやめ` ／ `もう3案` ／ `出し直し`
**進み方**：`山場からやり直す` ／ `通しにして`（→ 4へ）／ `短く` `3行で`
**確認**：`引っかかり` ／ `役割は？`（最初の2問の答えを表示する）
**渡す**：`辻褄を合わせたい`（→ `/fal-brainstorm`）／ `仕掛けを作りたい`（→ `/fal-twist`）
**チャットモード**：`チャットモード` `ふつうに話したい` ／ `戻る` `案を出して`

## よくある逸脱と対処

| 逸脱 | 対処 |
|---|---|
| **矛盾を理由に、面白い案を取り下げた** | **HARD-GATE 違反。**引っかかり置き場へ黙って足し、案はそのまま出す |
| 辻褄の話で1ターン使った | ここは辻褄を扱う場所ではない。案出しへ戻る |
| **細かい設定を提案した** | **HARD-GATE 違反。**⚠️ 邪魔になる。骨子だけを出す |
| **新しい案を、既存の設定に合わせて作った** | **HARD-GATE 違反。**⭐ 逆である。**案を活かす形になる設定のほうを提案する** |
| 「この案だと〈設定〉と食い違います」と報告して話を止めた | **引っかかり置き場へ黙って足す。**話は止めない |
| ✅ を付けた／`02_設定/` を書き換えた | **HARD-GATE 違反。**ここに決定は無い |
| 最初の2問を訊く前に案を出した | 止めて、2問から始め直す |
| 「見せる回」なのに驚きの案を並べた | 選ばれた役割に合わせる |
| 一行の芯が決まる前に、通しのあらすじを書いた | 1〜3 に戻る |
| 骨子が30行を大きく超えた | **細部が入り込んでいる。**一度だけ知らせる（⚠️ 勝手に削らない） |
| 型カタログをそのまま当てはめた | **この話でしか成り立たない一点**を足す |
| 手がかりの配り方まで決めようとした | それは `/fal-twist` の仕事 |
| 逆張り案を出さなかった | 毎回必ず1つ入れる |
| ⭐おすすめと理由を省いた | 追記して出し直す |
| 案の「狙い」1行を省いた | 書けない案は出さない |
| 引っかかり置き場に足したことを、会話で話題にした | **黙って足す。**議題にしない |
| 気に入らない案で、本体を上書きした | **別バージョンに分ける。**本体は上書きしない |
| 出どころの印（`👤`/`🤖`）を付けなかった | 付ける。渡した先で承認が取れなくなる |
| 渡すときに、ユーザーに貼り直させた | 持ち込む。⚠️ 新しいファイルも作らない |
| 記号を増やした／⭐を3つ重ねた | 4つの一覧にあるものだけ。⭐は2つまで |
