# ファイルを短くする（brainstorm/ ・ synopsis/ 共通）

⚠️ **このファイルは、`/fal-brainstorm` `/fal-twist` `/fal-synopsis` の3つから読まれる共通の決まりである。**
⚠️ **`always_on` ではない。**「短くして」と言われたとき、またはファイルが上限を超えたときにだけ読む。

---

## これは何か

**ファイルが長くなりすぎたときに、読める長さに戻すための作業。**⭐ **敵は長さそのものである。**

⚠️⚠️ **「一区切りの整理」とは別の作業である。**混ぜてはならない。

- **一区切りの整理**（`整理して` `片づけて` `見直して`）… **中身を確かめる。**決まったことを書き出して承認をもらう
- **短くする**（`短くして` `長すぎる` `詰めて`）… **長さを減らす。**中身は増えも減りもしない

⭐ **なぜ短さを優先するか。**ファイルが長くなると、確認漏れと読み間違いが増える。
⚠️ **記録の完全性より、読める長さを取る**（★ユーザー指定・2026-08-31）。

⭐ **消したものは git に残っている。**⚠️ だから「戻せないから消せない」は、この作業では理由にならない。

---

## HARD-GATE

<HARD-GATE>
選んでもらう前に、1文字も消してはならない。
「明らかに終わっているから」「他所に残っているから」も、例外にならない。
</HARD-GATE>

<HARD-GATE>
⚠️⚠️ **あらすじ・真相・骨子の「本文」を、この作業で短くしてはならない。**
本文には伏線とリフレインがある。⭐ **効いていないように見えるものが、いちばん効く**。
本文を短くしたいなら、それは短くする作業ではなく、それぞれのワークフローの案出しである。
</HARD-GATE>

<HARD-GATE>
⚠️⚠️ **短くするついでに、AI が中身を足したり書き換えたりしてはならない。**
できるのは、消す・1行にする・移す の3つだけである。⭐ **言い回しの改善もしない。**
</HARD-GATE>

<HARD-GATE>
⚠️ **番号と記号を、詰めたり振り直したりしてはならない。**
`#3` `〔注15〕` `S-33` は、他の行から指されている。⭐ **消した箇所は、穴のまま残す。**
</HARD-GATE>

---

## ものさしは3つだけ

⚠️⚠️ **`/fal-cleaning` の5つのものさし（効いていない／足かせ／重なり／食い違い／言葉が多い）は、ここでは使わない。**
伏線・リフレイン・叙述トリックが、そのまま引っかかるためである。

代わりに、次の3つだけを使う。⭐ **3つとも「中身は他所に残っている」ものに限られる。**だから伏線かどうかを訊く必要がない。

- **二重持ち** … あらすじ・真相・骨子・`02_設定/` を読めば分かることが、状態ファイルにも書いてある
- **もう終わっている** … 処置済みの〔注〕／片づいた宿題／反映済みの「まだ入れてない」／決着した「検討中の案」／古い `▶` 行
- **名前だけで足りる** … やめた案・却下した案・改稿履歴。⭐ **何をやめたかは要る。なぜやめたかは要らない**

⚠️ **この3つに当てはまらないものを「長いから」で挙げてはならない。**

⚠️⚠️ **空き枠（`・中身は未定` が付いた行）を、この3つに当てはめてはならない。**
⭐ **中身が他所に残っていないどころか、まだどこにも無い。**「もう終わっている」でも「二重持ち」でもない
（→ `.agents/skills/mystery-deep-brainstorm/SKILL.md` の「空き枠（あとで埋める）」）。

## 行き先は4つ

- **1行にする** … 名前だけ残して、中身を落とす（⭐ **この作業の主役**）
- **消す** … 行ごと落とす。⚠️ **中身が他所に残っているものだけ**
- **移す** … 別ファイルへ出す（`_決まったこと.md` ／ `_archive/`）
- **残す**

⚠️ **`消す` を既定にしない。**⭐ **迷ったら `1行にする`。**長さは消えて、手がかりは残る。

### 「1行にする」の形

⚠️ **理由を捨てて、名前だけを並べる。**

```text
❌ やめた案｜最後の一羽ではない／傷の一致／孫は1〜2年前／裁きの枠組み
```

- ⭐ **1件1行にせず、1つの行にまとめて並べる。**行数が桁で変わる
- ⚠️ **再提案の防止は、名前だけで効く。**理由は git にある

## 触らないもの（3つのワークフロー共通）

- **あらすじ・真相・骨子の本文**（→ HARD-GATE）
- **`絶対の制約`**
- **🎯 が付いている `とっておく`**

---

## フォルダごとの担当と、触ってよい節

**`/fal-brainstorm`** … `brainstorm/<セッション名>.md`（主役）＋ `_あらすじ.md` の**改稿履歴と〔注〕だけ**

- 触ってよい｜`いま`（古い `▶` 行）／`決まったこと`／`検討中の案`（決着したもの）／`宿題`（片づいたもの）／`やめたこと`／`まだ入れてない`（反映済み）／あらすじ冒頭の**改稿履歴**／**処置済みの〔注〕**
- ⚠️ 触らない｜`絶対の制約` ／ 🎯付きの `とっておく` ／ **あらすじの本文（`#0` 以降）**

**`/fal-twist`** … `brainstorm/<セッション名>_真相.md`

- 触ってよい｜**検討して捨てた仕掛け**／**同じ説明が2箇所以上にあるもの**／型カタログから引いた説明の写し
- ⚠️ 触らない｜**三つの層**（真相・読者に見せるもの・手がかり）／**手がかりの配置**。⭐ 真相は閉じた論理系なので、1つ抜くと立たなくなる

**`/fal-synopsis`** … `synopsis/<日付>_<短い名前>.md`

- 触ってよい｜`結び`／**判定済みの ×案**（→ 1行にする）／`引っかかり置き場`（渡し終えたもの）／`現代編の入り口` などの検討の跡
- ⚠️ 触らない｜**骨子あらすじ（表版・真相版）そのもの**。⭐ 表版と真相版が重なっているのは設計であって、重複ではない

## 長さの目安

⚠️ **超えたら、一度だけ「短くしますか」と知らせる。**⭐ **勝手に短くしない。**

- `brainstorm/<セッション名>.md` … **250行**（⭐ `決まったこと` を別ファイルへ出したうえで）
- `brainstorm/<セッション名>_決まったこと.md` … 上限なし。⚠️ **1件1行**
- `brainstorm/<セッション名>_あらすじ.md` … 本文は上限なし。⭐ **改稿履歴は直近1回分だけ**
- `brainstorm/<セッション名>_真相.md` … **200行**
- `synopsis/<日付>_<短い名前>.md` … **150行**

---

## 決まったことの扱い（⭐ いちばん効く）

状態ファイルでいちばん長くなるのは `決まったこと` である。**2段階で処理する。**

**1｜まず1行に詰める**

- あらすじ・`02_設定/` を読めば分かるものは、**`✅〈名前〉 → あらすじ #3` だけ**にする
- ⚠️ 経緯（なぜそう決めたか）は落とす

**2｜そのうえで `_決まったこと.md` へ移す**

状態ファイルには、**群ごとの見出しと件数だけ**を残す。

```text
## 決まったこと（207件）→ `20260816_seiichiro_truth_決まったこと.md`

- A｜誠一郎という人物 … 31件
- B｜ラーテン … 28件
```

⭐ **一目で何があるかは分かり、中身は開いたときだけ読む形になる。**

---

## 毎ターンの形

⭐ **1ターンに出すのは1〜3件まで。**⚠️ まとめて全部出さない。

```markdown
【短くする】対象：brainstorm/20260816_seiichiro_truth.md（558行）

**── やめたこと**

- **いまの形**：4件が理由つきで37行
- **どれに当たるか**：名前だけで足りる — 再提案の防止は、名前だけで効く
- **中身はどこに残るか**：git の履歴

行き先：

- **1行にする** … `❌ やめた案｜最後の一羽ではない／傷の一致／孫は1〜2年前／裁きの枠組み` の1行にする（37行 → 1行）
- **消す** … 節ごと落とす。⚠️ 却下済みの案が再提案されるようになる
- **移す** … `_archive/` へ出す。⚠️ ファイルが1本増える
- **残す**

⭐ **おすすめ：1行にする** — 長さは消えて、再提案の防止だけ残る

**質問**：〈1つだけ〉
```

**省略してはならないもの**：`【短くする】`の行／`どれに当たるか`（ものさしの名前つき）／
`中身はどこに残るか`／4つの行き先／⭐おすすめと理由／**まとまりごとの空白行**。

- ⚠️ **番号を振らない。**表を使わない（→ ブレストの「書き方の3つの決まり」）
- ⚠️ **全角スペースで字下げしない。**`- **ラベル**：` の箇条書きにする
- ⚠️ **質問は1ターンに1つだけ**

---

## 短くしたあとに必ず出す3行

```markdown
- 📝 **短くした**：やめたこと（37行 → 1行）
- **何を落としたか**：やめた4案の理由。⭐ 名前は残っている
- 📝 **減った**：558行 → 521行
```

終わったら、あわせて次を出す。

1. `📝減った：〈合計〉`（例：「状態ファイル 558行 → 210行、骨子 405行 → 148行」）
2. **落としたものの名前の一覧**（⭐ 戻したくなったときの手がかり）
3. ⚠️ **番号のずれが無いか**を最後に確かめる（`#3` `〔注15〕` の指し先）

## よくある逸脱と対処

- **選ばれる前に消した** … HARD-GATE 違反。戻して、提案からやり直す
- **あらすじ・真相・骨子の本文を短くした** … HARD-GATE 違反。戻す。⭐ **伏線が消えている可能性がある**
- **短くするついでに言い回しを直した** … HARD-GATE 違反。戻す。できるのは 消す・1行にする・移す だけ
- **番号を詰めた／振り直した** … HARD-GATE 違反。穴のまま戻す
- **`/fal-cleaning` の5つのものさしを使った** … 3つに当てはめ直す。当てはまらないなら取り下げる
- **「一区切りの整理」と混ぜて出した** … 別の作業である。どちらをやるかを1問訊く
- **既定を `消す` にした** … ⭐ 既定は `1行にする`
- **上限を超えたので、黙って短くした** … 知らせるだけ。⚠️ 短くするかどうかはユーザーが決める
- **一度に10件まとめて出した** … 1〜3件に絞り直す
- **`とっておく` の🎯付きを消した** … 戻す
- **空白行を入れずに出した** … 文字の固まりになって読めない。形に直して出し直す
