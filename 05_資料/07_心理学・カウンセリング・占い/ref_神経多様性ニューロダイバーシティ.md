# 神経多様性（ニューロダイバーシティ）

このファイルは、人間の脳や神経の働き方の違いを自然な多様性として捉え、発達障害などを「障害（欠損）」ではなく「特性」として扱う「神経多様性（ニューロダイバーシティ）」の概念をまとめた設定資料です。

---

## 1. 神経多様性（Neurodiversity）の基本概念

*   **定義**: 人間の脳や神経系の働き方（認知や情報処理のスタイル）には個人差があり、自閉スペクトラム症（ASD）、ADHD、学習障害（LD）などは病気や異常ではなく、「人類の自然な認知バリエーションの一部」であるとする考え方。多様性を尊重し、社会がその違いを受け入れ、適切な環境を整えることを目指します。
*   **歴史的背景**: 1990年代後半にオーストラリアの社会学者ジュディ・シンガーによって造語され、自閉症コミュニティからの議論が発端となりました。現在はLGBTQ+などと同様のアイデンティティ政治・社会運動としても展開しています。
*   **主要な用語**:
    *   **ニューロティピカル（Neurotypical: NT）**: 標準的な神経特性を持つ人。社会が「普通」とみなす認知スタイルを持つ人。
    *   **ニューロダイバージェント（Neurodivergent: ND）**: 標準とされる神経特性から外れる特性を持つ人。
    *   **ニューロマイノリティ（Neurominority）**: 人口比で少数派となる神経特性を持つ人々。

## 2. 障害の「社会モデル」と主要な主張

*   **社会モデル**: 障害は個人の「機能不全・欠陥」ではなく、「特定の特性を持つ個人」と「多数派（定型発達）向けに設計された社会環境・制度」との摩擦によって生み出される「障壁（バリア）」であると捉えます。
*   **主要な主張**:
    *   **尊厳と主体性**: 診断名に関わらず、本人の意思決定と自律を尊重。
    *   **環境調整を優先**: 個人に適応を求めるのではなく、社会（学校・職場・制度・道具）側を変える。
    *   **強みの可視化**: 過集中、体系化志向、パターン認識などの資質を価値あるものとして評価。
    *   **医療・支援は“選べる資源”**: 困りごとの軽減ケアは重要だが、"正常化"のための矯正一辺倒にはしない。

## 3. 科学的・進化的背景と妥当性

*   **多因子遺伝と連続性（スペクトラム）**: 単一の遺伝子によるものではなく、数多くの遺伝子多型の組み合わせと環境要因により連続的に分布する。
*   **進化理論（バランシングセレクション）**: 過去の狩猟採集の環境において、微細な痕跡を見逃さない「過集中（ASD的）」や、素早く動く「即応性と新奇追求（ADHD的）」が集団の生存に不可欠な役割分担であったため、集団内に残り続けている。
*   **動物界の神経多様性**: 鳥などの動物集団にも極端な「凝り性」や「学習障害（歌を標準通り覚えられない）」の個体がおり、それが種の新しい問題解決や進化の原動力として機能している。

## 4. 各特性の「強み（可能性）」

弱点を補うのではなく強みに注目する「ストレングス・ベース」の視点からまとめられた各特性の強みです。

| 状態                            | 特徴的な強み・可能性                                                                               |
| :------------------------------ | :------------------------------------------------------------------------------------------------- |
| **自閉スペクトラム症（ASD）**   | パターン認識、細部への集中力、記憶力、論理的体系化、誠実さ、特定の分野への深い専門性               |
| **ADHD（注意欠如・多動症）**    | 創造性、発散的・柔軟な発想、危機察知・即応性エネルギー、リスクを恐れない行動力、ハイパーフォーカス |
| **学習障害(LD)/ディスレクシア** | 視覚的・空間的思考能力の高さ、物語的思考、全体像の把握能力、芸術的センス、独創的な問題解決能力     |
| **トゥレット症候群**            | 創造性や芸術的身体的才能との強い関連性                                                             |
| **発達性協調運動障害（DCD）**   | 視覚的思考能力の高さによる非言語情報の処理能力                                                     |
| **HSP（高感受性人間）**         | 高い共感性、直感力、場の空気や機微を読み取る圧倒的な感受性                                         |
| **ギフテッド**                  | 特定領域（学術、芸術等）における突出した能力と深い洞察                                             |

## 5. 社会的実践と葛藤・課題

ニューロダイバーシティの実装と、それに伴う現実的な摩擦です。

### 実践例（インクルーシブ社会へ向けて）
*   **企業の取り組み**: 大手IT起業などを中心に、面接の代替手段（ワークサンプル評価）の導入、集中できる個室や照明の調整、リモートワークの推進、メンター制度の配置。
*   **教育現場**: ユニバーサルデザイン・フォー・ラーニング（UDL）による多様な評価や入力ルートの用意。感覚過敏に配慮したクールダウンルームや消音ヘッドホンの提供。
*   **医療・支援**: 困難だけでなく強みに注目するストレングス・ベース・アプローチや、当事者同士のピアサポートの促進。

### 批判と課題（パラドックス）
*   **医学的必要性の軽視**: 重度の困難を抱える人々への医療的介入や支援の必要性が、強みの強調によって軽視されるリスク（過度の理想化）。
*   **高サポートニーズの可視化不足**: 常時生活支援が必要な層のニーズが、「天才性を持つ一部の当事者」の語りの影に隠れてしまう懸念。
*   **社会制度の矛盾**: 現状の日本の制度下で支援や合理的配慮を受けるためには、自身の特性を「障害」として申請し、手帳を取得しなければならないジレンマがある。
*   **多様性ウォッシング**: 企業が採用広報目的で多様性を謳うものの、実際の現場では配慮や環境整備が伴わず、当事者が潰れてしまうケース。

## 6. 小説への応用アイデア

*   **キャラクター描写・集団編成**
    *   一般能力が平均的なチームではなく、極端な長所と致命的な短所を持つメンバーたちが、互いの欠落を補い合い規格外の発想で事態を打破する展開。
    *   天才的な能力の裏で、「なぜ自分は普通の雑談ができないのか」「スーパーの照明が痛い」といった日常的な摩擦や葛藤を抱えるリアルな内面描写。
*   **世界観構築**
    *   **感覚フィルター切り替え装置**: 近未来で自身が「認知モード（例：情報の流れを多角的に捉えるADHDモード）」を自由に選べる世界。
    *   **分離都市のディストピア**: 「標準化と効率化」が極まった社会からの脱出、あるいは認知特性別に居住区が分けられた都市で新たな差別が生まれる社会。
*   **葛藤とテーマ**
    *   「普通」という基準の牢獄に苦しむ主人公が、特性を肯定し受容していく過程。
    *   合理的な環境配慮を求める当事者社員と、それを「甘え」と見なす旧世代社員との世代間・価値観の衝突。
*   **小道具**
    *   **感覚調整グッズ**: 消音ヘッドホン、タスクを視覚化したカード群、シリコンボールなどのアイテム。
    *   **多様性の羽根標本**: 異なる鳥の羽根（異なる脳ネットワークのメタファー）が、複雑な謎を解く手がかりとなる象徴的アイテム。
