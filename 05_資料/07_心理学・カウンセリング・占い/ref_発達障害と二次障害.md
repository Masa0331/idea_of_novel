# 発達障害（ADHD・ASD）と二次障害・カサンドラ症候群

ADHD（注意欠如・多動症）とASD（自閉スペクトラム症）は、生まれつきの脳機能の偏りによる発達障害である。両者は中核となる特性が異なるが、併存（混合型）することもある。

## 1. 特性の比較とミスの発生メカニズム

発達障害によるミスは「努力不足」ではなく、認知と行動パターンの偏りから生じる。（二次障害の大きな要因となる）

| 特性の側面                   | ASD（自閉スペクトラム症）                                      | ADHD（注意欠如・多動症）                                               |
| :--------------------------- | :------------------------------------------------------------- | :--------------------------------------------------------------------- |
| **中核症状**                 | 「社会的コミュニケーションの困難さ」「強いこだわり・反復行動」 | 「不注意」「多動性」「衝動性」                                         |
| **注意力・集中**             | 興味のあることに**驚異的な過集中**を発揮。                     | **注意散漫**で気が散りやすい。ミスや忘れ物が多い。                     |
| **ワーキング**<br>**メモリ** | （特性としては言及されにくいが、特定手順への固執あり）         | **弱い傾向**。新情報が入ると古い情報が消去されやすい。抜け漏れの原因。 |
| **衝動性**                   | パニックなど別の要因による二次的な衝動。                       | **主要特性**。順番を待てない、危険を顧みない。                         |
| **計画整理**                 | 計画的行動は得意だが、急な変更（ハプニング）が苦手。           | 計画的進行が苦手。思いつきで行動し、整理整頓も苦手。                   |
| **時間の概念**               | （ルーチンには厳格）                                           | 「時間の逆算」が苦手で遅刻しやすい。                                   |
| **指示の理解**               | **曖昧な言葉（「あれやっといて」「適当に」）が理解できない。** | 途中で話を聞き漏らすため、最後まで理解できない。                       |
| **感覚の偏り**               | **感覚過敏・鈍麻**が顕著（後述）。                             | 併存していなければASDほど顕著ではない。                                |

## 2. 会話・コミュニケーションの特徴

どちらも「会話が噛み合わない」「空気が読めない」という印象を持たれがちだが、その原因は異なる。

### ADHDの話し方
*   **衝動的な割り込み**: 相手の話を最後まで聞けず、思いついたことをすぐ口にする。
*   **早口・立て続け**: 思考回路の回転に口が追いつかず、息継ぎなしに喋り続ける。
*   **話の脱線（飛び）**: 連想ゲームのように話題が次々と飛ぶ（本人の頭の中では繋がっている）。
*   **注意散漫**: 相手が話している途中で別のことに気を取られ、会話が途切れる。

### ASDの話し方
*   **文脈・裏の意味が読めない**: 冗談、皮肉、比喩を「文字通り」に受け取ってしまう。（例：「目が飛び出るかと思った」→「え、眼球の構造上あり得ないよ」などと返す）
*   **視線が合わない**: 他人の感情を読むのが苦手なため、目を合わせない、または不自然に見つめ続ける。
*   **興味範囲への固執（一方通行）**: 自分の好きな話題になると、相手の反応を無視して延々と専門的なことを話し続ける。
*   **質的な違い**: 音の高さ、リズムが独特。過度に丁寧すぎる、あるいは唐突にタメ口になるなど距離感の異常。

## 3. 二次障害のメカニズム

発達障害の特性ゆえの「失敗体験の蓄積」や「周囲（定型発達）に過剰に合わせようとする疲弊（過剰適応）」がストレスとなり、後天的に発症する身体的・精神的疾患群。
*   **精神疾患**: うつ病、不安障害症（パニック、社交不安など）、睡眠障害。
*   **行動上の問題**: 各種依存症（アルコール、薬物、ギャンブル）、不登校、引きこもり、反抗・暴力。
*   **身体症状**: ストレス性の片頭痛、胃潰瘍、心身症など。

## 4. 感覚過敏と感覚鈍麻（主にASD領域）

特定の感覚刺激に対する独特・異常な反応。これらは強いストレスとなり、行動を制限する。（わがままではなく、脳の処理の次元の問題）

*   **聴覚**: ドライヤーの音などが耐えられない。雑音と話し声のボリューム調整（カクテルパーティー効果）ができず、全てが同じ大音量で聞こえてパニックになる。
*   **視覚**: 蛍光灯の特定のチラつきが「針で刺される」ように眩しく痛い。
*   **触覚**: 服のタグ、特定の繊維の肌触りが苦痛で着られない。他人に触れられるのを極度に嫌がる。
*   **鈍麻（より危険）**: 痛覚や温度覚が鈍いため、大怪我や熱中症になっても気づかないなど、重大な健康リスクになり得る。

## 5. カサンドラ症候群

パートナーや家族が**ASD（またはその傾向）**であることで、情緒的なコミュニケーション（共感やねぎらい）が成立せず、孤独感と隔絶感から生じる心身の不調。

*   **特徴・原因**:
    *   ASD側は悪意がない（ただ相手の気持ちを推測する機能が欠けている）が、結果的に「冷たい」「無関心」な態度になる。
    *   ASD側が職場で過剰適応し「外ではいい人・優秀な人」であることが多いため、周囲に相談しても「いい旦那（妻）さんなのに贅沢な悩みだ」と理解されず、当事者の**孤立感**が深まる。
*   **なりやすい人の傾向**: 真面目、完璧主義、責任感が強い、我慢強い、面倒見が良いなど。自分を責めやすいタイプ。
*   **対策**:
    *   ASD特性の理解し、諦めるポイント（情緒的共感）を見極める。
    *   「察してほしい」をやめ、「何をしてほしいか」を**簡潔な言葉・ルール・視覚的なメモ**で具体的に指示する（システム化する）。
    *   心療内科や自助グループなど、外部の「理解者」を見つけること。
