# ADHD特有の困難と職業的ミスマッチ

このファイルは、ADHD（特に不注意優勢型）の特性と、特定の職業的要件との間に生じるミスマッチ（致命的なミスの発生リスク）についての資料です。ブライダル業界での頻出事象をケーススタディとして含んでいます。

---

## 1. ADHD（不注意特性）と相性の悪い業務要件

ADHDの特性（詳細への集中力不足、ケアレスミス、ワーキングメモリの制限、マルチタスクの困難、時間感覚の欠如）は、以下の要件を必須とする職業において重大なリスクとなる。

*   **安全クリティカル（一瞬のミスが人命や大事故に直結する）**
*   **極めて高い正確性と詳細への持続的注意（数字・データの完璧な処理）**
*   **複雑なステータス管理と同時並行処理（マルチタスクの極致）**

## 2. ミスマッチが起こりやすい職業の分類

支援や環境調整がない場合、以下の職業は失敗のリスクが極めて高い。

### I. 安全クリティカルな職種
秒単位の持続注意と瞬時の正確な判断が求められ、ミスが取り返しのつかない結果（死傷者、災害）を生む。
*   **例**: 航空管制官、パイロット、外科医・麻酔科医、原子力・化学プラントオペレーター、薬剤師（調剤）、救急救命士、高圧電気工事士。

### II. 詳細・反復処理・正確性が最重要な職種
単調な作業の連続の中で、1円・1文字単位の正確性が求められ、ミスが甚大な財務的・法的損失や品質低下を招く。
*   **例**: 会計士・税理士、データ入力専門職、校正者・校閲者、臨床検査技師、パラリーガル（法律事務）、品質管理検査員、組込ライン作業員。

### III. 複雑な調整・管理が求められる職種
多数のタスク、人員、スケジュールを抜け漏れなく同時並行で管理する必要がある。
*   **例**: 大規模プロジェクトマネージャー（PM）、複数役員担当の秘書、イベントプランナー。

## 3. ケーススタディ：ブライダル業界における頻出ミス

ブライダル業界は「一生に一度の完璧さ」と「膨大なマルチタスク」が同時に求められるため、ADHD特性によるミスが特に顕在化しやすい。

*   **打ち合わせ・手配段階**
    *   **ワーキングメモリの弱さ**: 「この曲は使わないで」という重要な要望の聞き流し、アレルギー情報の厨房への伝達漏れ（命に関わる）。
    *   **マルチタスクの困難**: 複数のクライアント情報の混同、一部の業者への連絡抜け。
    *   **不注意・ケアレスミス**: 招待状・席次表の致命的な誤字（特に名前）、日付のダブルブッキング、見積もりの計算ミス、ドレスのサイズや色の発注ミス。
*   **結婚式当日の運営**
    *   **時間感覚の欠如（タイムブラインドネス）**: スケジュールの遅延に気づけず、披露宴が大幅に押す。BGMや照明のキュー（合図）を出し遅れる。
    *   **整理整頓・物理的管理の困難**: 預かった結婚指輪の置き忘れ・紛失、ご祝儀の仮置きによる管理ミス。
    *   **注意散漫**: ゲストへの誤った場所の案内、親族紹介での順序や名前の度忘れ（暗記の飛躍）。
*   **事後処理**
    *   請求書の最終調整漏れ（追加ドリンク代など）、別のお客様へのお礼メール誤送信、次回のスケジュールの勘違い。

## 4. 創作への応用アイデア

*   **「向いていない職場」での孤軍奮闘**: 不注意特性を持つキャラクターが、上記のような厳格な現場（例：旧態依然としたお堅い会計事務所や、絶対にミスが許されないイベント会社）に配属されてしまい、独自の工夫（ガジェットの活用や極端なルーティン化）で生き残ろうとするサスペンス・コメディ。
*   **天才的発想と致命的ミスのアンバランス**: 誰も思いつかないような素晴らしいウエディングプラン（あるいはシステム設計）をゼロから生み出す天才的な能力（ADHDの過集中・創造性）を持つが、当日の席次表の発注を忘れて大パニックを引き起こすトラブルメーカーなキャラクター。
*   **適材適所による逆転劇**: ある職場では「ポンコツ」の烙印を押されていた人物が、環境や役割が変わる（例：緻密な管理職から、瞬発力と発想勝負の遊撃部隊へ転属する）ことで、水を得た魚のように無双する展開。
