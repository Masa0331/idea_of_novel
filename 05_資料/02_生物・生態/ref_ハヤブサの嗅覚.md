# 猛禽であるハヤブサ（Falco peregrinus）の嗅覚について分かっていることのまとめ

ハヤブサは視覚に極端に依存した狩猟を行うため、従来、嗅覚はほとんど機能しないと考えられてきましたが、近年のゲノム解析や行動実験により、限定的ではあるものの嗅覚が存在し、利用されていることが確認されています。

以下に、科学的に分かっているすべての知見を「形態・遺伝子」「行動・機能」に分けてまとめます。

## 1. 形態学的・分子生物学的証拠

ハヤブサの嗅覚システムは、他の鳥類（特に海鳥や腐肉食鳥）と比較して、進化の過程で縮小しています。

| 特徴                             | ハヤブサの知見                                                                                                                                  | 他の鳥類との比較                                                 | 示唆されること                                                                                     |
| :------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------- | :------------------------------------------------------------------------------------------------- |
| **嗅球（Olfactory Bulb）サイズ** | 脳全体に占める割合が非常に小さい（平均約0.08%）。ただし、一部の報告ではキンカチョウより大きく、ニワトリと同程度（約13-15%）とされることもある。 | 匂い依存型（コンドル科、ミズナギドリ類）は0.25%〜0.46%と大きい。 | 嗅覚処理の優先度が低く、「視覚依存型」に分類される。                                               |
| **嗅覚受容体（OR）遺伝子の数**   | 機能的なOR遺伝子の数は**鳥類の中で最小クラス**の一つで、約28個〜74個程度しかない（総数118、機能74という報告もある）。                           | 鳥類の平均は約180個。海鳥では600個を超える種もある。             | 匂いを識別する能力（解像度）が非常に低い。進化の過程で嗅覚遺伝子が急速に退化した（擬似遺伝子化）。 |
| **鼻腔構造**                     | 鼻孔（nostril）は小さく、鼻腔上皮（嗅上皮）の複雑さや表面積が小さい。                                                                           | 臭気分子を吸気中に長く保持する構造に乏しい。                     |                                                                                                    |

## **2. 行動的・実験的証拠**

伝統的に嗅覚は狩猟に使われないとされてきましたが、近年の実験により、基本的な機能の存在が証明されました。

| 機能               | 知見                                                                                                                                                                                                     | 備考                                                                                                                   |
| :----------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------- |
| **食物の検知**     | **嗅覚を使って隠された餌（肉塊）を検知できる**ことが、2025年に発表された飼育下の制御実験（Y字迷路テスト）で初めて示された。成功率は50%～90%に達した。                                                    | 従来の「嗅覚なし」説を覆す決定的な証拠。ただし、実験は飼育下であり、野生での使用頻度は低いと推測される。               |
| **狩猟・捕食**     | 主に**優れた視覚**（数km先の小鳥を識別）と高速飛行で獲物を捉えるため、獲物の追跡自体に嗅覚が使われることは稀である。                                                                                     | 腐肉食のハゲワシのように、遠距離から腐敗臭（メルカプタン類）を検知する能力はないか、あっても極めて近距離に限定される。 |
| **ナビゲーション** | ハトで知られるような「匂い地図」仮説に関して、ハヤブサ科3種で鼻孔を塞ぐ実験を行ったところ、帰巣率に有意な低下は見られなかった。                                                                          | ナビゲーションや帰巣において、嗅覚の役割は最小限または無いと考えられる。                                               |
| **その他の役割**   | 負傷した獲物の血臭、巣内の病原体の腐敗臭、あるいはテリトリー内の微かな痕跡（フェロモンや糞臭）など、**補助的なセンサー**として機能している可能性が示唆されているが、野外での確固たる証拠は不足している。 |                                                                                                                        |

## **3. 結論**

ハヤブサの感覚機能のバランスは**視覚 > 聴覚 > 嗅覚**です。

ハヤブサの嗅覚は、進化の過程で視覚への特化と引き換えに縮小しましたが、「完全にゼロ」ではありません。狩猟やナビゲーションの主要な役割を担うことはありませんが、特定の状況（視覚が利かない環境や、近距離での食物の最終確認、環境監視など）で補助的なバックアップ機能として利用されると考えられています。

**最新の研究（2025年）**により、ハヤブサが嗅覚を利用できる能力を保持していることは確認されましたが、この能力が野生下でどの程度重要であるかは、今後の研究課題とされています。
