# ネコが苦手とする音と光に関する設定・参考資料

ネコが苦手とする音（声を含む）や光について、複数のAIモデルの回答に基づきまとめた資料です。探偵小説におけるネコの行動制御や、動物の生態を活かしたトリック・描写の参考に役立ててください。

## 1. ネコが苦手とする音（声を含む）

### 高周波音（超音波）
*   **具体例**: モニターや旧式家電から発せられる「キーン」というモスキート音、超音波式ネズミ駆除装置、一部の防犯アラーム、金属同士が擦れる音（アルミホイルのガサガサ音、爪でガラスを引っかく音など）。
*   **理由**: 人間には聞こえない、あるいは気にならないレベルの音であっても、ネコの聴覚には非常に不快な騒音として響く。ネズミの鳴き声（30-55kHz）と周波数が重なるため、狩猟本能が刺激され、苛立ちや警戒心を引き起こすことがある。

### 突然の大きな音・爆発音
*   **具体例**: 雷鳴、花火、風船が破裂する音、金属が落下する音、大きな咳やくしゃみ、手を叩く音。
*   **理由**: 静かで予測可能な環境を好むネコにとって、突然の予期せぬ大音量は直接的な「危険」のシグナルとして、本能的な恐怖やパニックを引き起こす。

### 特定の機械音・低周波の騒音
*   **具体例**: 掃除機、ドライヤー、洗濯機、エアコンの急な起動音、工事の音（ドリル音、ハンマー音）。
*   **理由**: ネコにとって脅威的な「捕食者の咆哮」や「地面が揺れる」と感じさせるような空気振動として捉えられ、パニックやストレスを誘発する。単調で逃げ場のない騒音は「窓が開いていない檻」と同様のストレスを与える。

### 「シュー」という威嚇音に類似する音
*   **具体例**: ヘアスプレーや殺虫剤などのスプレー缶の噴射音、ビニール袋やレジ袋が激しく擦れる音、空気が抜ける音。
*   **理由**: ヘビや他の動物が威嚇する際の鳴き声に酷似しており、本能的な警戒心や闘争心を刺激する。

### 特定の声・鳴き声
*   **具体例**: 大きな男性の怒鳴り声（低くうなるような声）、赤ちゃんの甲高い泣き声、犬の吠え声（特に大型犬の低音）、他のネコの威嚇声。
*   **理由**: ネコは言葉の意味ではなく、声のトーンや音量から感情を読み取る。低く威圧的な声は捕食者のうなり声を、甲高い絶叫は警戒音を想起させ、恐怖やストレスを感じさせる。

## 2. ネコが苦手とする光

ネコの目は暗闇での活動に適応しており、わずかな光でも捉えられるように瞳孔が大きく開く特性を有している。このため、強い光や点滅する光に対しては非常に敏感である。

### 突然の強い光（フラッシュ）
*   **具体例**: カメラのフラッシュ、車のヘッドライト、暗い部屋で突然点灯される照明、強い懐中電灯の直射。
*   **理由**: 暗闇に慣れた目に突然強い光が入ると強い痛みすら感じることがある。一瞬視力を奪われ無防備になることを極端に嫌がる。

### 点滅する光（ストロボ・フリッカー）
*   **具体例**: ディスコライト、ストロボライト、故障した蛍光灯のちらつき（フリッカー）、パトカーの回転灯、不規則な点滅。
*   **理由**: 人間よりも高い臨界融合頻度を持つため、人間には連続光に見える光でもネコには点滅して見え、視界が断続的に遮られることで周囲の状況判断が困難になる。これは非常にストレスフルで、方向感覚を失わせる。

### レーザーポインターの光点
*   **具体例**: レーザーポインターの光点（特に青緑の強い単色光）。
*   **理由**: 追いかける本能が刺激されるが、決して捕まえることができないためフラストレーションやストレスになる。目に直接光が当たると失明の危険もある。

### 反射光や特定の色の光
*   **具体例**: 鏡や水面の反射光、CD・DVDの虹色反射、LEDの強い青白色光、紫外線ライト。
*   **理由**: 予測不能な光の動きや刺激が強い波長の光は不快感を与える。紫外線はネコにも見えるとされ、不快に感じることがある。

## 3. 注意事項
*   **個体差と慣れ**: 反応は個体の性格や経験によって異なり、繰り返し曝されることで慣れることもある。
*   **過度なストレスの回避**: 長時間与えたり意図的に恐怖を与えたりすることは健康に悪影響を及ぼす。しつけ等で使用する際は短時間・低強度にとどめ、逃げ場を確保する必要がある。
